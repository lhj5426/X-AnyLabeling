# 路径线 / 矩形框多选 — 标签模式

> **版本**: Hmogai_260702 | **创建日期**: 2026-07-06
> **功能路径**: `Tool → 路径线/框选设置`

---

## 1. 功能概述

为 **Shift+左键路径线选择** 和 **Alt+左键矩形框选择** 两种多选方式增加"标签模式"：
多选完成后自动将选中的图形标签统一改为预设的目标标签，大幅提升批量修正标注的效率。

| 模式 | 行为 |
|:---|:---|
| **默认多选模式** | 原有行为，只选中图形，不修改标签 |
| **标签模式** | 选中图形后自动将所有图形标签改为目标标签 |

---

## 2. 使用方法

### 2.1 打开设置窗口
菜单 `Tool → 路径线/框选设置`，打开设置窗口（非阻塞，可最小化常驻桌面）。

### 2.2 切换到标签模式
- 勾选 **标签模式**
- 在下方标签列表中勾选目标标签（颜色与软件标签列表一致，单选互斥）
- 所有修改即时生效，无需点"确定"

### 2.3 使用多选改标签
- **Shift+左键拖拽路径线**：拖动鼠标画线，松开后线与图形相交的图形自动改为目标标签
- **Alt+左键拖拽矩形框**：拖动鼠标画框，松开后框内图形自动改为目标标签

### 2.4 恢复普通多选
在设置窗口中切回 **默认多选模式** 即可。

## 4. 技术要点

### 4.1 性能优化
- 选中时不读文件、不 import 模块：`_try_apply_batch_label()` 直接从 `self._config` 字典检查模式（O(1)）
- 对话框保存时同步写入 `canvas._config`，保证实时一致
- 标签列表更新时用 `setUpdatesEnabled(False)` 包裹，统一刷新

### 4.2 颜色同步
标签列表的颜色通过 `label_widget._get_rgb_by_label()` 获取，与主界面标签列表完全一致。

### 4.3 配置存储
模式/目标标签保存在 `xanylabeling_config.ini` → `path_selection_settings` 字段：
```ini
path_selection_settings:
  label_mode: true
  target_label: balloon
```

## 5. 典型工作流

**场景：模型训练后批量修正误标**

1. 打开图片文件夹，进入编辑模式
2. 菜单 `Tool → 路径线/框选设置` → 选 **标签模式** → 勾选正确标签
3. 用 Shift+左键（画线）或 Alt+左键（框选）圈中需要修正的图形
4. 松开鼠标 → 全部图形标签自动修正
5. 翻页，重复第 3-4 步
6. 全部完成后菜单切换回 **默认多选模式**
