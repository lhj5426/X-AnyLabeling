# 251015 - 右侧标签区域切换显示快捷键自定义 - 实现文档

## 1. 需求概述

为右侧的标签列表（`UniqueLabelQListWidget`）增加快捷键功能，允许用户通过自定义的键盘快捷键（默认为 F1-F12，但支持任意组合）来切换列表中每个标签的复选框勾选状态，从而控制其在画布上的可见性。配置需要持久化保存在 `~/.YSGxanylabelingrc` 文件中。

## 2. 实现方案概览

整体实现思路分为三个部分：
1.  **UI层面**：创建一个新的对话框 `LabelToggleShortcutDialog` 用于管理快捷键的增、删、改、查。
2.  **逻辑层面**：在主窗口逻辑 `LabelingWidget` 中，增加加载、保存、应用快捷键的逻辑。
3.  **配置层面**：在 `config.py` 的基础上，增加对 `label_toggle_shortcuts` 这一新配置项的读写。

## 3. 主要代码修改

### 3.1. 新增文件：`views/labeling/widgets/label_toggle_shortcut_dialog.py`

-   这是本次功能的核心UI。
-   创建一个新的 `LabelToggleShortcutDialog` 类，继承自 `QtWidgets.QDialog`。
-   **UI构成**：
    -   使用 `QTableWidget` 展示“快捷键”和“标签”的映射关系。
    -   快捷键输入使用 `QKeySequenceEdit` 控件，可以方便地录制复杂的按键组合。
    -   标签选择使用 `QComboBox` 控件，下拉列表动态加载当前文件中的所有唯一标签。
    -   提供“添加”、“移除”、“重置”、“确认”、“取消”按钮来操作表格和保存配置。
-   **数据流**：
    -   对话框在初始化时接收一个快捷键字典 `{'shortcut': 'label'}` 和一个标签列表 `['label1', 'label2']`。
    -   当用户点击“确认”时，对话框将表格中的数据重新组织成字典格式，并通过 `self.accept()` 返回。

### 3.2. 修改文件：`views/labeling/widgets/__init__.py`

-   **目的**：将新创建的 `LabelToggleShortcutDialog` 注册到 `widgets` 包中，使其可以被其他模块正确导入。
-   **修改点**：
    -   从 `./label_toggle_shortcut_dialog` 导入 `LabelToggleShortcutDialog` 类。
    -   将 `LabelToggleShortcutDialog` 添加到 `__all__` 列表中。

### 3.3. 修改文件：`views/labeling/label_widget.py`

这是主要的逻辑修改，在修复了几个启动报错的Bug后，最终的修改如下：

1.  **修正错误的类继承**：
    -   将 `class LabelingWidget(LabelDialog)` 修改为 `class LabelingWidget(QtWidgets.QWidget)`。
    -   **原因**：`LabelingWidget` 是程序的主体，而 `LabelDialog` 是一个简单的弹出对话框，二者功能完全不同，不应存在继承关系。错误的继承导致了 `QWidget::setLayout` 报错。

2.  **修正父类初始化问题**：
    -   将 `super().__init__(parent=parent)` 调用从 `__init__` 方法的中间位置移动到了方法的最开始。
    -   **原因**：必须先完成 `QWidget` 父类的初始化，才能将其实例（`self`）作为父级传递给其他Qt控件（如 `QShortcut`），否则会导致 `RuntimeError: super-class __init__() ...` 的报错。

3.  **`__init__` 方法中增加快捷键初始化逻辑**：
    -   添加实例变量 `self.label_toggle_shortcuts = {}` 和 `self.label_toggle_qshortcuts = []`。
    -   在 `__init__` 的早期阶段（父类初始化之后）调用新方法 `self.load_label_toggle_shortcuts()`，从配置文件加载并应用快捷键。

4.  **新增菜单项和Action**：
    -   创建了一个新的 `QAction` `label_toggle_shortcut_manager`，并将其文本设置为“标签切换快捷键管理器”。
    -   将此 `action` 连接到新的 `open_label_toggle_shortcut_manager` 方法。
    -   将 `action` 添加到“工具”(`self.menus.tool`)菜单中。
    -   将 `action` 添加到 `self.actions` 结构体中，以便统一管理。

5.  **新增核心逻辑方法**：
    -   `open_label_toggle_shortcut_manager(self)`:
        -   获取当前所有的唯一标签 `[self.unique_label_list.item(i).text() ...]`。
        -   实例化并显示 `LabelToggleShortcutDialog`。
        -   如果对话框被确认，则获取返回的新的快捷键字典。
        -   将新配置写入 `self._config["label_toggle_shortcuts"]`，并调用 `save_config()` 持久化。
        -   调用 `self.load_label_toggle_shortcuts()` 以在当前会话中立即应用新快捷键。
    -   `load_label_toggle_shortcuts(self)`:
        -   首先清理并释放所有旧的 `QShortcut` 对象。
        -   从 `self._config` 中读取 `label_toggle_shortcuts` 配置。
        -   遍历配置字典，为每一个快捷键-标签对创建一个 `QShortcut` 实例。
        -   将每个 `QShortcut` 的 `activated` 信号连接到 `toggle_label_visibility_by_name` 方法，并使用 `functools.partial` 传入对应的标签名。
    -   `toggle_label_visibility_by_name(self, label_name)`:
        -   接收一个标签名作为参数。
        -   在 `self.unique_label_list` 中查找对应的 `QListWidgetItem`。
        -   如果找到，则反转其 `checkState`（`Qt.Checked` <-> `Qt.Unchecked`），实现功能的闭环。

## 4. 配置文件

-   功能配置存储在 `C:\Users\YourUsername\.YSGxanylabelingrc` 文件中。
-   新增的配置项为 `label_toggle_shortcuts`，其格式为 YAML 字典，例如：
    ```yaml
    label_toggle_shortcuts:
      F1: 'label_A'
      F2: 'label_B'
      Ctrl+P: 'person'
    ```

## 5. 后续优化与Bug修复

### 5.1. Bug修复：删除与重置无法保存

-   **问题**：在快捷键管理器中执行“移除”或“重置”操作后，虽然界面更新了，但重启软件后配置会复原。
-   **原因**：`config.py` 中的 `save_config` 函数在保存时使用了一套“合并”逻辑，当检测到新的配置项（如 `label_toggle_shortcuts`）为空字典时，会选择性地保留旧配置文件中的非空值，导致删除操作无法被持久化。
-   **修复**：修改 `save_config` 函数，在执行完默认的合并逻辑后，增加一步强制覆盖操作，确保 `label_toggle_shortcuts` 的最新状态（即使是空的）能被准确无误地写入配置文件。

### 5.2. 界面优化：下拉列表颜色显示

-   **需求**：为了提升用户体验，快捷键管理器中标签选择的下拉列表颜色应与右侧主标签列表的颜色保持一致。
-   **实现**：
    1.  **传递颜色**：修改 `label_widget.py` 中的 `open_label_toggle_shortcut_manager` 方法。在打开对话框前，遍历 `unique_label_list`，将每个标签的名称和背景色 `item.background().color()` 作为一个字典 `label_colors` 传递给对话框。
    2.  **自定义ComboBox**：在 `label_toggle_shortcut_dialog.py` 中，创建一个继承自 `QComboBox` 的 `ColoredLabelComboBox` 新类。
    3.  **渲染下拉列表**：`ColoredLabelComboBox` 在填充选项时，使用 `setItemData` 方法为每一项设置 `Qt.BackgroundRole`（背景色）和 `Qt.ForegroundRole`（前景色），前景色会根据背景色亮度动态调整（黑/白）以保证清晰。
    4.  **渲染选中项**：重写 `ColoredLabelComboBox` 的 `paintEvent` 方法，使其在折叠状态下也能绘制当前选中项的背景色和前景色，解决了“只有下拉时有颜色，选中后没颜色”的问题。
