# 251015 - 右侧标签区域切换显示快捷键自定义功能说明

## 1. 功能简介

为了提升标签筛选和显示的效率，本次更新增加了一个高度自定义的快捷键功能。用户现在可以为右侧“标签”面板中的每一个标签设置独立的键盘快捷键，用于快速切换该标签的可见性（即切换复选框的勾选状态）。

默认情况下，建议使用 `F1` 到 `F12` 功能键进行设置，但系统完全支持自定义为任意单个按键或组合键（例如 `Ctrl+P`, `Shift+A` 等）。

## 2. 如何使用

### 2.1. 打开管理器

在软件主界面的顶部菜单栏中，点击 **“工具”** -> **“标签切换快捷键管理器”**，即可打开设置窗口。

### 2.2. 配置快捷键

打开的窗口界面如下，包含一个快捷键和标签的映射列表：

-   **添加快捷键**：
    1.  点击右下角的 **“添加”** 按钮，列表会新增一行。
    2.  鼠标点击新行左侧的“快捷键”单元格，然后直接在键盘上按下您想设置的快捷键组合（例如，直接按 `F1` 或 `Ctrl+1`）。
    3.  点击右侧的“标签”单元格，会弹出一个下拉列表，其中包含了当前所有可用的标签。从中选择一个您希望与该快捷键绑定的标签。

-   **移除快捷键**：
    1.  在列表中用鼠标选中您想要删除的某一行快捷键配置。
    2.  点击右下角的 **“移除”** 按钮。

-   **重置所有**：
    *   点击左下角的 **“重置”** 按钮，会弹窗提示确认。确认后，将清空所有已设置的快捷键。

### 2.3. 保存与生效

-   点击 **“确认”** 按钮，所有配置将立即生效，并会自动保存到您的用户配置文件 (`C:\Users\YourUsername\.YSGxanylabelingrc`) 中，下次启动软件时会自动加载。
-   点击 **“取消”** 按钮，则会放弃本次的所有修改。

## 3. 实际效果

配置完成后，在主界面中，按下您设定的快捷键，右侧“标签”面板中对应的标签复选框状态将会自动切换（选中变为不选中，或反之），画布上对应标签的标注也会同步显示或隐藏，从而实现快速筛选。
