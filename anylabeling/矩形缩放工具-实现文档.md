## 📋 功能概述

为X-AnyLabeling添加**矩形缩放工具**功能，用于按比例缩放所有矩形标注的坐标位置。

### 使用场景

当标注文件在不同分辨率的显示器上显示时，可能会出现位置偏移的问题。例如：
- 原始标注：1920x1080 分辨率
- 显示环境：2560x1440 分辨率
- 结果：矩形位置出现偏移

使用矩形缩放工具可以快速调整所有矩形标注的位置和大小，使其适应新的分辨率。

### 功能特点

1. ✅ **灵活的缩放比例输入**
   - 支持正数和负数（负数会自动转为正数）
   - 支持小数点（如 1.333、0.75）
   - 提供快捷比例按钮（1920→2560、2560→1920等）

2. ✅ **两种缩放中心模式**
   - 图像中心：以图像中心为基准缩放（推荐）
   - 原点(0,0)：以左上角为基准缩放

3. ✅ **支持多种矩形类型**
   - 水平矩形 (rectangle)
   - 旋转矩形 (rotation)
   - 三次点击旋转矩形 (rotation3)
   - 三次点击水平矩形 (rectangle3)

4. ✅ **实时信息显示**
   - 当前图像尺寸
   - 矩形标注数量
   - 缩放结果反馈

5. ✅ **安全机制**
   - 确认对话框防止误操作
   - 支持撤销功能恢复
   - 保存上次使用的设置

## 🎯 使用方法

### 1. 打开工具

在主菜单中选择：**工具 (Tool) → 矩形缩放工具**

### 2. 设置缩放参数

#### 方式一：手动输入缩放比例
在"缩放比例"输入框中输入数值：
- `1.5` - 放大到1.5倍
- `0.5` 或 `-0.5` - 缩小到0.5倍
- `1.333` - 放大到1.333倍（1920→2560的宽度比例）

#### 方式二：使用快捷按钮
点击预设的快捷比例按钮：
- **1920→2560**：缩放比例 1.3333（宽度从1920到2560）
- **2560→1920**：缩放比例 0.7500（宽度从2560到1920）
- **1080→1440**：缩放比例 1.3333（高度从1080到1440）
- **1440→1080**：缩放比例 0.7500（高度从1440到1080）

### 3. 选择缩放中心

- **图像中心（推荐）**：矩形相对于图像中心的位置保持不变，整体布局更协调
- **原点(0,0)**：矩形相对于左上角的位置按比例缩放

### 4. 应用缩放

点击"应用缩放"按钮，确认后即可完成缩放。

### 5. 保存结果

缩放完成后，记得保存标注文件（Ctrl+S）。

## 🔧 技术实现

### 缩放算法

#### 1. 以图像中心为基准缩放
```python
center_x = image_width / 2.0
center_y = image_height / 2.0

for point in shape.points:
    # 计算相对于中心的坐标
    rel_x = point.x() - center_x
    rel_y = point.y() - center_y
    
    # 缩放
    new_x = center_x + rel_x * scale_factor
    new_y = center_y + rel_y * scale_factor
```

#### 2. 以原点为基准缩放
```python
center_x = 0
center_y = 0

for point in shape.points:
    new_x = point.x() * scale_factor
    new_y = point.y() * scale_factor
```

### 旋转矩形中心点更新

对于旋转矩形（rotation、rotation3、rectangle3），需要在缩放后重新计算中心点：
```python
if shape.shape_type in ["rotation", "rotation3", "rectangle3"] and len(shape.points) == 4:
    cx = (shape.points[0].x() + shape.points[2].x()) / 2
    cy = (shape.points[0].y() + shape.points[2].y()) / 2
    shape.center = QtCore.QPointF(cx, cy)
```

## 💡 使用示例

### 示例1：1920x1080 → 2560x1440

**场景**：标注文件是在1920x1080分辨率下创建的，现在要在2560x1440分辨率下使用。

**步骤**：
1. 打开标注文件
2. 打开矩形缩放工具
3. 点击"1920→2560"快捷按钮（缩放比例：1.3333）
4. 选择"图像中心"作为缩放中心
5. 点击"应用缩放"
6. 确认并保存

**结果**：所有矩形的位置和大小都按1.3333倍缩放，适应新的分辨率。

### 示例2：自定义缩放比例

**场景**：需要将所有矩形放大1.5倍。

**步骤**：
1. 打开矩形缩放工具
2. 在"缩放比例"输入框中输入 `1.5`
3. 选择缩放中心
4. 点击"应用缩放"
5. 确认并保存

## ⚠️ 注意事项

1. **备份数据**：虽然支持撤销功能，但建议在使用前备份标注文件。

2. **缩放中心选择**：
   - 如果标注是相对于图像中心布局的，选择"图像中心"
   - 如果标注是从左上角开始的，选择"原点(0,0)"

3. **分辨率比例**：
   - 宽度比例：`新宽度 / 原宽度`
   - 高度比例：`新高度 / 原高度`
   - 如果宽高比例不同，可能需要分别调整

4. **撤销功能**：缩放后可以使用撤销功能（Ctrl+Z）恢复到缩放前的状态。

5. **批量处理**：此工具只处理当前打开的图像，如需批量处理多个文件，需要逐个打开并应用。
