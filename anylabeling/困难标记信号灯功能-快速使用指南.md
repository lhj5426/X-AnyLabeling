# 困难标记信号灯功能 - 快速使用指南

## 什么是困难标记信号灯？

困难标记信号灯是红绿灯系统的一部分，用紫色圆点标识被标记为"困难"的标注对象。当你在标注时勾选了"困难标志"，该标注在标签列表中会显示紫色信号灯。

## 信号灯位置

困难标记信号灯位于标签列表项的**最左侧**，在绿色编辑灯的左边。

```
标签列表项示意：
┌─────────────────────────────────────────────┐
│ 1 balloon(1)                    🟣🟢🟡🔴    │
│                                 ↑ ↑ ↑ ↑     │
│                                 │ │ │ └─ 红色(已选中)
│                                 │ │ └─── 黄色/蓝色(锁定/解锁)
│                                 │ └───── 绿色(已编辑)
│                                 └─────── 紫色(困难标记) ← 新增
└─────────────────────────────────────────────┘
```

## 如何使用

### 查看困难标记

1. 打开包含标注的图片
2. 在右侧标签列表中查看
3. 带有紫色圆点的标注就是困难标记

### 自定义困难标记灯颜色

**步骤：**

1. 点击菜单栏的"工具" → "红绿灯设置"
2. 在弹出的对话框中找到"困难标记"选项
3. 点击颜色按钮（默认显示紫色）
4. 在颜色选择器中选择你喜欢的颜色
5. 点击"确定"

**效果：**
- 颜色会立即应用到所有困难标记灯
- 设置会自动保存到配置文件

## 信号灯完整说明

标签列表中最多可以显示4个信号灯（从右到左）：

| 位置 | 颜色 | 状态 | 默认颜色 |
|------|------|------|----------|
| 最右侧 | 🔴 | 已选中 | 红色 (255, 0, 0) |
| 右侧第2 | 🟡/🔵 | 已锁定/已解锁 | 黄色/蓝色 |
| 右侧第3 | 🟢 | 已编辑 | 绿色 (0, 255, 0) |
| 最左侧 | 🟣 | 困难标记 | 紫色 (128, 0, 128) |

## 使用场景

### 场景1：快速识别困难标注

**需求**：在标注过程中，快速找到标记为困难的对象

**操作**：
- 打开图片
- 在标签列表中查找带有紫色灯的标注
- 这些就是困难标注

### 场景2：配合过滤功能使用

**需求**：筛选出所有困难标注的图片，并在列表中查看

**操作**：
1. 使用文件过滤功能选择"仅困难标记"
2. 打开筛选出的图片
3. 在标签列表中，困难标注会显示紫色灯
4. 可以快速定位和处理困难标注

### 场景3：自定义颜色以适应个人习惯

**需求**：紫色不够明显，想换成更醒目的颜色

**操作**：
1. 打开红绿灯设置
2. 修改困难标记颜色为橙色或其他醒目颜色
3. 保存设置

## 常见问题

**Q: 为什么我的标注没有显示紫色灯？**

A: 可能的原因：
1. 该标注的 `difficult` 字段为 `false`（未勾选困难标志）
2. JSON文件中没有 `difficult` 字段（旧版本文件）
3. 需要重新加载文件

**Q: 可以隐藏困难标记灯吗？**

A: 困难标记灯只在 `difficult: true` 时显示，如果不需要，可以在标注时不勾选困难标志。

**Q: 困难标记灯的颜色设置会影响其他用户吗？**

A: 不会。颜色设置保存在本地配置文件中，只影响当前用户。

**Q: 可以同时显示所有4个信号灯吗？**

A: 可以。如果一个标注同时满足以下条件：
- 被选中（红色）
- 被锁定或解锁（黄色/蓝色）
- 被编辑过（绿色）
- 标记为困难（紫色）

那么会同时显示4个信号灯。

## 技术说明

### JSON数据结构

```json
{
  "shapes": [
    {
      "label": "balloon",
      "difficult": true,  // 困难标记
      "is_edited": true,  // 编辑标记
      "points": [[181.0, 101.0], [246.0, 960.0]],
      "shape_type": "rectangle"
    }
  ]
}
```

### 配置文件

```yaml
traffic_light_colors:
  selected: [255, 0, 0]    # 红色
  edited: [0, 255, 0]      # 绿色
  difficult: [128, 0, 128] # 紫色（可自定义）
  locked: [255, 255, 0]    # 黄色
  unlocked: [0, 0, 255]    # 蓝色
```
