# 虚影填充透明度功能实现文档

## 功能概述

在颜色管理器中新增"虚影填充透明度"设置，用于独立控制虚影（粘贴预览）的填充部分透明度，与边框透明度分离。

## 问题背景

原有的"虚影透明度"设置会同时影响虚影的边框和填充部分，导致无法单独调整填充的透明度。用户希望能够：
- 让填充更透明，以便看清下方的图像内容
- 保持边框清晰可见，便于定位和调整

## 功能说明

### 虚影透明度（原有）
- 控制整个虚影的整体透明度
- 同时影响边框和填充
- 范围：0.0 - 1.0
- 默认值：0.70

### 虚影填充透明度（新增）
- 专门控制虚影填充部分的透明度
- 不影响边框的显示
- 范围：0.0 - 1.0
- 默认值：0.30

### 透明度叠加效果
最终填充的透明度 = 虚影透明度 × 虚影填充透明度

例如：
- 虚影透明度 = 0.70
- 虚影填充透明度 = 0.30
- 实际填充透明度 = 0.70 × 0.30 = 0.21

## 实现细节

### 1. 配置文件修改

**文件：** `configs/xanylabeling_config.yaml`

新增配置项：
```yaml
paste_preview_fill_opacity: 0.3
```

位置：在虚影相关配置项之后
```yaml
paste_preview_line_width: 2.0
paste_preview_line_color: [255, 0, 255]
paste_preview_opacity: 0.4
paste_preview_fill_opacity: 0.3  # 新增
```

### 2. Canvas 绘制逻辑

**文件：** `views/labeling/widgets/canvas.py`

#### 初始化属性
```python
self.paste_preview_fill_opacity = self._config.get('paste_preview_fill_opacity', 0.3)
```

#### 修改绘制逻辑
原代码：
```python
# 绘制填充
if preview_shape.fill:
    color = preview_shape.fill_color
    p.setBrush(QtGui.QBrush(color))
```

修改后：
```python
# 绘制填充 - 使用单独的填充透明度
if preview_shape.fill:
    color = preview_shape.fill_color
    # 创建带有填充透明度的颜色
    fill_color = QtGui.QColor(color)
    fill_color.setAlphaF(self.paste_preview_fill_opacity)
    p.setBrush(QtGui.QBrush(fill_color))
```

**关键点：**
- 使用 `QtGui.QColor` 创建新的颜色对象
- 使用 `setAlphaF()` 设置填充透明度（范围 0.0-1.0）
- 边框不受影响，保持原有的虚影透明度

### 3. 颜色管理器

**文件：** `views/labeling/widgets/color_manager_dialog.py`

#### 新增控件
```python
self.paste_preview_fill_opacity_spinbox = QDoubleSpinBox()
self.paste_preview_fill_opacity_spinbox.setRange(0.0, 1.0)
self.paste_preview_fill_opacity_spinbox.setSingleStep(0.1)
self.paste_preview_fill_opacity_spinbox.setValue(self.config.get('paste_preview_fill_opacity', 0.3))
self.paste_preview_fill_opacity_spinbox.valueChanged.connect(
    lambda value: self._on_setting_changed('paste_preview_fill_opacity', value)
)
right_form.addRow(self.tr("虚影填充透明度:"), self.paste_preview_fill_opacity_spinbox)
```

**位置：** 在"虚影透明度"控件之后

### 4. 配置更新处理

**文件：** `views/labeling/label_widget.py`

在配置更新处理函数中添加：
```python
elif key == 'paste_preview_fill_opacity':
    # 虚影填充透明度
```

## 使用方法

1. 打开"颜色管理器"对话框（菜单：视图 → 颜色管理器）
2. 找到"虚影填充透明度"设置项
3. 调整数值（0.0 - 1.0）
4. 设置实时生效，立即可以看到效果
5. 配置自动保存

## 使用场景

### 场景1：需要看清底图
- 虚影透明度：0.70（保持边框可见）
- 虚影填充透明度：0.20（填充非常透明）
- 效果：边框清晰，填充几乎透明，便于查看底图细节

### 场景2：需要明显的预览效果
- 虚影透明度：0.70
- 虚影填充透明度：0.60（填充较不透明）
- 效果：填充和边框都比较明显，便于预览标注效果

### 场景3：完全透明填充
- 虚影透明度：0.70
- 虚影填充透明度：0.00（完全透明）
- 效果：只显示边框，填充完全透明

## 技术要点

### Qt 颜色透明度设置
```python
# 方法1：使用 setAlphaF (推荐，范围 0.0-1.0)
color = QtGui.QColor(r, g, b)
color.setAlphaF(0.3)

# 方法2：使用 setAlpha (范围 0-255)
color = QtGui.QColor(r, g, b)
color.setAlpha(76)  # 76 ≈ 255 * 0.3
```

### 透明度叠加
- 使用 `p.setOpacity()` 设置整体透明度（影响所有绘制）
- 使用 `color.setAlphaF()` 设置颜色透明度（只影响该颜色）
- 两者会叠加：最终透明度 = 整体透明度 × 颜色透明度

### 绘制顺序
```python
p.save()                          # 保存当前状态
p.setOpacity(0.7)                 # 设置整体透明度
fill_color.setAlphaF(0.3)         # 设置填充颜色透明度
p.setBrush(QtGui.QBrush(fill_color))  # 设置填充画刷
p.setPen(pen)                     # 设置边框画笔（不受颜色透明度影响）
p.drawPath(path)                  # 绘制路径
p.restore()                       # 恢复状态
```

## 注意事项

1. 虚影填充透明度是在虚影透明度基础上的额外透明度控制
2. 两个透明度设置是相乘关系，不是相加
3. 边框只受虚影透明度影响，不受虚影填充透明度影响
4. 默认值 0.3 是经过测试的较合适的值，既能看清底图又能看到预览效果
