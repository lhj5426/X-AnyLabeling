## 📋 功能概述

本次更新为 X-AnyLabeling 的十字参考线功能添加了两个重要增强：

1. **rotation3 模式旋转十字线**：十字线自动跟随第一条边方向旋转
2. **线条样式切换**：用户可选择实线或虚线显示十字线

## 🎯 功能 1：rotation3 旋转十字线

### 功能描述

在 rotation3 模式下，当用户点击第一个点后，十字参考线会智能旋转，其中一条线平行于第一条边方向，另一条线垂直于第一条边，帮助用户精确对齐倾斜文本。

### 修改文件

**文件**：`anylabeling/views/labeling/widgets/canvas.py`
**位置**：第 2613-2688 行（十字线绘制部分）
**修改类型**：逻辑增强

### 核心代码

```python
# rotation3 mode: rotated crosshair based on first edge direction
if (self.create_mode == "rotation3" and self.current
    and len(self.current.points) >= 1 and len(self.line.points) == 2):
    # Get the first edge direction
    p0 = self.current[0]
    p1 = self.line[1]  # Current mouse position

    # Calculate angle of first edge
    dx = p1.x() - p0.x()
    dy = p1.y() - p0.y()
    length = math.sqrt(dx**2 + dy**2)

    if length > 1:  # Avoid division by zero
        # Normalize direction vector
        dx /= length
        dy /= length

        # Get perpendicular direction (90° rotation)
        perp_x = -dy
        perp_y = dx

        # Draw rotated crosshair at mouse position
        crosshair_length = max(self.pixmap.width(), self.pixmap.height()) * 2

        # Line 1: along the first edge direction
        p.drawLine(...)

        # Line 2: perpendicular to first edge
        p.drawLine(...)
```

### 算法原理

1. **向量归一化**：计算起点到鼠标的单位方向向量
2. **90° 旋转**：通过坐标变换得到垂直向量（perp_x = -dy, perp_y = dx）
3. **绘制两条线**：一条平行于第一条边，一条垂直于第一条边

### 视觉效果

| 模式 | 十字线类型 | 说明 |
|-----|-----------|------|
| **其他模式** | 固定水平/垂直 | 标准十字线 |
| **rotation3（未点击）** | 固定水平/垂直 | 标准十字线 |
| **rotation3（已点击第一个点）** | 旋转十字线 | 跟随第一条边方向旋转 |

## 🎨 功能 2：线条样式切换（实线/虚线）

### 功能描述

在十字线设置对话框中新增"线条样式"选项，用户可以选择：
- **虚线（Dashed Line）**：默认，适合不遮挡内容
- **实线（Solid Line）**：更清晰，适合精确标注

这是**全局设置**，影响所有模式的十字线（包括 rotation3 的旋转十字线）。

## 💡 使用场景

### 场景 1：标注倾斜文本（rotation3 + 虚线）

```
1. 进入 rotation3 模式
2. 十字线设置 → 虚线（默认）
3. 点击文本左上角
4. 向右上方移动鼠标（文本方向）
   → 虚线十字线旋转至文本方向
   → 不遮挡文本内容
5. 对齐文本边缘，完成标注
```

**优势**：虚线不遮挡内容，便于观察文本细节

### 场景 2：精确标注（rotation3 + 实线）

```
1. 进入 rotation3 模式
2. 十字线设置 → 实线
3. 点击目标左上角
4. 移动鼠标
   → 实线十字线旋转
   → 线条更清晰，便于精确对齐
5. 完成精确标注
```

**优势**：实线更清晰，适合高精度标注

## 🎯 技术亮点

### 1. 向量数学的优雅应用（功能 1）

```python
# 90° 旋转只需简单的坐标变换
perp_x = -dy
perp_y = dx
```

**优点**：
- 无需三角函数（sin/cos）
- 计算高效（仅两次赋值）
- 代码简洁

### 2. Qt 线条样式的灵活应用（功能 2）

```python
# 动态选择线条样式
line_style = Qt.SolidLine if self.cross_line_style == "solid" else Qt.DashLine
```

**优点**：
- 一行代码完成样式切换
- 无需重复绘制逻辑
- 易于扩展更多样式（点线、点划线等）

### 3. 全局配置管理

所有十字线设置集中管理：
- 配置文件：`xanylabeling_config.yaml`
- UI 对话框：`CrosshairSettingsDialog`
- Canvas 应用：`set_cross_line()`

**优点**：
- 配置一致性
- 易于维护
- 用户友好
