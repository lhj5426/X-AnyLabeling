# 困难标记信号灯功能 - 实现文档

## 功能概述

在标签列表的红绿灯系统中新增了"困难标记"指示灯，当标注框被标记为困难（difficult: true）时，会在标签栏中显示紫色的信号灯。

## 功能特性

### 1. 困难标记指示灯

在标签列表中，每个标注项右侧最多可以显示4个信号灯（从右到左）：

1. **红色灯** - 已选中（最右侧）
2. **黄色/蓝色灯** - 已锁定/已解锁
3. **绿色灯** - 已编辑
4. **紫色灯** - 困难标记（最左侧，新增）

### 2. 显示逻辑

- 当标注框的 `difficult` 字段为 `true` 时，显示紫色困难标记灯
- 当标注框的 `difficult` 字段为 `false` 时，不显示困难标记灯
- 困难标记灯位于绿色编辑灯的左侧

### 3. 颜色自定义

在"红绿灯设置"对话框中可以自定义困难标记灯的颜色：

- 默认颜色：紫色 (RGB: 128, 0, 128)
- 可以通过点击颜色按钮自定义为任意颜色
- 颜色设置会保存到配置文件中

## 实现细节

### 1. 红绿灯对话框修改

在 `views/mainwindow_widgets/traffic_light_dialog.py` 中：

#### 添加困难标记配置

```python
self.key_to_display_name = {
    "selected": "已选中",
    "edited": "已编辑",
    "difficult": "困难标记",  # 新增

    "unlocked": "已解锁",
}

default_colors_rgb = {
    "selected": [255, 0, 0],  # Red
    "edited": [0, 255, 0],  # Green
    "difficult": [128, 0, 128],  # Purple (新增)
    "locked": [255, 255, 0],  # Yellow
    "unlocked": [0, 0, 255],  # Blue
}
```

#### 调整UI布局

由于增加了一个灯，UI布局从2x2调整为3行2列：

```python
# Row 0: selected, edited
# Row 1: difficult, locked
# Row 2: unlocked
grid_order_keys = ["selected", "edited", "difficult", "locked", "unlocked"]
```

### 2. 标签列表绘制修改

在 `views/labeling/widgets/label_list_widget.py` 中：

#### 添加困难标记灯的位置

```python
# Position 1 (Rightmost): Selected (红色)
pos1_x = option.rect.right() - dot_radius - 5

# Position 2: Locked/Unlocked (黄色/蓝色)
pos2_x = pos1_x - (dot_diameter + spacing)

# Position 3: Edited (绿色)
pos3_x = pos2_x - (dot_diameter + spacing)

# Position 4 (Leftmost): Difficult (紫色) - 新增
pos4_x = pos3_x - (dot_diameter + spacing)
```

#### 绘制困难标记灯

```python
# 4. Draw Difficult dot (Position 4 - Leftmost)
if shape and hasattr(shape, 'difficult') and shape.difficult:
    painter.save()
    painter.setRenderHint(QtGui.QPainter.Antialiasing)
    difficult_color_rgb = self.parent._config.get("traffic_light_colors", {}).get("difficult", [128, 0, 128])
    painter.setBrush(QtGui.QBrush(QtGui.QColor(*difficult_color_rgb)))
    painter.setPen(Qt.NoPen)
    painter.drawEllipse(QtCore.QPointF(pos4_x, dot_y), dot_radius, dot_radius)
    painter.restore()
```

### 3. Shape对象支持

Shape对象已经支持 `difficult` 属性：

- 在 `views/labeling/shape.py` 中定义
- 默认值为 `False`
- 可以通过JSON文件加载和保存

## 使用方法

### 查看困难标记灯

1. 打开包含困难标记的图片
2. 在右侧标签列表中，被标记为困难的标注项会在左侧显示紫色灯

### 自定义困难标记灯颜色

1. 点击菜单栏的"红绿灯设置"按钮
2. 在弹出的对话框中找到"困难标记"选项
3. 点击颜色按钮选择新的颜色
4. 颜色会立即应用到标签列表中

## 配置文件格式

在配置文件中，困难标记颜色保存在 `traffic_light_colors` 中：

```json
{
  "traffic_light_colors": {
    "selected": [255, 0, 0],
    "edited": [0, 255, 0],
    "difficult": [128, 0, 128],
    "locked": [255, 255, 0],
    "unlocked": [0, 0, 255]
  }
}
```

## 注意事项

1. 困难标记灯只在 `shape.difficult` 为 `true` 时显示
2. 如果shape对象没有 `difficult` 属性，不会显示困难标记灯
3. 困难标记灯的颜色可以在红绿灯设置对话框中自定义
4. 困难标记灯位于最左侧，不会与其他信号灯重叠
5. 信号灯的大小和间距保持一致，确保视觉统一

## 与其他功能的配合

### 与困难标记过滤功能配合

- 可以使用文件过滤功能筛选包含困难标记的图片
- 在标签列表中通过紫色灯快速识别困难标记
- 两个功能相互配合，提高标注效率

### 与红绿灯系统配合

- 困难标记灯是红绿灯系统的一部分
- 与其他信号灯（选中、编辑、锁定）共同工作
- 统一的颜色管理和配置方式
