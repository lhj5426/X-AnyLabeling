### 2. Canvas修改 (`views/labeling/widgets/canvas.py`)

#### paintEvent中的改进：

在 `paintEvent` 方法中添加了**持久间距线检测**：

```python
# Detect and draw spacing guide (矩形间距线) - 检测所有矩形之间的间距
if self.spacing_guide_enabled and self.shapes:
    spacing_snap_offset, spacing_lines = RectangleSpacingGuide.detect_spacing_lines(
        self.shapes, self.shapes,
        display_distance=self.spacing_guide_display_distance,
        snap_distance=self.spacing_guide_snap_distance
    )
    self.spacing_guide_lines = spacing_lines

# Draw spacing guide (矩形间距线)
if self.spacing_guide_lines:
    self.draw_spacing_guide(p)
```

**关键改进**：
- ✅ 在每次绘制时检测所有矩形之间的间距
- ✅ 不仅在移动时显示，而是**持久显示**
- ✅ 支持开关控制，可随时启用/禁用

## 🎯 功能特性

### 间距线显示

1. **自动检测** - 自动检测所有矩形之间的间距
2. **四方向检测** - 检测左、右、上、下四个方向的间距
3. **距离显示** - 在间距线上显示距离数值（小数点后2位）
4. **三种矩形类型支持**：
   - 水平矩形 - 显示水平/垂直间距线
   - 水平旋转矩形 - 显示水平/垂直间距线
   - 有角度旋转矩形 - 显示斜向间距线

1. **打开辅助线工具窗口** - 在菜单中找到"辅助线工具"
2. **启用间距线** - 勾选"开启间距线显示"
3. **调整参数**：

## 🔧 配置文件

配置项在 `configs/xanylabeling_config.yaml` 中：

```yaml
# Rectangle spacing guide (矩形间距线)
spacing_guide_enabled: true
spacing_guide_line_width: 2.0
spacing_guide_line_color: [0, 255, 255]  # 青色
spacing_guide_opacity: 0.8
spacing_guide_display_distance: 200  # 显示距离（像素）
spacing_guide_snap_distance: 10  # 吸附距离（像素）
```

## 💡 技术细节

### 间距线检测流程

1. 在 `paintEvent` 中调用 `RectangleSpacingGuide.detect_spacing_lines()`
2. 检测所有矩形对之间的间距
3. 返回间距线列表（包含坐标和距离）
4. 调用 `draw_spacing_guide()` 绘制间距线和距离文本

### 配置同步

- 用户在辅助线工具窗口中修改参数
- 触发 `_on_setting_changed()` 回调
- 更新配置文件和canvas属性
- 调用 `canvas.update()` 刷新画布
