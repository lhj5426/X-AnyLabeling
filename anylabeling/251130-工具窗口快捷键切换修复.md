# 251130 - 工具窗口快捷键切换修复

## 问题描述

以下三个工具窗口存在快捷键使用问题：
- **标签页管理器** (`Ctrl+T`)
- **标注框边距扩展工具** (`Ctrl+Shift+M`)
- **矩形对齐工具** (`Ctrl+Shift+R`)

**问题现象**：
1. 用快捷键打开窗口后，主界面失去焦点
2. 必须用鼠标点击主窗口才能继续使用快捷键
3. 无法用快捷键关闭窗口
4. 最小化后无法用快捷键呼出
5. 控制台出现 "Ambiguous shortcut overload" 警告

## 问题原因

1. **快捷键冲突**：窗口内部定义了与主窗口 QAction 相同的快捷键（如 `Ctrl+T`），导致快捷键歧义
2. **toggle 逻辑不统一**：这三个窗口没有使用与其他工具窗口一致的三态切换逻辑

## 修复方案

### 1. 删除窗口内部的重复快捷键

**修改文件**：
- `views/labeling/widgets/object_manager_dialog.py`
- `views/labeling/widgets/expand_margins_dialog.py`
- `views/labeling/widgets/alignment_dialog.py`

删除了窗口内部的 `QShortcut` 定义，因为主窗口的 action 已经使用 `Qt.ApplicationShortcut` 上下文，快捷键在应用程序级别生效。

### 2. 统一 toggle 逻辑

**修改文件**：`views/labeling/label_widget.py`

将三个窗口的打开方法改为统一的三态切换逻辑：

```python
# 使用通用的toggle逻辑
if dialog.isMinimized():
    # 最小化 → 恢复并激活
    dialog.setWindowState(
        dialog.windowState() & ~QtCore.Qt.WindowMinimized | QtCore.Qt.WindowActive
    )
    dialog.raise_()
    dialog.activateWindow()
elif dialog.isVisible():
    # 可见 → 隐藏
    dialog.hide()
else:
    # 不可见 → 显示
    dialog.show()
    dialog.raise_()
```

### 3. 保持窗口标志

确保窗口使用 `Qt.Window` 类型，保留最小化/最大化/关闭按钮：

```python
self.setWindowFlags(
    QtCore.Qt.Window |
    QtCore.Qt.WindowMinimizeButtonHint |
    QtCore.Qt.WindowMaximizeButtonHint |
    QtCore.Qt.WindowCloseButtonHint
)
```

## 关键技术点

1. **Qt.ApplicationShortcut**：主窗口的 action 使用此上下文，使快捷键在应用程序级别生效，即使焦点在工具窗口上也能触发

2. **三态切换**：
   - 最小化 → 恢复并激活
   - 可见 → 隐藏（使用 `hide()` 而非 `close()`）
   - 不可见 → 显示

3. **避免快捷键冲突**：不在子窗口内部定义与主窗口相同的快捷键
