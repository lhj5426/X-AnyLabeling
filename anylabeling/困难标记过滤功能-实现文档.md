# 困难标记过滤功能 - 实现文档

## 功能概述

在文件过滤对话框中新增了"困难标记"过滤功能，支持筛选包含困难标记（difficult）的图片文件，并且支持与标签联动过滤。

## 功能特性

### 1. 困难标记过滤

在JSON标注文件中，每个shape都有一个`difficult`字段：
- `"difficult": false` - 非困难标记（默认）
- `"difficult": true` - 困难标记（勾选困难标志后）

过滤选项：
- **仅困难标记**：只显示至少包含一个困难标记（difficult: true）的图片
- **仅非困难标记**：只显示至少包含一个非困难标记（difficult: false）的图片

### 2. 标签联动功能

困难标记过滤支持与标签列表联动：

#### 使用场景示例

**场景1：筛选所有困难标记**
- 选择"仅困难标记"
- 不勾选任何标签
- 结果：显示所有包含困难标记的图片（不限标签类型）

**场景2：筛选特定标签的困难标记**
- 选择"仅困难标记"
- 勾选"balloon"标签
- 结果：只显示balloon标签中有困难标记的图片

**场景3：筛选多个标签的困难标记**
- 选择"仅困难标记"
- 勾选"balloon"和"qipao"标签
- 结果：显示balloon或qipao标签中有困难标记的图片

**场景4：筛选特定标签的非困难标记**
- 选择"仅非困难标记"
- 勾选"balloon"标签
- 结果：只显示balloon标签中有非困难标记的图片

## 实现细节

### 1. UI修改

在`views/labeling/widgets/file_filter_dialog.py`中添加了困难标记过滤组：

```python
# 困难标记过滤
difficult_group = QGroupBox("困难标记")
difficult_layout = QVBoxLayout()

self.difficult_only = QRadioButton("仅困难标记")
self.difficult_not_only = QRadioButton("仅非困难标记")
self.filter_group.addButton(self.difficult_only)
self.filter_group.addButton(self.difficult_not_only)

difficult_layout.addWidget(self.difficult_only)
difficult_layout.addWidget(self.difficult_not_only)
difficult_group.setLayout(difficult_layout)
layout.addWidget(difficult_group)
```

### 2. 配置获取

在`get_filter_config()`方法中添加了困难标记的配置获取逻辑：

```python
elif self.difficult_only.isChecked():
    config['mode'] = 'difficult'
    config['value'] = 'difficult'
    # 获取勾选的标签（用于联动）
    checked_labels = []
    for i in range(self.label_list.count()):
        item = self.label_list.item(i)
        if item.checkState() == Qt.Checked:
            checked_labels.append(item.text())
    if checked_labels:
        config['filter_labels'] = checked_labels
```

### 3. 过滤逻辑

在`views/labeling/label_widget.py`的`_file_matches_filter()`方法中添加了困难标记过滤逻辑：

```python
# 困难标记过滤
if mode == 'difficult':
    shapes = data.get("shapes", [])
    filter_labels = filter_config.get('filter_labels', [])
    
    # 如果指定了标签过滤，只检查这些标签的shapes
    if filter_labels:
        target_shapes = [s for s in shapes if s.get("label") in filter_labels]
    else:
        target_shapes = shapes
    
    # 如果没有目标shapes，返回False
    if not target_shapes:
        return False
    
    if value == 'difficult':
        # 仅困难标记：至少有一个目标shape的difficult为true
        return any(s.get("difficult", False) for s in target_shapes)
    elif value == 'not_difficult':
        # 仅非困难标记：至少有一个目标shape的difficult为false
        return any(not s.get("difficult", False) for s in target_shapes)
```

## 使用方法

1. 点击文件列表搜索框旁边的 **⚙** 按钮
2. 在弹出的对话框中找到"困难标记"分组
3. 选择"仅困难标记"或"仅非困难标记"
4. （可选）在下方的标签列表中勾选要过滤的标签
5. 点击"应用"按钮应用过滤

## 注意事项

1. 困难标记过滤只对已标注的文件有效（需要有JSON文件）
2. 如果JSON文件中没有shapes，该文件不会被显示
3. 标签联动是可选的，不勾选标签时会检查所有标签的困难标记
4. 勾选多个标签时，只要任一标签满足条件即可（OR逻辑）
5. 困难标记过滤与其他过滤条件互斥，一次只能选择一种过滤方式

## JSON数据结构示例

```json
{
  "shapes": [
    {
      "label": "balloon",
      "difficult": false,
      "points": [[181.0, 101.0], [246.0, 960.0]],
      "shape_type": "rectangle"
    },
    {
      "label": "balloon",
      "difficult": true,
      "points": [[1589.0, 102.0], [1653.0, 964.0]],
      "shape_type": "rectangle"
    }
  ]
}
```

在这个例子中：
- 第一个balloon标注是非困难标记（difficult: false）
- 第二个balloon标注是困难标记（difficult: true）

如果选择"仅困难标记"并勾选"balloon"标签，这个文件会被显示（因为有一个balloon是困难标记）。
