# 文件过滤功能说明

## 功能概述

在文件列表的搜索框旁边添加了一个过滤按钮（⚙），支持多种过滤条件，帮助用户快速筛选需要的文件。

## 功能特性

### 1. 标注状态过滤
- **全部**：显示所有文件
- **已标注**：只显示有标注文件（.json）的图片
- **未标注**：只显示没有标注文件的图片

### 2. 编辑状态过滤
- **全部**：显示所有文件
- **仅手动编辑**：只显示被手动编辑过的文件（manually_edited标记为true）
- **仅未手动编辑**：只显示未被手动编辑的文件

### 3. 文本内容过滤
- **全部**：显示所有文件
- **包含文本**：只显示标注中包含文本内容的文件
- **不包含文本**：只显示标注中不包含文本的文件

### 4. 标签过滤
- 可以选择一个或多个标签
- 只显示包含选中标签的文件
- 提供"全选"和"全不选"快捷按钮
- 如果不选择任何标签，则显示所有文件

## 使用方法

1. 点击搜索框旁边的 **⚙** 按钮
2. 在弹出的对话框中设置过滤条件
3. 点击"应用"按钮应用过滤
4. 点击"重置"按钮清除所有过滤条件
5. 点击"关闭"按钮关闭对话框

## 组合使用

- 可以同时使用多个过滤条件
- 搜索框和过滤功能可以同时使用
- 过滤条件会在切换文件夹时保持

## 实现文件

- `views/labeling/widgets/file_filter_dialog.py` - 过滤对话框
- `views/labeling/label_widget.py` - 主要逻辑修改
- `resources/images/filter.svg` - 过滤图标（可选）

## 注意事项

1. 过滤功能会读取JSON标注文件，对于大量文件可能需要一些时间
2. 如果标注文件损坏或格式不正确，该文件会被保留在列表中
3. 过滤条件会影响文件列表的显示，但不会删除或修改任何文件
