# 标签转换功能增强说明

## 功能概述

增强了"旋转转水平标签"和"水平转旋转标签"功能，现在用户可以选择性地转换特定标签，而不是一次性转换所有标签。

## 主要改进

### 1. 新增标签选择对话框
- 在执行转换前，会弹出一个对话框显示所有可转换的标签
- 用户可以勾选想要转换的标签，取消勾选不想转换的标签
- 提供"全选"和"取消全选"按钮，方便快速操作
- 默认情况下所有标签都是勾选状态

### 2. 智能标签收集
- 系统会自动扫描所有标注文件，收集符合转换条件的标签
- 只显示相关的标签（例如：水平转旋转时只显示水平矩形的标签）
- 如果没有找到可转换的标签，会提示用户

### 3. 转换确认
- 选择标签后，会显示确认对话框，告知用户将要转换的标签数量
- 用户可以在最后一步取消操作

## 使用方法

### 旋转转水平标签（OBB to HBB）
1. 点击菜单：工具 → Convert OBB to HBB
2. 系统会扫描所有文件，收集旋转框标签
3. 在弹出的对话框中选择要转换的标签
4. 点击"确定"
5. 在确认对话框中再次确认
6. 等待转换完成

### 水平转旋转标签（HBB to OBB）
1. 点击菜单：工具 → Convert HBB to OBB
2. 系统会扫描所有文件，收集水平矩形标签
3. 在弹出的对话框中选择要转换的标签
4. 点击"确定"
5. 在确认对话框中再次确认
6. 等待转换完成

### 多边形转换
同样适用于：
- Polygon to HBB（多边形转水平框）
- Polygon to OBB（多边形转旋转框）

## 使用场景示例

### 场景1：部分标签转换
假设你有以下标签：
- 文字（旋转框）
- 气泡（旋转框）
- 背景（旋转框）

你只想把"文字"和"气泡"转换为水平框，保留"背景"为旋转框：
1. 执行"旋转转水平标签"
2. 在对话框中取消勾选"背景"
3. 确认转换

结果：
- 文字 → 水平框 ✓
- 气泡 → 水平框 ✓
- 背景 → 旋转框（保持不变）✓

### 场景2：测试性转换
你想先测试某个标签的转换效果：
1. 在对话框中只勾选一个标签
2. 转换后查看效果
3. 如果满意，再转换其他标签

## 技术实现

### 新增文件
- `views/labeling/widgets/label_selection_dialog.py` - 标签选择对话框

### 修改文件
- `views/labeling/utils/shape.py` - 增强 `shape_conversion` 函数

### 核心逻辑
1. **标签收集阶段**：遍历所有标注文件，根据转换模式收集符合条件的标签
2. **用户选择阶段**：显示对话框让用户选择要转换的标签
3. **转换执行阶段**：只转换用户选中的标签，其他标签保持不变

### 代码示例

```python
# 在转换时检查标签是否被选中
shape_label = shape.get("label")

# 只转换选中的标签
if shape_label not in selected_labels_set:
    continue  # 跳过未选中的标签

# 执行转换
if mode == "hbb_to_obb" and shape_type == "rectangle":
    shape["shape_type"] = "rotation"
    shape["direction"] = 0
```

## 注意事项

1. **备份数据**：虽然有确认步骤，但建议在大批量转换前备份标注文件
2. **不可撤销**：转换操作会直接修改标注文件，无法通过Ctrl+Z撤销
3. **批量操作**：转换会应用到所有加载的图片文件
4. **标签匹配**：转换基于标签名称的精确匹配

## 优势

✅ **更灵活**：可以选择性转换，不必全部转换  
✅ **更安全**：可以先转换部分标签测试效果  
✅ **更高效**：避免转换后再手动改回某些标签  
✅ **更直观**：清楚地看到哪些标签会被转换  

## 兼容性

- 完全兼容现有的标注文件格式
- 不影响其他功能的使用
- 向后兼容，不会破坏现有数据
