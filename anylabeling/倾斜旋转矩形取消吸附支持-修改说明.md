# 倾斜旋转矩形取消吸附支持 - 修改说明

**修改日期：** 2025-11-09  
**修改原因：** 倾斜旋转矩形的吸附功能支持不好，取消吸附支持，只保留辅助线显示

---

## 📋 修改概述

### 修改前的行为
- ✅ 水平矩形：显示辅助线 + 吸附
- ✅ 旋转矩形（0°/90°/180°/270°）：显示辅助线 + 吸附
- ⚠️ 旋转矩形（倾斜角度）：显示辅助线 + 吸附（但吸附效果不好）

### 修改后的行为
- ✅ 水平矩形：显示辅助线 + 吸附
- ✅ 旋转矩形（0°/90°/180°/270°）：显示辅助线 + 吸附
- ✅ 旋转矩形（倾斜角度）：**只显示辅助线，不吸附**

---

## 🎯 什么是倾斜旋转矩形？

### 水平角度旋转矩形（保留吸附）
```
角度：0°, 90°, 180°, 270° (±5°误差范围)

0°:          90°:        180°:        270°:
┌─────┐      │           ┌─────┐      │
│     │      │           │     │      │
└─────┘      │           └─────┘      │
```

### 倾斜角度旋转矩形（取消吸附）
```
角度：除了 0°/90°/180°/270° 之外的所有角度

45°:         30°:        60°:
  ┌──┐        ┌──┐       ┌──┐
 /    \      /    \     /    \
/      \    /      \   /      \
```

```python
def _detect_edge_snap(self, moving_rects, snap_distance):
    """
    检测边缘吸附（矩形边缘贴边）
    
    注意：倾斜旋转矩形（非0/90/180/270度）不参与边缘吸附
    """
    # ...
    for other_shape in self.shapes:
        if not self.is_visible(other_shape):
            continue

        # 🎯 排除倾斜旋转矩形（非0/90/180/270度）作为吸附目标
        if other_shape.shape_type in ['rotation', 'rotation3']:
            angle_rad = getattr(other_shape, 'direction', 0)
            angle_deg = math.degrees(angle_rad) % 360
            angle_threshold = 5.0
            is_horizontal_angle = (
                abs(angle_deg) < angle_threshold or
                abs(angle_deg - 90) < angle_threshold or
                abs(angle_deg - 180) < angle_threshold or
                abs(angle_deg - 270) < angle_threshold or
                abs(angle_deg - 360) < angle_threshold
            )
            # 如果是倾斜角度，跳过这个形状
            if not is_horizontal_angle:
                continue

        # 检查是否是正在移动的形状
        is_moving = False
        # ...
```

**关键点：**
- 在遍历目标形状时，检查是否为倾斜旋转矩形
- 如果是倾斜角度（非0/90/180/270度），跳过该形状，不作为吸附目标

## 🎯 技术实现

### 角度判断逻辑

```python
# 获取旋转角度（弧度）
angle_rad = getattr(shape, 'direction', 0)

# 转换为度数（0-360）
angle_deg = math.degrees(angle_rad) % 360

# 允许 ±5° 的误差
angle_threshold = 5.0

# 判断是否为水平角度
is_horizontal_angle = (
    abs(angle_deg) < angle_threshold or          # 0°
    abs(angle_deg - 90) < angle_threshold or     # 90°
    abs(angle_deg - 180) < angle_threshold or    # 180°
    abs(angle_deg - 270) < angle_threshold or    # 270°
    abs(angle_deg - 360) < angle_threshold       # 360° (等同于0°)
)

# 倾斜旋转矩形
is_tilted_rotation = not is_horizontal_angle
```

### 双重过滤机制

#### 1. 移动形状过滤
```python
# 在 detect_smart_guides 方法中
if self.edge_snap_enabled and not is_tilted_rotation:
    # 只有非倾斜旋转矩形才调用边缘吸附检测
    edge_snap_offset = self._detect_edge_snap(...)
```

#### 2. 目标形状过滤
```python
# 在 _detect_edge_snap 方法中
for other_shape in self.shapes:
    # 排除倾斜旋转矩形作为吸附目标
    if other_shape.shape_type in ['rotation', 'rotation3']:
        if not is_horizontal_angle:
            continue  # 跳过倾斜角度的矩形
```

## 💡 为什么这样设计？

### 问题分析

1. **倾斜矩形的吸附不准确**
   - 倾斜矩形的边界框（bounding_rect）是水平的
   - 吸附基于边界框，不是实际的倾斜边
   - 导致吸附位置不符合预期

2. **辅助线仍然有用**
   - 倾斜矩形的边对边辅助线可以帮助对齐
   - 显示辅助线不影响性能
   - 用户可以手动对齐，更精确

### 解决方案

- ✅ **保留辅助线**：帮助用户手动对齐
- ❌ **取消吸附**：避免不准确的自动吸附
- ✅ **水平角度例外**：0/90/180/270度的旋转矩形仍然吸附
