# 统计总览搜索功能说明

## 功能概述

统计总览窗口新增了强大的搜索和过滤功能，支持多字段搜索、多种匹配条件、正则表达式、自定义规则保存等功能。

## 界面布局

### 第一行：搜索条件
```
[字段选择▼] [条件选择▼] [搜索输入框] [过滤地址栏]
```

### 第二行：规则管理
```
[保存规则] [已保存规则▼] [删除] [清除]
```

## 功能详解

### 1. 字段选择

可以选择在哪个字段中搜索：

- **文件名** - 在文件名字段搜索
- **标签** - 在标签字段搜索
- **描述** - 在描述字段搜索
- **类型** - 在类型字段搜索（rectangle、polygon等）
- **组ID** - 在组ID字段搜索

### 2. 条件选择

支持7种匹配条件：

- **包含** - 字段包含搜索文本（不区分大小写）
- **等于** - 字段完全等于搜索文本（不区分大小写）
- **不包含** - 字段不包含搜索文本
- **不等于** - 字段不等于搜索文本
- **正则匹配** - 使用正则表达式匹配（不区分大小写）
- **为空** - 字段为空（null、空字符串、{}等）
- **不为空** - 字段有实际内容

### 3. 搜索输入

- **手动输入**：输入搜索内容后按**回车键**执行搜索
- **延迟搜索**：避免输入时卡顿，只有按回车才搜索
- **自动搜索**：选择"为空"或"不为空"条件时自动搜索

### 4. 正则表达式支持

选择"正则匹配"条件后，可以使用正则表达式：

**常用正则示例：**
- `\d+` - 匹配包含数字
- `^\d+$` - 匹配纯数字
- `[\u4e00-\u9fa5]+` - 匹配包含中文
- `[a-zA-Z]+` - 匹配包含英文
- `^$` - 匹配空字符串
- `.+` - 匹配任意非空内容
- `你好|hello` - 匹配"你好"或"hello"

### 5. 过滤地址栏

点击"过滤地址栏"按钮后：
- 主窗口的文件列表会被过滤
- 只显示包含搜索结果的图片文件
- 方便快速定位相关文件

点击"重置"按钮恢复显示所有文件。

### 6. 自定义规则保存

**保存规则：**
1. 设置好字段、条件和搜索内容
2. 点击"保存规则"按钮
3. 输入规则名称（如"查找空描述"）
4. 规则保存到 `~/.anylabeling/overview_search_rules.json`

**使用规则：**
1. 点击"已保存规则"下拉框
2. 选择要使用的规则
3. 规则自动应用并执行搜索

**删除规则：**
1. 从"已保存规则"下拉框选择要删除的规则
2. 点击"删除"按钮
3. 确认删除

### 7. 清除功能

点击"清除"按钮会：
- 清空搜索输入框
- 重置字段和条件选择
- 重置已保存规则选择
- 恢复显示所有数据

## 性能优化

- **延迟搜索**：输入时不会立即搜索，避免卡顿
- **按需搜索**：只有按回车或选择规则时才执行搜索
- **范围限制**：可以配合"从X到X"范围选择，减少搜索数据量

## 数据持久化

- 自定义规则保存在：`~/.anylabeling/overview_search_rules.json`
- 规则在不同项目间共享
- 可以手动编辑JSON文件管理规则

## 注意事项

1. 搜索功能只在**Shape视图**下可用（切换到Shape标签页）
2. 正则表达式必须选择"正则匹配"条件才生效
3. "为空"判断包括：null、空字符串、"None"、"{}"等
4. 搜索不区分大小写（除非使用特定的正则表达式）
5. 过滤地址栏后，需要点击"重置"按钮才能恢复显示所有文件

## 快捷操作

- **回车键** - 执行搜索
- **清除按钮** - 快速清除所有搜索条件
- **保存规则** - 保存常用搜索条件，下次直接使用
- **过滤地址栏** - 快速定位相关文件

## 技术实现

- 使用Python正则表达式引擎（re模块）
- 支持Unicode字符（中文、日文等）
- 延迟搜索机制避免频繁刷新
- 规则持久化使用JSON格式存储
