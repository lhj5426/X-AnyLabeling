# SHIFT+右键路径线隐藏偶数图形功能

## 功能概述

按住 **SHIFT + 鼠标右键** 拖动绘制红色路径线，路径线穿过的图形按穿过顺序编号，释放鼠标后自动隐藏偶数位置（2, 4, 6...）的图形。

## 使用场景

- 快速隐藏交替排列、重叠的图形
- 分批处理密集标注，避免互相干扰
- 配合反选功能实现高效的分组编辑

## 操作方式

### 基本操作
1. 按住 **SHIFT** 键
2. 按住 **鼠标右键** 并拖动
3. 红色路径线穿过目标图形
4. 释放鼠标右键完成操作

### 取消操作
- 拖动过程中释放 **SHIFT** 键可取消操作

## 视觉反馈

| 元素 | 颜色 | 说明 |
|------|------|------|
| 路径线 | 红色 | 当前绘制的路径 |
| 奇数位置图形 | 绿色高亮 + 数字 | 1, 3, 5... 保持显示 |
| 偶数位置图形 | 红色高亮 + 数字 | 2, 4, 6... 将被隐藏 |

## 特性说明

### 排序规则
- 按路径线**实际穿过的空间顺序**编号
- 不是按标签列表顺序

### 锁定图形
- 被锁定的图形不参与路径线检测和计数
- 锁定图形不会被隐藏

### 联动功能
- 隐藏的图形在右侧标签列表中自动取消勾选
- 可通过 `show_hidden_polygons` 功能逐个恢复
- 可通过反选功能批量切换显示/隐藏状态

## 推荐工作流

1. **SHIFT+右键** 划过重叠的图形 → 隐藏偶数位置
2. 调整显示的图形（1, 3, 5...）
3. 点击 **反选** 按钮 → 切换显示/隐藏
4. 调整之前隐藏的图形（2, 4, 6...）
5. 再次 **反选** 或 **全选** 恢复全部显示

## 快捷键对比

| 功能 | 快捷键 | 路径颜色 | 作用 |
|------|--------|----------|------|
| 路径选择 | SHIFT+左键 | 蓝色 | 选中穿过的所有图形 |
| 隐藏偶数图形 | SHIFT+右键 | 红色 | 隐藏穿过的偶数位置图形 |
| 框选 | ALT+左键 | 蓝色框 | 选中框内的所有图形 |

## 代码实现位置

### canvas.py

| 功能 | 位置 | 说明 |
|------|------|------|
| 信号定义 | `hide_shapes_requested` | 请求隐藏图形的信号 |
| 状态变量 | `ctrl_path_selection_mode` 等 | 路径选择模式状态 |
| 鼠标按下 | `mousePressEvent` | 检测 SHIFT+右键启动模式 |
| 鼠标移动 | `mouseMoveEvent` | 记录路径点，更新交叉检测 |
| 鼠标释放 | `mouseReleaseEvent` | 完成选择，发送隐藏信号 |
| 键盘释放 | `keyReleaseEvent` | SHIFT键释放时取消模式 |
| 交叉检测 | `update_ctrl_path_intersections` | 计算路径与图形的交点，按距离排序 |
| 绘制 | `draw_ctrl_path_selection` | 绘制红色路径线和编号 |

### label_widget.py

| 功能 | 位置 | 说明 |
|------|------|------|
| 信号连接 | `__init__` | 连接 `hide_shapes_requested` 信号 |
| 隐藏处理 | `hide_shapes_by_path` | 隐藏图形并更新标签列表勾选状态 |
