# 锁定困难标记功能 - 实现文档

## 功能概述

在"高亮与锁定设置"的"标签锁定"功能中新增"锁定困难标记"复选框，启用后，所有被标记为困难（difficult: true）的标注都会被自动锁定，无论其标签是什么。

## 功能特性

### 1. 锁定困难标记

- **功能位置：** 工具 → 高亮与锁定设置 → 标签锁定
- **复选框名称：** "锁定困难标记"
- **功能说明：** 启用后，所有标记为困难（difficult: true）的标注都会被锁定

### 2. 锁定逻辑

锁定判断的优先级：
1. **会话解锁优先：** 如果标注被会话解锁（is_session_unlocked: true），则不锁定
2. **困难标记锁定：** 如果启用了"锁定困难标记"且标注的difficult为true，则锁定
3. **标签锁定：** 如果标注的标签在锁定标签列表中，则锁定

### 3. 与标签锁定的关系

- **独立功能：** 困难标记锁定与标签锁定是独立的
- **可以共存：** 可以同时启用困难标记锁定和标签锁定
- **统一行为：** 锁定后的行为（是否可高亮、是否显示宽高等）对两种锁定方式都生效

## 使用场景

### 场景1：保护困难标注

**需求：** 困难标注通常比较复杂，不希望被误操作修改

**操作：**
1. 打开"工具" → "高亮与锁定设置"
2. 在"标签锁定"组中勾选"锁定困难标记"
3. 所有difficult: true的标注都会被锁定
4. 无法移动、调整大小或删除这些标注

### 场景2：混合锁定

**需求：** 既要锁定特定标签（如"other"），又要锁定所有困难标注

**操作：**
1. 在"需要锁定的标签"输入框中填写：`other`
2. 勾选"锁定困难标记"
3. 结果：
   - 所有"other"标签的标注被锁定
   - 所有difficult: true的标注被锁定
   - 其他标注不受影响

### 场景3：临时解锁困难标注

**需求：** 需要修改某个困难标注，但不想取消全局的困难标记锁定

**操作：**
1. 按住Ctrl键点击该困难标注
2. 标注被会话解锁（is_session_unlocked: true）
3. 可以正常编辑该标注
4. 其他困难标注仍然保持锁定

## 实现细节

### 1. UI修改

在 `views/labeling/widgets/highlight_settings_dialog.py` 中添加复选框：

```python
self.lock_difficult_checkbox = QtWidgets.QCheckBox("锁定困难标记")
self.lock_difficult_checkbox.setToolTip("启用后，所有标记为困难（difficult: true）的标注都会被锁定")
```

### 2. Shape类修改

在 `views/labeling/shape.py` 中：

#### 添加类变量

```python
class Shape:
    # ...
    locked_labels = set()  # 锁定的标签集合
    lock_difficult = False  # 锁定困难标记（新增）
```

#### 修改is_label_locked()方法

```python
def is_label_locked(self):
    """检查当前 shape 的标签是否在锁定列表中，或者是否为困难标记且启用了锁定困难标记
    注意：如果 shape 已被会话解锁（is_session_unlocked=True），则不视为锁定
    """
    # 如果已被会话解锁，则不视为锁定
    if getattr(self, "is_session_unlocked", False):
        return False
    
    # 检查是否启用了锁定困难标记，且当前shape是困难标记
    if Shape.lock_difficult and getattr(self, "difficult", False):
        return True
    
    # 检查标签是否在锁定列表中
    if self.label and Shape.locked_labels:
        return self.label.strip() in Shape.locked_labels
    
    return False
```

### 3. 配置加载

在 `views/labeling/label_widget.py` 中加载配置：

```python
Shape.lock_difficult = self._config.get("lock_difficult", False)
```

### 4. 配置保存

在 `highlight_settings_dialog.py` 的 `_realtime_save_settings()` 方法中：

```python
self._config["lock_difficult"] = self.lock_difficult_checkbox.isChecked()
```

## 锁定效果

当标注被锁定后（无论是通过标签锁定还是困难标记锁定）：

1. **不可移动：** 无法拖动标注
2. **不可调整：** 无法调整标注的大小和形状
3. **不可删除：** 无法删除标注（需要先解锁）
4. **显示锁定灯：** 在标签列表中显示黄色锁定信号灯
5. **可选行为：** 根据设置决定是否可高亮、是否显示宽高等

## 解锁方式

### 1. 全局解锁

取消"锁定困难标记"复选框，所有困难标注的锁定状态解除。

### 2. 会话解锁

按住Ctrl键点击锁定的标注，该标注在当前会话中被临时解锁：
- 可以正常编辑
- 显示蓝色解锁信号灯
- 关闭程序后会话解锁状态不保存

### 3. 取消困难标记

在标注属性中取消"困难标志"勾选，该标注不再被困难标记锁定。

## 配置文件格式

```yaml
# 高亮与锁定设置
locked_labels: "other,background"  # 锁定的标签
lock_difficult: true  # 锁定困难标记
locked_can_highlight: false  # 锁定后是否可高亮
locked_hide_info: false  # 锁定后是否隐藏宽高和角度
locked_hide_order: true  # 锁定后是否隐藏序号
locked_show_point: false  # 锁定后是否显示点
locked_show_square: false  # 锁定后是否显示块
```

## 与其他功能的配合

### 1. 与困难标记信号灯配合

- 困难标记灯（紫色）显示标注是困难的
- 锁定灯（黄色）显示标注被锁定
- 如果启用了"锁定困难标记"，困难标注会同时显示紫色和黄色灯

### 2. 与困难标记过滤配合

- 使用"仅困难标记"过滤筛选出困难标注
- 启用"锁定困难标记"保护这些标注不被误操作

### 3. 与高亮功能配合

- 如果勾选了"锁定后仍可高亮"，困难标注可以参与高亮
- 否则困难标注不会被高亮

## 注意事项

1. **优先级：** 会话解锁优先级最高，即使启用了困难标记锁定，会话解锁的标注仍然可以编辑

2. **实时生效：** 勾选或取消"锁定困难标记"后立即生效，无需重启

3. **不影响新标注：** 新创建的标注默认difficult为false，不会被锁定

4. **批量操作：** 可以使用"清除全部困难标记"功能批量解除困难标记，从而解除锁定

5. **兼容性：** 与现有的标签锁定功能完全兼容，可以同时使用
