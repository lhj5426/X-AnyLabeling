# ALT+右键删除线功能

## 功能概述

按住 **ALT + 鼠标右键** 拖动绘制绿色路径线，路径线穿过的图形会被标记，释放鼠标后自动删除所有穿过的图形。

## 使用场景

- 快速批量删除多个图形
- 清理错误的标注
- 删除不需要的重叠标注

## 操作方式

### 基本操作
1. 按住 **ALT** 键
2. 按住 **鼠标右键** 并拖动
3. 绿色路径线穿过目标图形
4. 释放鼠标右键完成删除

### 取消操作
- 拖动过程中释放 **ALT** 键可取消操作

## 视觉反馈

| 元素 | 颜色 | 说明 |
|------|------|------|
| 路径线 | 绿色 | 当前绘制的路径 |
| 穿过的图形 | 红色高亮 | 将被删除的图形 |
| 中心标记 | 红色圆圈 + "删"字 | 表示该图形将被删除 |

## 特性说明

### 锁定图形
- 被锁定的图形不参与路径线检测
- 锁定图形不会被删除

### 联动功能
- 删除的图形会从画布和右侧标签列表中同时移除
- 操作后自动标记文件为已修改状态

## 路径线工具对比

| 功能 | 快捷键 | 路径颜色 | 中心标记 | 作用 |
|------|--------|----------|----------|------|
| 路径选择 | SHIFT+左键 | 蓝色 | - | 选中穿过的所有图形 |
| 隐藏偶数图形 | SHIFT+右键 | 红色 | 数字 | 隐藏穿过的偶数位置图形 |
| 删除图形 | ALT+右键 | 绿色 | "删" | 删除穿过的所有图形 |

## 代码实现位置

### canvas.py

| 功能 | 说明 |
|------|------|
| `delete_shapes_requested` 信号 | 请求删除图形的信号 |
| `delete_path_selection_mode` | 删除路径选择模式状态 |
| `delete_path_selection_points` | 路径点列表 |
| `delete_path_intersected_shapes` | 穿过的图形列表 |
| `update_delete_path_intersections()` | 更新穿过的图形列表 |
| `complete_delete_path_selection()` | 完成删除操作 |
| `draw_delete_path_selection()` | 绘制绿色路径线和标记 |

### label_widget.py

| 功能 | 说明 |
|------|------|
| 信号连接 | `delete_shapes_requested` → `delete_shapes_by_path` |
| `delete_shapes_by_path()` | 从画布和标签列表中删除图形 |
