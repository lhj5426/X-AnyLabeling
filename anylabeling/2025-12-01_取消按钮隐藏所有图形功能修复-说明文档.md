# 取消按钮隐藏所有图形功能修复

## 问题描述

原来的"取消"按钮存在逻辑问题：

1. 第一次点击"取消" → 所有图形被隐藏 ✓
2. 标注一个新图形（新图形自动显示并勾选）
3. 再次点击"取消" → 新图形没有被隐藏 ✗

用户需要先点"全选"再点"取消"才能隐藏新图形，操作繁琐。

## 修复内容

修改了两个取消功能，确保能隐藏所有图形（包括新创建的）：

### 1. 标签列表区的取消按钮（ALT+W）

位置：`views/labeling/label_widget.py` 约第 6695 行

```python
def deselect_all_labels():
    # 取消标签列表的勾选
    for i in range(self.unique_label_list.count()):
        item = self.unique_label_list.item(i)
        item.setCheckState(Qt.Unchecked)
    # 同时取消对象列表的勾选
    for item in self.label_list:
        item.setCheckState(Qt.Unchecked)
    # 确保canvas.shapes中的所有图形都被隐藏
    for shape in self.canvas.shapes:
        shape.visible = False
    self.canvas.update()
    self.update_navigator_shapes()
```

### 2. 对象列表区的取消按钮（ALT+S）

位置：`views/labeling/label_widget.py` 约第 475 行

```python
def deselect_all_objects():
    # 遍历label_list中的所有item并取消勾选
    for item in self.label_list:
        item.setCheckState(Qt.Unchecked)
    # 确保canvas.shapes中的所有图形都被隐藏
    for shape in self.canvas.shapes:
        shape.visible = False
    self.canvas.update()
    self.update_navigator_shapes()
```

## 修复原理

原来的代码只遍历 `label_list` 并取消勾选，但可能存在同步问题导致新创建的图形没有被正确处理。

修复后增加了直接遍历 `canvas.shapes` 并设置 `visible = False` 的逻辑，确保所有图形都被隐藏。

## 快捷键

| 快捷键 | 按钮位置 | 功能 |
|--------|----------|------|
| ALT+W | 标签列表区 | 隐藏所有图形 |
| ALT+S | 对象列表区 | 隐藏所有图形 |

## 推荐工作流

1. **ALT+W** 或 **ALT+S** → 隐藏所有图形，获得干净画布
2. 标注新图形
3. **ALT+W** 或 **ALT+S** → 直接隐藏新图形
4. 继续标注下一个
5. 完成后点"全选"恢复所有图形显示
