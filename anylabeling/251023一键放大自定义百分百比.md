# 251015 - 一键放大自定义百分比功能 - 实现文档

## 1. 功能概述

此功能允许用户通过一个自定义快捷键，在鼠标当前位置对画布进行放大操作。每次放大的增量为固定百分比，该百分比可在配置文件中自定义。

## 2. 配置项 (xanylabeling_config.yaml)

在 `xanylabeling_config.yaml` 文件中，新增了以下配置项：

*   `zoom_at_mouse_percentage_increase`: 20
    *   说明：鼠标位置放大时，每次增加的缩放百分比。例如，设置为 20，则每次在当前缩放值基础上增加 20%。
    *   默认值：20
*   `zoom_at_mouse_shortcut`: Ctrl+B
    *   说明：触发鼠标位置放大功能的快捷键。
    *   默认值：Ctrl+B

**注意：** 为避免快捷键冲突，`open_chatbot` 的默认快捷键已从 `Ctrl+B` 修改为 `null`。

用户可以通过修改 `~/.YSGxanylabelingrc` 文件来覆盖这些默认配置。

## 3. 核心代码修改

### 3.1. `label_widget.py`

*   **新增方法 `zoom_at_mouse_shortcut_triggered(self)`**:
    *   获取鼠标在画布上的当前精确位置。
    *   从配置中读取 `zoom_at_mouse_percentage_increase`。
    *   计算新的缩放值（当前缩放值 + `zoom_at_mouse_percentage_increase`）。
    *   调用 `self.set_zoom()` 方法应用新的缩放值。
    *   根据鼠标位置和缩放比例，精确调整画布的滚动条位置，确保放大操作以鼠标为中心。
*   **UI 集成**:
    *   创建了一个 `QAction` 来绑定 `zoom_at_mouse_shortcut_triggered` 方法和 `zoom_at_mouse_shortcut`。
    *   该 `QAction` 被添加到 `self.actions` 结构体和 `self.actions.zoom_actions` 列表中，以确保其生命周期管理和启用/禁用状态正确。
    *   **重要提示：** 此功能没有对应的菜单项。它仅通过快捷键触发，以避免鼠标移动到菜单时丢失焦点位置。
    *   通过 `self.addAction(QAction)` 将快捷键显式注册到主窗口，确保其能够被系统识别和触发。

## 4. 验证

*   **功能验证**: 启动应用程序，加载图像，将鼠标悬停在画布上任意位置，按下 `Ctrl+B` 快捷键。验证画布是否以鼠标位置为中心放大，并且每次放大都是固定的百分比（例如，100% -> 120% -> 140%）。
*   **配置验证**: 检查 `~/.YSGxanylabelingrc` 文件中是否包含 `zoom_at_mouse_percentage_increase` 和 `zoom_at_mouse_shortcut` 配置项。

## 5. 修复说明 (251023)

*   **问题**: 初始版本中，以鼠标为中心的缩放功能存在定位不准的问题。
*   **修复**:
    *   修正了 `zoom_at_mouse_shortcut_triggered` 方法中对鼠标位置的计算逻辑，确保了以鼠标指针为中心的精确缩放。
    *   改进了当鼠标指针不在画布上时触发快捷键的缩放行为，使其以当前可见区域的中心点进行缩放。
