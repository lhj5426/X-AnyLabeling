# 间距线颜色和透明度移至颜色管理器

## 功能概述

将间距线的颜色和透明度设置从**辅助线菜单**移动到**颜色管理器**，并统一透明度的输入方式为数值输入框（0.0-1.0）。

## 实现细节

### 1. 颜色管理器修改 (`views/labeling/widgets/color_manager_dialog.py`)

#### 新增设置项：
在"矩形间距线样式设置"部分添加了三个新的控件：

1. **间距线线条颜色** - 颜色选择按钮
   - 配置键：`spacing_guide_line_color`
   - 默认值：`[0, 255, 255]`（青色）

2. **间距线线条粗细** - 数值输入框
   - 配置键：`spacing_guide_line_width`
   - 范围：0.5 - 10.0
   - 步长：0.5
   - 默认值：2.0

3. **间距线透明度** - 数值输入框
   - 配置键：`spacing_guide_opacity`
   - 范围：0.0 - 1.0
   - 步长：0.1
   - 默认值：0.8

### 2. 辅助线菜单修改 (`views/labeling/widgets/smart_guides_dialog.py`)

#### 删除的内容：
- ✅ 删除了间距线颜色选择按钮和颜色显示标签
- ✅ 删除了间距线透明度滑块和百分比标签
- ✅ 删除了 `_on_spacing_color_clicked()` 方法
- ✅ 删除了 `_on_spacing_opacity_changed()` 方法
- ✅ 删除了 `_on_setting_changed()` 中关于 `spacing_guide_line_color` 和 `spacing_guide_opacity` 的处理

#### 保留的内容：
- ✅ 间距线启用/禁用复选框
- ✅ 仅对选中矩形测距复选框
- ✅ 显示距离设置
- ✅ 最多检测矩形数设置

### 3. 主窗口修改 (`views/labeling/label_widget.py`)

#### 新增处理：
在 `update_single_setting()` 方法中添加了对间距线设置的处理：

```python
elif key == 'spacing_guide_line_color':
    # 间距线线条颜色
    self.canvas.spacing_guide_line_color = value if isinstance(value, list) else [color.red(), color.green(), color.blue()]
elif key == 'spacing_guide_line_width':
    # 间距线线条粗细
    self.canvas.spacing_guide_line_width = value
elif key == 'spacing_guide_opacity':
    # 间距线透明度
    self.canvas.spacing_guide_opacity = value
```

## 使用方式

### 修改间距线颜色和透明度：

1. 打开**颜色管理器**（菜单 → 颜色管理器）
2. 在右列找到"矩形间距线样式设置"部分
3. 修改以下设置：
   - **间距线线条颜色**：点击颜色按钮选择颜色
   - **间距线线条粗细**：输入 0.5-10.0 之间的数值
   - **间距线透明度**：输入 0.0-1.0 之间的数值（0.0 = 完全透明，1.0 = 完全不透明）

## 配置文件

配置项在 `configs/xanylabeling_config.yaml` 中：

```yaml
# Rectangle spacing guide (矩形间距线)
spacing_guide_enabled: true
spacing_guide_selected_only: false
spacing_guide_line_width: 2.0
spacing_guide_line_color: [0, 255, 255]  # 青色
spacing_guide_opacity: 0.8
spacing_guide_display_distance: 200
spacing_guide_snap_distance: 10
spacing_guide_max_shapes: 0
```
