**修复日期**：2025-10-01

## 📋 问题概述

### 问题描述

当用户开启十字线功能并调整透明度后，Shift+拖动路径选择模式下的矩形高亮边框会**继承十字线的透明度设置**，导致边框变透明或变细，影响可见性。

### 问题表现

- **未开启十字线时**：Shift 路径选择穿过矩形，边框显示为**粗的、不透明的青色线条**（正确）
- **开启十字线后**：Shift 路径选择穿过矩形，边框变成**半透明或细线条**（bug）

### 影响范围

- 仅影响 Shift+拖动路径选择功能的视觉效果
- 不影响功能逻辑，只是显示问题

```
  ↓

  ↓
3. 【没有恢复状态】
  ↓
4. 绘制 Shift 路径选择 → 继承了步骤2的透明度设置 ❌
  ↓
5. 其他绘制...
```

## 🔧 修复方案

### 解决方法

使用 PyQt5 的 `p.save()` 和 `p.restore()` 方法**隔离十字线的绘图状态**，防止透明度设置影响后续绘制。

**修改行号**：
- 第 2651 行：添加 `p.save()`
- 第 2746 行：添加 `p.restore()`

## 🎨 技术细节

### QPainter 状态管理

#### save() 方法
```python
p.save()
```
- **作用**：保存当前绘图状态到栈中
- **保存内容**：画笔、画刷、字体、变换矩阵、裁剪区域、**透明度**等

#### restore() 方法
```python
p.restore()
```
- **作用**：从栈中恢复之前保存的绘图状态
- **效果**：恢复到 `save()` 时的状态

### 状态隔离原理

```python
# 原始状态（透明度 = 1.0）
p.save()                        # 保存状态（透明度 = 1.0）
    p.setOpacity(0.5)          # 修改透明度 = 0.5
    # 绘制十字线（使用透明度 0.5）
p.restore()                     # 恢复状态（透明度 = 1.0）

# 后续绘制使用透明度 1.0，不受影响 ✓
```

### 为什么需要隔离

**QPainter 的状态是持久的**：
- 一旦设置 `p.setOpacity(0.5)`，后续所有绘制都使用这个透明度
- 除非显式修改或恢复状态
- 这就是为什么 Shift 路径选择会继承十字线透明度的原因

## 💡 最佳实践

### QPainter 状态管理规范

**推荐做法**：
```python
# 当需要临时修改绘图状态时
p.save()                    # 1. 保存状态
    p.setOpacity(0.5)      # 2. 修改状态
    p.setPen(custom_pen)   # 3. 修改其他状态
    # 4. 执行绘制
    p.drawLine(...)
p.restore()                 # 5. 恢复状态
```

**适用场景**：
- 临时修改透明度
- 临时修改变换矩阵（旋转、缩放、平移）
- 临时修改裁剪区域
- 临时修改合成模式

### 避免状态泄漏

**❌ 错误示例**：
```python
def draw_something(p):
    p.setOpacity(0.5)
    p.drawRect(...)
    # 忘记恢复状态！
    # 后续所有绘制都会是半透明的
```

**✅ 正确示例**：
```python
def draw_something(p):
    p.save()
    p.setOpacity(0.5)
    p.drawRect(...)
    p.restore()
    # 状态已恢复，不影响后续绘制
```

## 💡 常见问题 (FAQ)

### Q1：为什么十字线会影响其他绘制？

**A1**：
QPainter 的状态（如透明度、画笔、画刷）是**持久的**。一旦设置，会影响后续所有绘制操作，直到被修改或恢复。

### Q2：save() 和 restore() 有性能开销吗？

**A2**：
开销极小，可以忽略不计。这是 Qt 推荐的标准做法。

### Q3：是否需要在所有绘制代码中使用 save()/restore()？

**A3**：
不需要。只在需要**临时修改状态**且**不想影响后续绘制**时使用。

### Q4：可以嵌套使用 save()/restore() 吗？

**A4**：
可以。Qt 使用栈结构管理状态，支持多层嵌套。

### Q5：除了透明度，还有哪些状态需要注意？

**A5**：
- 透明度（opacity）
- 变换矩阵（transform）
- 裁剪区域（clip region）
- 合成模式（composition mode）
- 画笔（pen）
- 画刷（brush）
- 字体（font）
