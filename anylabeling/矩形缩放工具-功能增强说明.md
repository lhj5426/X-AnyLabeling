## 🎉 新增功能

### 1. ✅ 缩放范围选择

现在可以选择缩放的范围：

#### 📄 仅当前页面（默认）
- 只缩放当前打开的图像的标注
- 速度快，适合单个文件调整
- 可以立即看到效果

#### 📚 全部页面
- 缩放文件夹中所有图像的标注
- 批量处理，节省时间
- 自动保存每个文件
- 显示处理进度

### 2. ✅ 矩形选择模式

可以选择要缩放的矩形：

#### 🔲 所有矩形（默认）
- 缩放当前页面/全部页面的所有矩形
- 适合整体调整

#### ☑️ 仅选中的矩形
- 只缩放当前选中的矩形
- 适合精确调整特定区域
- **注意**：全部页面模式不支持此选项

### 3. ✅ 日志显示系统

**去掉了弹窗提示**，改为在界面上显示实时日志：

#### 日志特点
- 📝 实时显示操作过程
- 🎨 彩色日志，易于区分
- ⏰ 带时间戳
- 📊 显示详细统计信息
- 🔄 自动滚动到最新日志

#### 日志级别
- ℹ️ **信息**（蓝色）：普通操作信息
- ⚠️ **警告**（橙色）：需要注意的情况
- ❌ **错误**（红色）：操作失败
- ✅ **成功**（绿色）：操作成功完成

## 📖 使用示例

### 示例1：缩放当前页面的所有矩形

1. 打开工具：**工具 → 矩形缩放工具**
2. 输入缩放比例：`1.3333` 或点击 **1920→2560**
3. 选择：
   - 缩放中心：**图像中心**
   - 缩放范围：**仅当前页面** ✓
   - 矩形选择：**所有矩形** ✓
4. 点击：**应用缩放**
5. 查看日志：
   ```
   [11:30:25] 🚀 开始缩放，比例：1.3333
   [11:30:25] ✅ 当前页面缩放完成！缩放了 4 个矩形，比例: 1.3333
   ```

### 示例2：只缩放选中的矩形

1. 在画布上选中要缩放的矩形（按住 Ctrl 多选）
2. 打开工具：**工具 → 矩形缩放工具**
3. 输入缩放比例：`1.5`
4. 选择：
   - 缩放范围：**仅当前页面** ✓
   - 矩形选择：**仅选中的矩形** ✓
5. 点击：**应用缩放**
6. 查看日志：
   ```
   [11:32:10] 🚀 开始缩放，比例：1.5000
   [11:32:10] ✅ 当前页面缩放完成！缩放了 2 个矩形，比例: 1.5000
   ```

### 示例3：批量缩放全部页面

1. 打开工具：**工具 → 矩形缩放工具**
2. 点击快捷按钮：**1920→2560**
3. 选择：
   - 缩放范围：**全部页面** ✓
   - 矩形选择：**所有矩形** ✓
4. 点击：**应用缩放**
5. 查看日志（实时更新）：
   ```
   [11:35:00] 🔄 开始批量缩放，共 10 个文件...
   [11:35:01]   [1/10] 0001.jpg: 3 个矩形
   [11:35:02]   [2/10] 0002.jpg: 5 个矩形
   [11:35:03]   [3/10] 0003.jpg: 4 个矩形
   ...
   [11:35:10] ✅ 批量缩放完成！处理了 10 个文件，共 42 个矩形，比例: 1.3333
   ```

## 💡 使用技巧

### 技巧1：先测试单页，再批量处理

1. 先选择"仅当前页面"测试缩放效果
2. 如果效果满意，再选择"全部页面"批量处理
3. 这样可以避免批量处理后发现比例不对

### 技巧2：使用日志监控进度

- 批量处理时，日志会实时显示进度
- 可以看到每个文件处理的矩形数量
- 如果某个文件没有矩形，会自动跳过

### 技巧3：精确调整特定区域

1. 选中需要调整的矩形
2. 选择"仅选中的矩形"
3. 应用缩放
4. 其他矩形不受影响

### 技巧4：清空日志保持界面整洁

- 日志太多时，点击"清空日志"按钮
- 开始新的操作前清空日志，便于查看

## ⚠️ 注意事项

### 1. 全部页面模式

- ⚠️ 会自动保存所有修改的文件
- ⚠️ 建议先备份数据
- ⚠️ 处理大量文件时需要等待
- ⚠️ 不支持"仅选中的矩形"选项

### 2. 仅选中的矩形

- ⚠️ 需要先在画布上选中矩形
- ⚠️ 如果没有选中，会显示警告
- ⚠️ 只在"仅当前页面"模式下可用

### 3. 日志显示

- ℹ️ 日志会自动滚动到最新内容
- ℹ️ 可以随时清空日志
- ℹ️ 日志不会保存到文件
