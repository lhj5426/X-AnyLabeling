# 瀑布流缩略图困难标记显示 - 实现文档

## 功能概述

在瀑布流缩略图查看器的悬浮显示中添加困难标记信息，当鼠标悬停在缩略图上时，会显示该图片中包含的困难标记数量。

## 功能特性

### 1. 困难标记统计

在缩略图悬浮信息中显示困难标记的数量。

**显示格式：**
```
[困难标记: 3]
```

**显示颜色：** 紫色 (RGB: 128, 0, 128) - 与困难标记信号灯颜色一致

### 2. 显示位置

困难标记信息显示在悬浮窗口中，位于：
- 文件基本信息（大小、分辨率、日期、文件名）之后
- [已编辑] 标记之后（如果有）
- 标签统计信息之前

### 3. 显示条件

只有当图片中包含困难标记（difficult: true）时才显示，如果没有困难标记则不显示该行。

## 实现细节

### 1. 数据统计

在 `_check_manually_edited()` 方法中添加困难标记统计：

```python
def _check_manually_edited(self):
    json_path = os.path.splitext(self.image_path)[0] + ".json"
    self.label_stats = {}  # 标签统计
    self.total_labels = 0  # 总标签数
    self.difficult_count = 0  # 困难标记数量（新增）
    if os.path.exists(json_path):
        try:
            with open(json_path, 'r', encoding='utf-8') as f:
                data = json.load(f)
                self.is_manually_edited = data.get("manually_edited", False)
                # 统计标签和困难标记
                shapes = data.get("shapes", [])
                for shape in shapes:
                    label = shape.get("label", "unknown")
                    self.label_stats[label] = self.label_stats.get(label, 0) + 1
                    # 统计困难标记
                    if shape.get("difficult", False):
                        self.difficult_count += 1
                self.total_labels = len(shapes)
        except Exception:
            pass
```

### 3. 颜色配置获取

在 `MasonryThumbnailDialog` 类中添加获取困难标记颜色的方法：

```python
def _get_difficult_color(self):
    """获取困难标记颜色配置"""
    default_color = [128, 0, 128]  # 默认紫色
    if self.labeling_widget and hasattr(self.labeling_widget, '_config'):
        traffic_light_colors = self.labeling_widget._config.get("traffic_light_colors", {})
        color_value = traffic_light_colors.get("difficult", default_color)
        if isinstance(color_value, list):
            # RGB列表格式
            return QtGui.QColor(*color_value[:3])
        else:
            return QtGui.QColor(color_value)
    return QtGui.QColor(*default_color)
```

def update_difficult_color(self):
    """更新困难标记颜色（当红绿灯设置修改颜色时调用）"""
    new_color = self._get_difficult_color().name()
    for item in self.masonry_widget.items:

## 使用场景

### 场景1：快速识别困难标注

**需求：** 在浏览缩略图时，快速找到包含困难标记的图片

**操作：**
1. 打开瀑布流缩略图查看器
2. 鼠标悬停在缩略图上
3. 查看悬浮信息中的 `[困难标记: X]` 提示
4. 紫色文字表示有困难标记

### 场景2：统计困难标记数量

**需求：** 了解某张图片中有多少个困难标记

**操作：**
1. 在缩略图上悬停
2. 查看 `[困难标记: 3]` 显示
3. 数字表示该图片中有3个标注被标记为困难

### 场景3：配合过滤功能使用

**需求：** 先用过滤功能筛选困难标记，再在缩略图中查看详情

**操作：**
1. 使用文件过滤选择"仅困难标记"
2. 打开瀑布流缩略图查看器
3. 悬停查看每张图片的困难标记数量
4. 点击图片进行编辑

## 颜色说明

### 困难标记颜色

困难标记的颜色**跟随红绿灯设置中的配置**：

- **默认颜色：** 紫色 (RGB: 128, 0, 128)
- **配置路径：** `traffic_light_colors.difficult`
- **可自定义：** 在红绿灯设置窗口中修改"困难标记"颜色
- **实时更新：** 修改颜色后，缩略图悬浮显示会自动更新

**如何自定义颜色：**
1. 打开"工具" → "红绿灯设置"
2. 找到"困难标记"颜色按钮
3. 点击选择新颜色
4. 瀑布流缩略图中的困难标记显示会自动使用新颜色

### 其他颜色

- **已编辑标记：** 橙色（可在颜色管理器中自定义）
- **总标签数：** 浅蓝色 (100, 200, 255)
- **标签统计：** 根据标签颜色配置显示

## 注意事项

1. **性能考虑**
   - 困难标记统计在加载JSON文件时一次性完成
   - 不会影响缩略图加载性能
   - 悬浮显示时直接使用已统计的数据

2. **显示逻辑**
   - 只有当 `difficult_count > 0` 时才显示
   - 避免在没有困难标记时显示 `[困难标记: 0]`
   - 保持界面简洁

3. **颜色一致性**
   - 使用与困难标记信号灯相同的颜色配置
   - 从 `traffic_light_colors.difficult` 读取
   - 确保视觉上的统一性
   - 便于用户识别
   - 支持自定义颜色

4. **布局优化**
   - 困难标记信息占用一行
   - 不影响标签统计的显示
   - 自动调整行高
