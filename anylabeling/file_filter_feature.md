# 文件过滤功能说明

## 功能概述

在文件列表的搜索框旁边添加了一个过滤按钮（漏斗图标），点击后可以打开文件过滤对话框，支持多种互斥的过滤条件。

## 过滤模式

所有过滤条件是**互斥**的，一次只能选择一种过滤方式：

### 1. 无过滤
- **显示全部**：显示所有文件（默认）

### 2. 标注状态过滤
- **已标注**：只显示有标注文件（.json）的图片
- **未标注**：只显示没有标注文件的图片

### 3. 编辑状态过滤
- **仅手动编辑**：只显示标注文件中标记为"manually_edited"的图片
- **仅未手动编辑**：只显示标注文件中未标记为"manually_edited"的图片

### 4. 文本内容过滤
- **包含文本**：只显示标注中包含文本标签或描述的图片
- **不包含文本**：只显示标注中不包含文本的图片

### 5. 标签过滤
- **按标签过滤**：根据选中的标签过滤文件
  - 可以在列表中选择一个或多个标签（多选）
  - 只显示包含所选标签的图片
  - 支持"全选"和"全不选"快捷按钮
  - 当在列表中选择标签时，会自动选中"按标签过滤"单选按钮

## 使用方法

1. 点击文件列表搜索框旁边的过滤按钮（漏斗图标）
2. 在弹出的对话框中选择一种过滤条件
3. 如果选择"按标签过滤"，可以在列表中勾选一个或多个标签
4. 点击"应用"按钮应用过滤
5. 点击"重置"按钮清除所有过滤条件
6. 点击"关闭"按钮关闭对话框

## 注意事项

1. 过滤条件是互斥的，选择一个新的过滤条件会自动取消之前的选择
2. 过滤功能与搜索框可以同时使用，先应用搜索，再应用过滤
3. 编辑状态、文本内容和标签过滤只对已标注的文件有效
4. 过滤后的文件列表会保持当前选中的文件（如果该文件仍在过滤结果中）

## 实现文件

- `views/labeling/widgets/file_filter_dialog.py` - 过滤对话框
- `views/labeling/label_widget.py` - 主窗口集成和过滤逻辑
- `resources/images/filter.svg` - 过滤按钮图标

## 编译资源文件

添加了新的图标文件后，需要重新编译资源文件：

```bash
pyrcc5 resources/resources.qrc -o resources/resources.py
```

或者在Windows上：

```cmd
pyrcc5 resources\resources.qrc -o resources\resources.py
```
