# 20251020 标签工具功能增强总结

本文档旨在记录对 `views/labeling/widgets/label_tool_dialog.py` 中 `LabelToolDialog` 工具的功能增强过程，主要目标是为未来的自己提供清晰的修改记录和实现思路。

## 1. 需求概述

用户希望在原有的“双色标签工具”（间隔将标签A修改为标签B）基础上，增加一个全新的 **“批量修改”** 模式。此模式可以直接将所有指定的“标签A”全部替换为对应的“标签B”，以提高标签修改的灵活性和效率。

## 2. 主要变更内容

### 2.1. UI界面更新

- **新增模式选项**：在“模式”选择框中，增加了一个新的 `QRadioButton`：“批量修改标签 (将所有A替换为B)”。
- **优化现有选项**：为了避免混淆，将原有的“转换为双色标签”重命名为“间隔修改标签 (将偶数个A替换为B)”，并为所有选项添加了更清晰的说明文字。
- **调整默认选项**：将新增的“批量修改标签”设置为默认选中项。

### 2.2. 功能逻辑增强

- **新增处理模式**：在后台 `Worker` 和前台“处理当前页”的逻辑中，增加了一个名为 `bulk_edit` 的新模式。
- **实现批量替换**：创建了 `bulk_edit` 和 `_bulk_edit` 方法，其逻辑为：遍历文件中的所有 `shapes`，只要 `label` 在“标签A”列表中，就无条件地将其替换为“标签B”列表中对应的标签。
- **兼容现有功能**：所有修改都兼容原有的“间隔修改”和“还原”功能。

## 3. 实现过程

整个实现过程分为三个主要步骤：

1.  **修改UI定义**：在 `LabelToolDialog` 的 `__init__` 方法中，重新定义了“模式” `QGroupBox` 内的 `QRadioButton` 控件。
2.  **更新核心逻辑**：
    - 在 `Worker` 类中，添加 `bulk_edit` 方法，并在 `process_file` 中增加对 `bulk_edit` 模式的调用。
    - 在 `LabelToolDialog` 类中，添加 `_bulk_edit` 方法，用于处理“当前页”的修改。
3.  **更新模式分发逻辑**：
    - 修改 `_run_processing_with_worker` 方法，使其能正确识别新的UI选项，并将 `bulk_edit` 模式名传递给 `Worker`。
    - 修改 `run_current_page_processing` 方法，使其在点击“处理当前页”时，能够根据新UI选项调用对应的处理方法 (`_bulk_edit`, `_to_bicolor`, `_to_monocolor`)。

### 4.2. Worker类 (`Worker`)

**变更点**：在 `process_file` 中添加模式判断，并实现 `bulk_edit` 方法。

```python
# 在 process_file 方法中
if self.mode == 'to_bicolor':
    self.to_bicolor(data)
elif self.mode == 'bulk_edit': # 新增
    self.bulk_edit(data)      # 新增
elif self.mode == 'to_monocolor':
    self.to_monocolor(data)

# ...

# 新增 bulk_edit 方法
def bulk_edit(self, data):
    label_map = dict(zip(self.labels_a, self.labels_b))
    for shape in data['shapes']:
        label = shape.get('label')
        if label in label_map:
            original_label = label
            new_label = label_map[label]
            shape['label'] = new_label
            self.log_signal.emit(f"  已将 '{original_label}' 批量修改为 '{new_label}'")
```
