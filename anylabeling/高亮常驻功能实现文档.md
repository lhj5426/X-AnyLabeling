# 高亮常驻功能实现文档

## 功能概述

在"高亮与锁定设置"对话框中新增"启用常驻高亮"开关，用于控制标注的默认高亮状态。

## 功能说明

### 启用常驻高亮（勾选）
- 所有标注默认处于高亮状态
- 如果配置了"正向高亮"规则，则按规则高亮指定标签
- 如果没有配置规则，则全部标注高亮
- 切换页面时保持高亮状态

### 不启用常驻高亮（不勾选）
- 所有标注默认不高亮
- 需要手动点击"高亮"按钮才会高亮
- 切换页面时保持不高亮状态

### 实时生效
- 勾选或取消勾选后，立即应用到当前页面的所有标注
- 高亮按钮状态同步更新
- 配置自动保存，切换页面时自动应用最新设置

## 实现细节

### 1. 配置文件修改

**文件：** `configs/xanylabeling_config.yaml`

新增配置项：
```yaml
highlight_enabled_by_default: true
```

默认值为 `true`，保持向后兼容。

### 2. 高亮设置对话框

**文件：** `views/labeling/widgets/highlight_settings_dialog.py`

#### 新增UI组件
```python
# 高亮常驻设置分组
self.default_highlight_group = QtWidgets.QGroupBox("高亮常驻设置")
self.default_highlight_checkbox = QtWidgets.QCheckBox("启用常驻高亮")
```

#### 新增方法
```python
def _on_default_highlight_changed(self, state):
    """处理常驻高亮开关状态变化，实时生效"""
    - 保存配置到文件
    - 调用父窗口的 apply_default_highlight_setting() 方法
    - 立即应用到当前页面所有标注
```

### 3. 标注窗口主逻辑

**文件：** `views/labeling/label_widget.py`

#### 新增方法
```python
def apply_default_highlight_setting(self, is_enabled):
    """应用默认高亮设置，实时生效到所有标注"""
    - 根据 is_enabled 设置所有 shape.selected 状态
    - 更新全局高亮状态 Shape.highlighting_enabled
    - 更新高亮按钮状态
    - 刷新画布显示
```

## 使用方法

1. 打开"高亮与锁定设置"对话框（菜单：工具 → 高亮设置）
2. 在"高亮常驻设置"分组中勾选或取消勾选"启用常驻高亮"
3. 设置立即生效，无需重启软件
4. 切换页面时自动应用最新设置

## 注意事项

1. 配置项 `highlight_enabled_by_default` 默认为 `true`，保持向后兼容
2. 使用 `get_config()` 重新读取配置，确保获取最新设置
3. 高亮按钮必须是实例变量 `self.btn_highlight`，才能在其他方法中访问
4. 对话框创建时必须传入 `parent` 和 `config` 参数
