## 🐛 问题描述

### 问题1：批量处理时软件假死
在使用"全部页面"或"指定页面范围"模式批量缩放矩形时，软件界面会出现假死现象，无法响应用户操作，看起来像是程序卡死了。

**表现**：
- 界面无响应
- 进度条不更新
- 日志不实时显示
- 无法取消操作

### 问题2：批量处理报错
批量处理时出现错误：`list indices must be integers or slices, not str`

**错误日志示例**：

**结果**：
- 所有文件处理失败

- 批量操作完全无效

## 🔍 问题原因分析

### 原因1：缺少UI事件处理
在批量处理循环中，没有调用 `QApplication.processEvents()` 来处理UI事件，导致：
- UI线程被长时间占用
- 界面无法重绘
- 进度条无法更新
- 用户输入无法响应

### 原因2：数据类型不匹配
`LabelFile.save()` 方法期望接收**字典列表**，但代码传入的是 **Shape对象列表**。

**代码流程**：
1. `LabelFile.load()` 读取JSON文件，将字典转换为 `Shape` 对象
2. 批量处理修改 `Shape` 对象的 `points` 属性
3. 直接将 `Shape` 对象列表传给 `LabelFile.save()`
4. `LabelFile.save()` 尝试访问 `shape["shape_type"]`（期望字典）
5. 但实际是 `Shape` 对象，导致报错

**关键代码位置**（`label_file.py` 第163-164行）：
```python
for i, shape in enumerate(shapes):
    if shape["shape_type"] == "rectangle":  # ❌ 这里期望字典，但收到的是Shape对象
        # ...
```

## ✅ 修复方案

### 修复1：添加UI事件处理（防止假死）

在批量处理循环中添加以下代码：

```python
# 更新进度条和UI（防止假死）
self.rectangle_scale_dialog.update_progress(current_progress, total_pages)
QtWidgets.QApplication.processEvents()
```

**作用**：
- 定期处理UI事件队列
- 更新进度条显示
- 保持界面响应
- 允许用户看到实时进度

### 修复2：转换Shape对象为字典（修复报错）

在保存前将 `Shape` 对象转换为字典：

```python
# 将Shape对象转换为字典格式
shapes_dict = [shape.to_dict() for shape in label_file.shapes]

# 保存JSON文件（传入字典列表）
label_file.save(
    filename=label_file_path,
    shapes=shapes_dict,  # ✅ 传入字典列表
    image_path=label_file.image_path,
    image_height=image_height,
    image_width=image_width,
    image_data=label_file.image_data,
    other_data=label_file.other_data,
    flags=label_file.flags,
)
```

### 修复3：添加进度条重置

在批量处理完成后重置进度条：

```python
# 重置进度条
self.rectangle_scale_dialog.reset_progress()
```

## 💡 技术要点

### 1. QApplication.processEvents() 的作用

在PyQt中，UI更新和事件处理都在主线程的事件循环中进行。当主线程被长时间占用时（如批量处理），事件循环无法运行，导致：
- UI无法重绘
- 用户输入无法响应
- 定时器无法触发

**解决方案**：在长时间操作中定期调用 `QApplication.processEvents()`，让事件循环有机会处理积压的事件。

```python
for i in range(large_number):
    # 执行耗时操作
    do_something()
    
    # 定期处理UI事件（建议每次循环都调用）
    QtWidgets.QApplication.processEvents()
```

### 2. Shape对象与字典的转换

X-AnyLabeling中的数据流：

```
JSON文件 → 字典 → Shape对象 → 字典 → JSON文件
   ↓         ↓        ↓         ↓        ↓
 load()  load_from_dict()  to_dict()  save()
```

**关键方法**：
- `Shape.load_from_dict(data)` - 从字典创建Shape对象
- `Shape.to_dict()` - 将Shape对象转换为字典

**注意事项**：
- `LabelFile.load()` 返回的 `shapes` 是 `Shape` 对象列表
- `LabelFile.save()` 期望接收字典列表
- 在保存前必须调用 `to_dict()` 转换

### 3. 进度条更新

```python
# 更新进度
self.rectangle_scale_dialog.update_progress(current, total)

# 重置进度
self.rectangle_scale_dialog.reset_progress()
```

---

## ⚠️ 注意事项

1. **不要过度调用 processEvents()**
   - 虽然 `processEvents()` 可以保持UI响应，但过度调用会降低性能
   - 建议在每次循环迭代时调用一次即可

2. **批量处理时的内存管理**
   - 批量处理大量文件时，注意内存使用
   - 当前实现每次只加载一个文件，处理完立即释放

3. **错误处理**
   - 单个文件处理失败不会影响其他文件
   - 错误信息会记录在日志中
   - 最终统计只包含成功处理的文件
