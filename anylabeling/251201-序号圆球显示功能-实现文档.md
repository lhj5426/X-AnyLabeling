# 序号圆球显示功能

## 功能概述

改进"显示序号"功能的视觉效果，将原来和标签文字放在一起的序号改为在图形中心显示蓝色圆球+白色数字的样式。

## 使用方式

菜单：**视图 → 显示序号**（快捷键：Ctrl+Shift+O）

## 视觉效果

| 元素 | 样式 |
|------|------|
| 背景圆球 | Dodger Blue (30, 144, 255) |
| 圆球边框 | 白色，2px |
| 数字文字 | 白色，粗体，9pt |
| 圆球大小 | 固定 12px 半径，不随缩放变化 |
| 显示位置 | 图形中心 |

## 与路径线模式的对比

此功能的视觉样式与 SHIFT+右键隐藏线模式中的数字显示一致，保持界面风格统一。

## 修改的文件

### canvas.py

1. 注释掉原来的序号文字拼接逻辑（约第 3937 行）
2. 在标签绘制后调用 `draw_order_circles()` 方法（约第 4013 行）
3. 新增 `draw_order_circles()` 方法（约第 4710 行）
   - 使用屏幕坐标绘制，固定像素大小
   - 计算每个图形的全局序号
   - 在图形中心绘制蓝色圆球和白色数字
