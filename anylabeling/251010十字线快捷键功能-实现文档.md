## 📋 功能概述

为 X-AnyLabeling 添加了快速切换十字线（Crosshair）显示/隐藏的功能。该功能通过专门的快捷键和视图菜单中的新选项实现，旨在提升用户操作效率。

### 需求背景

- **原始问题**：“设置十字线”菜单项仅能打开设置对话框，无法快速切换其可见性，操作繁琐。
- **用户需求**：需要一个快捷键来直接、快速地打开或关闭十字线，并希望菜单项能反映当前的显示状态。

### 功能特点

1. ✅ **快捷键切换**：新增 `Ctrl+Shift+H` 快捷键，可随时切换十字线的显示/隐藏状态。
2. ✅ **菜单项同步**：在“视图”菜单中添加了“显示十字线”选项，该选项为复选框样式，实时同步十字线的可见状态。
3. ✅ **配置持久化**：十字线的显示状态会自动保存到配置文件中，下次启动时保持不变。
4. ✅ **UI 一致性**：新菜单项的命名（显示十字线）和图标风格与现有菜单保持了统一。

## 📝 详细修改记录

### 1. `label_widget.py` 的修改

#### a. 新增 `toggle_crosshair` 方法

在 `LabelingWidget` 类中，添加了此方法以处理切换逻辑。

```python
def toggle_crosshair(self):
    """Toggle crosshair visibility."""
    settings = self._config["canvas"]["crosshair"]
    new_show_state = not settings.get("show", True)
    settings["show"] = new_show_state
    self.canvas.set_cross_line(**settings)
    self.actions.toggle_cross_line.setChecked(new_show_state)
```

**逻辑说明**：
- 从 `self._config` 读取当前的十字线设置。
- 反转 `show` 状态（`True` -> `False`，`False` -> `True`）。
- 使用更新后的设置重新应用到 `canvas`。
- 同步更新菜单项的勾选状态。

#### b. 新增 `toggle_cross_line` QAction

在 `__init__` 方法中，定义了一个新的 `QAction`。

```python
toggle_cross_line = action(
    self.tr("显示十字线"),
    self.toggle_crosshair,
    shortcuts.get("toggle_crosshair", "Ctrl+Shift+H"),
    tip=self.tr("显示/隐藏十字线"),
    icon="eye",
    checkable=True,
    checked=self._config["canvas"]["crosshair"]["show"],
)
```

**逻辑说明**：
- **文本**：“显示十字线”，与菜单风格统一。
- **触发**：调用 `toggle_crosshair` 方法。
- **快捷键**：从配置中读取 `toggle_crosshair`，默认为 `Ctrl+Shift+H`。
- **图标**：使用 `eye.png` 图标，直观表示“可见性”。
- **可勾选**：`checkable=True` 使其成为一个复选菜单项。
- **初始状态**：`checked` 状态根据配置文件中的 `show` 值初始化。

#### c. 更新 `self.actions` 结构体和视图菜单

将新的 `toggle_cross_line` action 添加到 `self.actions` 和 `self.menus.view` 中，使其在程序中可用并显示在正确的位置。

```python
# 添加到 self.actions
self.actions = utils.Struct(
    # ...
    set_cross_line=set_cross_line,
    toggle_cross_line=toggle_cross_line, # 新增
    show_groups=show_groups,
    # ...
)

# 添加到视图菜单
utils.add_actions(
    self.menus.view,
    (
        # ...
        set_cross_line,
        toggle_cross_line, # 新增
        show_texts,
        # ...
    ),
)
```

## 💡 常见问题 (FAQ)

### Q1：如何修改切换十字线的快捷键？

**A1**：
打开您的用户配置文件 `C:\Users\ziiyue\.YSGxanylabelingrc`，在 `shortcuts` 部分找到 `toggle_crosshair` 并修改为您想要的快捷键组合，然后重启程序即可。

### Q2：为什么菜单项叫“显示十字线”而不是“切换十字线”？

**A2**：
为了与“显示文本”、“显示标签”等现有菜单项的命名风格保持一致，采用了“显示XX”的格式。勾选状态代表了其可见性。

### Q3：这个功能和“设置十字线”有什么区别？

**A3**：
- **显示十字线 (`Ctrl+Shift+H`)**：用于快速切换十字线的 **可见性**。
- **设置十字线**：用于打开一个对话框，以详细 **配置** 十字线的样式（如颜色、宽度、线型等）。
