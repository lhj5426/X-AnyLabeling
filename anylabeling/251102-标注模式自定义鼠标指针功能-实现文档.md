## 📋 功能概述

为 X-AnyLabeling 的四种矩形标注模式添加自定义鼠标指针功能，使用指定的 `.cur` 光标文件替代默认光标，提升用户体验和视觉反馈。

### 支持的标注模式

| 标注模式 | 说明 | 自定义光标 |
|---------|------|-----------|
| **rectangle** | 水平矩形标注 | ✅ 已添加 |
| **rotation** | 旋转矩形标注 | ✅ 已添加 |
| **rotation3** | 三点旋转矩形标注 | ✅ 已有 |
| **rectangle3** | 三点水平矩形标注 | ✅ 已添加 |

### 需求背景

- **原始问题**：rectangle 和 rotation 模式使用系统默认光标，缺乏辨识度
- **用户需求**：为不同的标注模式使用不同的自定义光标，增强视觉效果
- **实现目标**：统一管理所有矩形标注模式的自定义光标

### 修改 2：初始化自定义光标

**位置**：`_init_custom_cursors()` 方法，约第 4741-4785 行  
**修改类型**：新增代码块

```python
def _init_custom_cursors(self):
    """初始化自定义鼠标指针"""
    global CURSOR_GRAB, CURSOR_MOVE, CURSOR_RECTANGLE, CURSOR_ROTATION, CURSOR_ROTATION3, CURSOR_RECTANGLE3

    try:
        # 创建自定义接触矩形指针
        CURSOR_GRAB = QtGui.QCursor(QtGui.QPixmap(CUSTOM_CURSOR_GRAB_PATH))
    except Exception:
        CURSOR_GRAB = QtCore.Qt.OpenHandCursor

    try:
        # 创建自定义移动指针
        CURSOR_MOVE = QtGui.QCursor(QtGui.QPixmap(CUSTOM_CURSOR_MOVE_PATH))
    except Exception:
        CURSOR_MOVE = QtCore.Qt.ClosedHandCursor

    try:
        # 创建自定义rectangle指针
        CURSOR_RECTANGLE = QtGui.QCursor(QtGui.QPixmap(CUSTOM_CURSOR_RECTANGLE_PATH))
    except Exception:
        CURSOR_RECTANGLE = QtCore.Qt.CrossCursor

    try:
        # 创建自定义rotation指针
        CURSOR_ROTATION = QtGui.QCursor(QtGui.QPixmap(CUSTOM_CURSOR_ROTATION_PATH))
    except Exception:
        CURSOR_ROTATION = QtCore.Qt.CrossCursor

    try:
        # 创建自定义rotation3指针
        CURSOR_ROTATION3 = QtGui.QCursor(QtGui.QPixmap(CUSTOM_CURSOR_ROTATION3_PATH))
    except Exception:
        CURSOR_ROTATION3 = QtCore.Qt.CrossCursor

    try:
        # 创建自定义rectangle3指针
        CURSOR_RECTANGLE3 = QtGui.QCursor(QtGui.QPixmap(CUSTOM_CURSOR_RECTANGLE3_PATH))
    except Exception:
        CURSOR_RECTANGLE3 = QtCore.Qt.CrossCursor
```

**说明**：
- 在全局变量声明中添加了 4 个光标变量
- 为每个光标添加了加载代码块
- 包含容错机制：文件不存在或加载失败时自动回退到系统默认光标

### 修改 3：模式切换时设置光标

**位置**：`create_mode` 属性 setter，约第 427-456 行  
**修改类型**：新增代码块

```python
@create_mode.setter
def create_mode(self, value):
    """Set create mode for canvas"""
    if value not in [
        "polygon",
        "rectangle",
        "rectangle3",
        "rotation",
        "rotation3",
        "circle",
        "line",
        "point",
        "linestrip",
    ]:
        raise ValueError(f"Unsupported create_mode: {value}")
    self._create_mode = value

    # Set custom cursor for different modes
    if value == "rectangle":
        self.un_highlight()
        self.setCursor(CURSOR_RECTANGLE)
    elif value == "rotation":
        self.un_highlight()
        self.setCursor(CURSOR_ROTATION)
    elif value == "rotation3":
        self.un_highlight()
        self.setCursor(CURSOR_ROTATION3)
    elif value == "rectangle3":
        self.un_highlight()
        self.setCursor(CURSOR_RECTANGLE3)
```

**说明**：
- 当用户切换到不同的标注模式时，自动设置对应的自定义光标
- 先调用 `un_highlight()` 清除之前的高亮状态
- 使用 `setCursor()` 设置光标

**💡 添加新模式的方法**：
如果要为其他模式（如 polygon、circle）也添加自定义光标，在这里添加新的 `elif` 分支即可。

## 🎨 技术细节

### 光标加载机制

#### Qt 光标系统

```python
# 从文件加载自定义光标
pixmap = QtGui.QPixmap("path/to/cursor.cur")  # 加载光标图像
cursor = QtGui.QCursor(pixmap)                # 创建光标对象

# 系统预定义光标
cursor = QtCore.Qt.CrossCursor                # 十字光标
cursor = QtCore.Qt.ArrowCursor                # 箭头光标
```

#### 容错机制

```python
try:
    # 尝试加载 .cur 文件
    CURSOR_RECTANGLE = QtGui.QCursor(QtGui.QPixmap(CUSTOM_CURSOR_RECTANGLE_PATH))
except Exception:
    # 加载失败则使用系统默认光标
    CURSOR_RECTANGLE = QtCore.Qt.CrossCursor
```

**优点**：
- 文件存在 → 使用自定义光标
- 文件不存在/损坏 → 自动回退，程序不会崩溃

### 光标应用机制

#### 两种设置方法

##### 1. `setCursor()` - 直接设置

```python
self.setCursor(CURSOR_RECTANGLE)
```

- **作用范围**：整个 Canvas 小部件
- **持续时间**：直到被其他 `setCursor()` 调用覆盖
- **使用场景**：模式切换时（`create_mode` setter）

##### 2. `override_cursor()` - 覆盖设置

```python
self.override_cursor(cursor)
```

- **作用范围**：整个应用程序
- **优先级**：高于 `setCursor()`
- **使用场景**：绘制过程中动态调整光标

## 💡 常见问题 (FAQ)

### Q1：如何更换光标文件？

**A1**：修改 `canvas.py` 文件第 29-32 行的路径即可：
```python
CUSTOM_CURSOR_RECTANGLE_PATH = r"你的新路径\新光标.cur"
```

### Q2：支持哪些光标文件格式？

**A2**：
- ✅ `.cur` 文件（Windows 光标格式，推荐）
- ✅ `.png` 文件（需要代码稍作调整）
- ❌ 自制的 `.cur` 文件可能不兼容（Qt 的 QPixmap 可能无法加载）

### Q3：为什么我的自制光标文件加载失败？

**A3**：
- 某些光标制作软件生成的 `.cur` 文件格式可能不被 Qt 支持
- 建议使用标准的 `.cur` 文件或从 Windows 系统目录 `C:\Windows\Cursors\` 复制
- 或者将光标导出为 `.png` 格式使用

### Q4：光标文件路径可以使用中文吗？

**A4**：
- ✅ 可以！经过测试，Qt 支持中文路径
- ❌ 但文件名中的**括号**可能导致问题，建议避免使用特殊字符
- ✅ 推荐使用纯英文+数字的文件名

### Q5：如何为其他模式（polygon、circle）也添加自定义光标？

**A5**：按照相同的步骤：
1. 在第 16-24 行添加全局变量：`CURSOR_POLYGON = None`
2. 在第 29-32 行添加路径常量：`CUSTOM_CURSOR_POLYGON_PATH = r"..."`
3. 在 `_init_custom_cursors()` 中添加加载代码
4. 在 `create_mode` setter 中添加判断分支
5. 在两处绘制代码中添加条件判断

### Q6：修改后需要重新编译吗？

**A6**：
不需要！Python 是解释型语言：
1. 保存修改后的 `canvas.py` 文件
2. 重新启动程序即可生效
