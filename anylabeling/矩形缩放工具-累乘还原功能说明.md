# 矩形缩放工具 - 累乘还原功能说明

## 📋 功能概述

新增**累乘还原计算器**功能，用于快速还原多次相同比例缩放的操作。

### 使用场景

当你不小心多次使用相同比例进行缩放时（例如连续3次放大1.3333倍），可以使用此功能一键计算还原比例。

---

## 🎯 功能说明

### 界面位置

在"矩形缩放工具"对话框中，位于"倒数计算器"下方，显示为：

```
累乘还原: [1.3333] × [3次] 需缩放: 0.421875 [应用]
```

### 参数说明

1. **缩放比例**（左侧输入框）
   - 输入每次缩放使用的比例
   - 例如：`1.3333`、`1.5`、`2.0`

2. **缩放次数**（中间数字框）
   - 输入连续缩放的次数
   - 范围：1-100次
   - 默认值：3次

3. **需缩放**（结果显示）
   - 自动计算出还原所需的缩放比例
   - 橙红色显示，醒目易识别

4. **应用按钮**
   - 点击后将计算结果填入"缩放比例"输入框
   - 然后点击"缩放"按钮即可还原

## 💡 使用示例

### 示例1：还原3次1.3333倍的放大

**问题**：不小心连续3次输入了 `1.3333` 进行放大

**操作步骤**：
1. 在"累乘还原"区域输入：
   - 缩放比例：`1.3333`
   - 缩放次数：`3`
2. 查看结果显示：`需缩放: 0.421875`
3. 点击"应用"按钮
4. 点击"缩放"按钮完成还原

**计算过程**：
- 累乘结果：1.3333³ = 2.370370
- 还原比例：1 ÷ 2.370370 = 0.421875

## 📊 三个计算器对比

工具中现在有三个计算器，各有不同用途：

### 1. 分辨率计算器（蓝色）
- **用途**：根据原始和目标分辨率计算缩放比例
- **示例**：1920×1080 → 2560×1440
- **计算**：2560 ÷ 1920 = 1.3333

### 2. 倒数计算器（紫色）
- **用途**：已知当前图相对原图的比例，计算还原比例
- **示例**：当前是原图的 0.75 倍
- **计算**：1 ÷ 0.75 = 1.3333

### 3. 累乘还原计算器（橙红色）⭐ 新增
- **用途**：已知连续缩放的比例和次数，计算还原比例
- **示例**：连续3次放大1.3333倍
- **计算**：1 ÷ (1.3333³) = 0.421875

---

## ⚠️ 注意事项

1. **适用场景**：
   - 只适用于连续使用**相同比例**进行缩放的情况
   - 如果每次缩放比例不同，需要手动计算

2. **精度问题**：
   - 计算结果保留6位小数
   - 多次缩放可能产生累积误差

3. **验证结果**：
   - 应用还原后，建议检查图像是否恢复到预期状态
   - 如有偏差，可使用撤销功能（Ctrl+Z）

4. **日志信息**：
   - 点击"应用"后，日志会显示详细的计算过程
   - 例如：`✅ 已应用累乘还原: 1.3333 的 3 次方 = 2.370370，需要缩放 0.421875 倍恢复原图`
