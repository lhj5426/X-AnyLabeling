# 251021 - 标签过滤功能

## 📌 功能概述

为 AI 自动标注工具添加可视化的标签过滤功能，用户可以通过界面直接配置要显示的检测标签，无需手动编辑 YAML 配置文件。

## ✨ 功能特点

### 1. 可视化配置
- 点击"过滤标签"按钮打开配置对话框（**非模态窗口**，可同时操作主界面）
- 通过复选框勾选/取消勾选要显示的标签
- 提供"全选"、"取消全选"快捷按钮
- 点击"应用"立即生效，无需关闭窗口

### 2. 多种标签来源
- **右侧标签列表**：自动读取当前项目右侧标签栏的所有标签
- **YAML 文件导入**：支持从模型配置文件导入标签（适用于新项目）

### 3. 会话期配置（不持久化）
- **默认全选**：每次启动软件打开对话框时，默认所有标签都被勾选（显示所有）
- **会话内保留**：在软件运行期间，多次打开对话框会保留上次的选择
- **重启清空**：关闭软件后重新启动，过滤配置恢复为默认全选状态
- **临时标签**：从 YAML 导入的标签在软件运行期间保留，关闭软件后清空

### 4. 按需显示
- 只在加载 YOLO 模型后才显示"过滤标签"按钮
- 未加载模型时自动隐藏，保持界面整洁

unique_label_list = self.parent.unique_label_list

for label in self.extra_labels_from_yaml:

### 2. YAML 导入实现
```python
def import_from_yaml(self):
    # 选择 YAML 文件
    file_path, _ = QFileDialog.getOpenFileName(...)

    # 读取 classes 字段
    with open(file_path, 'r', encoding='utf-8') as f:
        yaml_config = yaml.safe_load(f)
    yaml_classes = yaml_config.get("classes", [])

    # 动态添加复选框
    for class_name in yaml_classes:
        checkbox = QCheckBox(class_name)
        checkbox.setChecked(True)
        self.checkboxes[class_name] = checkbox
        self.checkbox_layout.insertWidget(index, checkbox)

    # 回调保存到持久化存储
    if self.on_yaml_import:
        self.on_yaml_import(new_labels)
```

### 3. 过滤配置应用（非模态窗口）
```python
# 非模态窗口实现
def on_filter_classes_clicked(self):
    # 创建非模态对话框
    dialog = FilterClassesDialog(
        all_classes=all_classes,
        current_filter_classes=current_filter_classes,
        on_apply=self.apply_filter_classes,  # 应用回调
        parent=self
    )
    # 使用 show() 而不是 exec_()
    dialog.show()

# 应用过滤设置（回调函数）
def apply_filter_classes(self, selected_classes):
    model_config["filter_classes"] = selected_classes

    # 将类别名称转换为索引
    # 注意：空列表 [] 表示不显示任何标签
    if selected_classes is not None:
        filter_indices = [
            i for i, cls in enumerate(model_classes)
            if cls in selected_classes
        ]
    else:
        filter_indices = None  # None 表示显示所有标签

    model_config["model"].filter_classes = filter_indices
```

## 🔍 配置管理说明

### 配置不持久化策略
本功能采用**会话期配置**策略，不将过滤设置保存到 YAML 文件：

**原因：**
- 避免污染模型配置文件
- 每次使用都从全选状态开始，更符合直觉
- 防止上次的过滤设置影响本次工作

**行为：**
- ✅ **启动软件** → 打开过滤窗口 → 默认全选（显示所有）
- ✅ **会话期间** → 多次打开窗口 → 保留上次选择
- ✅ **关闭软件** → 配置清空 → 下次启动恢复全选

如果需要每次都使用相同的过滤配置，可以：
1. 在 YAML 文件中手动配置 `filter_classes` 字段
2. 或者使用"从YAML导入"功能快速加载标签

## 📝 注意事项

1. **过滤配置不持久化**
   - 配置仅在当前会话期间有效
   - 关闭软件后自动清空
   - 每次启动默认全选（显示所有标签）
   - 避免污染模型配置文件

2. **YAML 导入的标签是临时的**
   - 仅在当前软件会话期间有效
   - 关闭软件后自动清空
   - 适用于快速测试和新项目

3. **标签来源优先级**
   - 右侧标签列表（始终读取）
   - YAML 导入的额外标签（叠加显示）

4. **非模态窗口特性**
   - 可以同时操作主界面和过滤窗口
   - 点击"应用"立即生效，无需关闭窗口
   - 支持多次调整查看效果
