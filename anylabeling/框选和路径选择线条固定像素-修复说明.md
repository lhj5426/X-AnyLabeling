# 框选和路径选择模式线条固定像素修复

## 问题描述

ALT+鼠标左键框选模式和SHIFT+鼠标左键路径选择模式的线条宽度会随着图片缩放比例变化：
- 图片100%时线条正常（细）
- 图片放大到500%或1000%时线条变得很粗

用户期望：无论图片放大多少倍，线条都保持固定的物理像素大小（如3像素）。

## 修复方案

在 `views/labeling/widgets/canvas.py` 中修改 `draw_selection_box()` 和 `draw_path_selection()` 函数。

### 核心思路

由于 `paintEvent` 中 painter 已经被 `p.scale(self.scale, self.scale)` 变换过，所有绘制的内容都会被放大。

解决方法：在绘制框选和路径选择时，先重置 painter 变换（`p.resetTransform()`），然后将图像坐标转换为屏幕坐标进行绘制。

### 坐标转换公式

```python
# offset_to_center() 返回的是 painter 坐标（已除以 scale）
# 正确的转换公式：screen = (image + offset) * scale
offset = self.offset_to_center()
screen_x = (image_x + offset.x()) * self.scale
screen_y = (image_y + offset.y()) * self.scale
```

### 修改内容

#### 1. ALT框选模式 (`draw_selection_box`)

```python
def draw_selection_box(self, p):
    if not self.selection_box_mode:
        return

    # 重置 painter 变换，使用屏幕坐标绘制
    p.save()
    p.resetTransform()

    # 图像坐标转屏幕坐标
    offset = self.offset_to_center()
    x1_screen = (self.selection_box_start.x() + offset.x()) * self.scale
    y1_screen = (self.selection_box_start.y() + offset.y()) * self.scale
    x2_screen = (self.selection_box_end.x() + offset.x()) * self.scale
    y2_screen = (self.selection_box_end.y() + offset.y()) * self.scale

    # ... 绘制代码 ...
    
    # 固定 2 物理像素边框
    pen = QtGui.QPen(QtGui.QColor(0, 120, 215), 2, Qt.SolidLine)
    
    p.restore()
```

#### 2. SHIFT路径选择模式 (`draw_path_selection`)

```python
def draw_path_selection(self, p):
    if not self.path_selection_mode or len(self.path_selection_points) < 2:
        return

    p.save()
    p.resetTransform()

    offset = self.offset_to_center()

    def to_screen(pt):
        return QtCore.QPointF(
            (pt.x() + offset.x()) * self.scale,
            (pt.y() + offset.y()) * self.scale
        )

    # 固定像素大小
    line_width = 3      # 路径线条 3 物理像素
    circle_radius = 6   # 圆点半径 6 物理像素
    border_width = 2    # 圆点边框 2 物理像素

    # ... 绘制代码使用 to_screen() 转换坐标 ...
    
    p.restore()
```

## 效果

| 缩放比例 | 修复前 | 修复后 |
|---------|--------|--------|
| 100%    | 3px    | 3px    |
| 500%    | 15px   | 3px    |
| 1000%   | 30px   | 3px    |

现在无论图片放大到多少倍，框选和路径选择的线条都保持固定的物理像素大小。
