# 8点矩形调整功能 - 实现文档

**实现日期：** 2025-11-09  
**功能描述：** 为所有矩形类型（rectangle、rotation、rotation3）添加8点调整功能（4个角点 + 4个边中点）

---

## 📋 功能概述

### 问题背景
原有的矩形只有4个角点可以拖拽调整，拖拽角点时会同时改变矩形的宽度和高度。由于手抖等原因，很难精确地只调整一个方向的尺寸。

### 解决方案
添加4个边中点作为额外的控制点，拖拽边中点时只移动那条边，不会影响矩形的宽高比例。

### 功能特性
- ✅ **8个控制点**：4个角点（圆形） + 4个边中点（方形）
- ✅ **视觉区分**：角点显示为圆形，边中点显示为方形
- ✅ **精确调整**：拖拽边中点只移动对应的边
- ✅ **支持所有矩形类型**：
  - `rectangle` - 水平矩形
  - `rotation` - 旋转矩形（拖拽式）
  - `rotation3` - 三点旋转矩形

---

## 🎯 控制点说明

### 角点（索引 0-3）
- **显示样式**：圆形控制点
- **拖拽行为**：移动角点会同时改变宽度和高度
- **索引映射**：
  - 0: 左上角
  - 1: 右上角
  - 2: 右下角
  - 3: 左下角

### 边中点（索引 4-7）
- **显示样式**：方形控制点
- **拖拽行为**：只移动对应的边，保持矩形形状
- **索引映射**：
  - 4: 上边中点（边 0-1）
  - 5: 右边中点（边 1-2）
  - 6: 下边中点（边 2-3）
  - 7: 左边中点（边 3-0）

## 🔧 技术实现

### 1. 边中点计算

对于4个顶点的矩形，计算4条边的中点：

```python
midpoints = []
for i in range(4):
    p1 = points[i]
    p2 = points[(i + 1) % 4]
    midpoint = QPointF((p1.x() + p2.x()) / 2, (p1.y() + p2.y()) / 2)
    midpoints.append(midpoint)
```

### 2. 虚拟索引系统

使用虚拟索引来区分角点和边中点：
- **0-3**: 实际顶点（角点）
- **4-7**: 虚拟顶点（边中点）

### 3. 边中点拖拽逻辑

#### 水平矩形（rectangle）
```python
if is_horizontal_edge:
    # 水平边 - 只垂直移动
    new_v1 = QPointF(original_v1.x(), original_v1.y() + offset_y)
    new_v2 = QPointF(original_v2.x(), original_v2.y() + offset_y)
else:
    # 垂直边 - 只水平移动
    new_v1 = QPointF(original_v1.x() + offset_x, original_v1.y())
    new_v2 = QPointF(original_v2.x() + offset_x, original_v2.y())
```

#### 旋转矩形（rotation/rotation3）
```python
# 计算边向量
edge_vec = v2 - v1
edge_unit = normalize(edge_vec)

# 计算垂直向量（旋转90度）
perp_unit = QPointF(-edge_unit.y(), edge_unit.x())

# 将鼠标偏移投影到垂直方向
offset_along_perp = dot(mouse_offset, perp_unit)

# 沿垂直方向移动两个顶点
perp_offset = perp_unit * offset_along_perp
new_v1 = original_v1 + perp_offset
new_v2 = original_v2 + perp_offset
```

## 🚀 使用方法

### 1. 创建矩形
使用任意矩形创建模式：
- 快捷键 `W` - rectangle 模式
- 快捷键 `R` - rotation 模式
- 快捷键 `3` - rotation3 模式（如果配置了）

### 2. 选中矩形
点击矩形选中后，会显示8个控制点：
- **圆形点**：4个角点
- **方形点**：4个边中点

### 3. 调整矩形

#### 拖拽角点
- 同时改变宽度和高度
- 适合整体调整矩形大小

#### 拖拽边中点
- **上边中点**：只调整高度（向上/向下）
- **下边中点**：只调整高度（向上/向下）
- **左边中点**：只调整宽度（向左/向右）
- **右边中点**：只调整宽度（向左/向右）

### 4. 优势
- ✅ 不会因为手抖影响另一个方向的尺寸
- ✅ 精确调整单边位置
- ✅ 配合滚轮调整功能，更加灵活
