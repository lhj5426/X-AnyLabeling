# 矩形间距线 - 仅选中矩形测距功能

## 功能概述

在辅助线菜单中添加了一个新的勾选开关：**"仅对选中矩形测距"**

- **启用时**：只对选中的矩形的四周进行测距，并显示测距线
- **禁用时**：正常全图显示所有矩形之间的测距线（默认行为）

## 实现细节

### 1. 辅助线菜单修改 (`views/labeling/widgets/smart_guides_dialog.py`)

#### 新增UI控件：
- **"仅对选中矩形测距"** - 复选框，位于"开启间距线显示"下方
- 默认状态：未勾选（关闭）

#### 修改的函数：
1. **`init_ui()`** - 添加新的复选框控件
2. **`_on_setting_changed()`** - 处理新配置的同步到canvas
3. **`load_settings()`** - 加载新配置项

### 2. Canvas修改 (`views/labeling/widgets/canvas.py`)

#### 新增属性：
```python
self.spacing_guide_selected_only = False  # 是否仅对选中矩形测距
```

#### 修改的逻辑：
在 `paintEvent()` 中添加条件判断：
- 如果 `spacing_guide_selected_only` 为 True：
  - 获取所有选中的矩形 `selected_shapes`
  - 只对这些选中矩形进行测距
  - 如果没有选中矩形，则不显示测距线
- 如果 `spacing_guide_selected_only` 为 False：
  - 正常检测所有矩形之间的距离

### 3. 间距线检测修改 (`views/labeling/widgets/rectangle_spacing_guide.py`)

#### 新增参数：
```python
def detect_spacing_lines(..., selected_only: bool = False)
```

- `selected_only=True` 时，只检测 `moving_shapes` 与其他矩形的距离
- `selected_only=False` 时，检测所有矩形对之间的距离

## 使用方式

### 启用"仅选中矩形测距"：

1. 打开辅助线工具窗口（菜单 → 辅助线工具）
2. 在"矩形间距线"部分找到"仅对选中矩形测距"
3. 勾选该选项
4. 在画布上选中一个或多个矩形
5. 只有选中矩形周围会显示测距线

### 禁用"仅选中矩形测距"：

1. 取消勾选"仅对选中矩形测距"
2. 所有矩形之间的测距线会恢复显示

## 配置文件

新增配置项在 `configs/xanylabeling_config.yaml` 中：

```yaml
# Rectangle spacing guide (矩形间距线)
spacing_guide_enabled: true
spacing_guide_selected_only: false  # 仅对选中矩形测距
spacing_guide_line_width: 2.0
spacing_guide_line_color: [0, 255, 255]  # 青色
spacing_guide_opacity: 0.8
spacing_guide_display_distance: 200  # 显示距离（像素）
spacing_guide_snap_distance: 10  # 吸附距离（像素）
```

## 技术细节

### 工作流程：

1. 用户在辅助线菜单中勾选/取消"仅对选中矩形测距"
2. 触发 `_on_setting_changed()` 回调
3. 更新 `canvas.spacing_guide_selected_only` 属性
4. 在下一次 `paintEvent()` 中：
   - 检查 `spacing_guide_selected_only` 状态
   - 如果启用，获取选中的矩形列表
   - 调用 `detect_spacing_lines()` 时传入 `selected_only=True`
   - 只显示选中矩形的测距线

### 选中状态检测：

通过 `shape.selected` 属性判断矩形是否被选中：
```python
selected_shapes = [s for s in self.shapes if s.selected]
```
