# 粘贴模式辅助线和吸附独立开关 - 实现文档

## 📋 功能概述

为**粘贴模式**添加了三个独立的设置，允许用户分别控制：
1. **粘贴模式显示辅助线** - 控制在粘贴虚影时是否显示辅助线
2. **粘贴模式启用吸附** - 控制在粘贴虚影时是否启用磁铁吸附功能
3. **粘贴模式吸附距离** - 控制粘贴模式下的吸附距离（独立于全局吸附距离）

这些设置独立于全局的辅助线开关，专门用于粘贴模式。

#### 修改 `update_paste_preview_position()` 方法（第 5698-5734 行）：

**原逻辑**：
- 虚影模式下始终显示辅助线
- 始终启用吸附功能

**新逻辑**：
```python
# 根据粘贴模式的辅助线显示开关决定是否显示辅助线
snap_offset = None
if self.smart_guides_paste_show_guides:
    # 使用 force_enable=True 强制启用辅助线检测（绕过画布辅助线开关）
    # enable_snap 参数控制是否启用吸附功能
    # snap_distance 参数使用粘贴模式的独立吸附距离
    snap_offset, guide_lines = self.detect_smart_guides(
        temp_shapes,
        force_enable=True,
        enable_snap=self.smart_guides_paste_enable_snap,
        snap_distance=self.smart_guides_paste_snap_distance
    )
    self.smart_guides_lines = guide_lines
else:
    # 不显示辅助线
    self.smart_guides_lines = []

# 如果启用了吸附功能且有吸附偏移，应用它
if self.smart_guides_paste_enable_snap and snap_offset:
    self.paste_preview_mouse_pos = QtCore.QPointF(
        canvas_pos.x() + snap_offset.x(),
        canvas_pos.y() + snap_offset.y()
    )
else:
    self.paste_preview_mouse_pos = canvas_pos
```

**关键改进**：
- ✅ 辅助线显示和吸附功能完全独立
- ✅ 粘贴模式使用独立的吸附距离（不受全局吸附距离影响）
- ✅ 可以只显示辅助线而不吸附
- ✅ 可以关闭辅助线但保留吸附（不推荐）
- ✅ 可以同时关闭辅助线和吸附

## 🎯 功能特性

### 四种组合模式

| 显示辅助线 | 启用吸附 | 效果 | 适用场景 |
|----------|---------|------|---------|
| ✅ | ✅ | 显示辅助线 + 自动吸附 | **默认模式**，最佳体验 |
| ✅ | ❌ | 显示辅助线，但不吸附 | 只想看参考线，手动对齐 |
| ❌ | ✅ | 不显示辅助线，但自动吸附 | 界面简洁，但保留吸附 |
| ❌ | ❌ | 完全自由移动 | 不需要任何辅助 |

### 推荐配置

**场景 1：精确对齐（推荐）**
- ✅ 粘贴模式显示辅助线
- ✅ 粘贴模式启用吸附
- 效果：虚影跟随鼠标，显示参考线，自动吸附到对齐位置

**场景 2：手动对齐**
- ✅ 粘贴模式显示辅助线
- ❌ 粘贴模式启用吸附
- 效果：虚影跟随鼠标，显示参考线，但不自动吸附，完全手动控制

**场景 3：简洁界面**
- ❌ 粘贴模式显示辅助线
- ✅ 粘贴模式启用吸附
- 效果：虚影跟随鼠标，不显示参考线，但仍然自动吸附

**场景 4：完全自由**
- ❌ 粘贴模式显示辅助线
- ❌ 粘贴模式启用吸附
- 效果：虚影跟随鼠标，无任何辅助，完全自由移动

## 🚀 使用方式

### 打开辅助线工具窗口

1. 在菜单中找到"辅助线工具"（或快捷键）
2. 打开辅助线工具窗口

### 配置粘贴模式

在**粘贴模式设置**部分，你会看到：

```
粘贴模式设置
├─ ☑ 启用虚影粘贴模式
│   • 启用：复制后显示虚影跟随鼠标，粘贴到鼠标位置
│     （适合在同一图片内复制标注）
│   • 禁用：传统模式，粘贴到原始坐标位置
│     （适合跨图片复制标注到相同位置）
├─ ☑ 粘贴模式显示辅助线    ← 新增
└─ ☑ 粘贴模式启用吸附      ← 新增
```

### 操作步骤

1. **启用虚影粘贴模式** - 勾选此项以启用虚影跟随鼠标
2. **粘贴模式显示辅助线** - 勾选以在粘贴时显示参考线
3. **粘贴模式启用吸附** - 勾选以在粘贴时自动吸附到对齐位置
4. 复制标注（Ctrl+C）
5. 移动鼠标，虚影会跟随鼠标移动
6. 根据配置，辅助线会显示/隐藏，吸附会启用/禁用
7. 粘贴（Ctrl+V）

## 💡 技术细节

### 辅助线显示逻辑

```python
if self.smart_guides_paste_show_guides:
    # 显示辅助线
    snap_offset, guide_lines = self.detect_smart_guides(
        temp_shapes, 
        force_enable=True,  # 强制启用（绕过全局开关）
        enable_snap=self.smart_guides_paste_enable_snap  # 根据吸附开关决定是否吸附
    )
    self.smart_guides_lines = guide_lines
else:
    # 不显示辅助线
    self.smart_guides_lines = []
```

### 吸附功能逻辑

```python
# 只有在启用吸附且有吸附偏移时才应用吸附
if self.smart_guides_paste_enable_snap and snap_offset:
    # 应用吸附偏移
    self.paste_preview_mouse_pos = QtCore.QPointF(
        canvas_pos.x() + snap_offset.x(),
        canvas_pos.y() + snap_offset.y()
    )
else:
    # 不吸附，使用原始鼠标位置
    self.paste_preview_mouse_pos = canvas_pos
```

### 配置同步流程

1. 用户在辅助线工具窗口中勾选/取消复选框
2. 触发 `stateChanged` 信号
3. 调用 `_on_setting_changed(key, value)` 方法
4. 更新配置字典 `self._config[key] = value`
5. 发出 `setting_changed` 信号
6. 直接更新 `canvas` 属性
7. 调用 `canvas.update()` 刷新画布

## 📝 注意事项

1. **独立性**：这两个开关只影响粘贴模式，不影响全局的辅助线和吸附功能
2. **默认值**：两个开关默认都是启用状态（true）
3. **配置持久化**：设置会保存到配置文件中，下次启动时自动加载
4. **实时生效**：修改设置后立即生效，无需重启应用

## 🎉 总结

通过添加这两个独立开关，用户现在可以更灵活地控制粘贴模式的行为：
- 可以只看辅助线而不吸附（适合手动精确对齐）
- 可以只吸附而不显示辅助线（适合简洁界面）
- 可以同时启用或同时禁用（适合不同的工作流程）
