# 边中点辅助线支持 - 修改说明

**修改日期：** 2025-11-09  
**修改原因：** 拖拽边中点（索引4-7）时没有显示辅助线和吸附，需要添加支持

---

## 📋 问题描述

### 修改前的行为
- ✅ 拖拽角点（索引0-3）：显示辅助线 + 吸附
- ❌ 拖拽边中点（索引4-7）：**没有辅助线，没有吸附**

### 修改后的行为
- ✅ 拖拽角点（索引0-3）：显示辅助线 + 吸附
- ✅ 拖拽边中点（索引4-7）：**显示辅助线 + 吸附**

---

## 🎯 边中点索引定义

矩形有8个控制点：
- **索引 0-3**: 角点（实际顶点）
  - 0: 左上角
  - 1: 右上角
  - 2: 右下角
  - 3: 左下角

- **索引 4-7**: 边中点（虚拟顶点）
  - 4: 顶边中点（边 0-1）
  - 5: 右边中点（边 1-2）
  - 6: 底边中点（边 2-3）
  - 7: 左边中点（边 3-0）

```
    0 ----4---- 1
    |           |
    7           5
    |           |
    3 ----6---- 2
```

## 🔧 修改的文件

### `views/labeling/widgets/canvas.py`

#### 修改1：`detect_vertex_smart_guides`（第5719-5807行）

**修改前的问题：**
- 只处理角点（索引0-3）
- 边中点（索引4-7）直接使用 `temp_shape[vertex_index]` 会报错（因为只有4个点）

**修改后的逻辑：**
1. 检测是否为边中点（`vertex_index >= 4`）
2. 如果是边中点，模拟边中点拖拽后的矩形形状
3. 如果是角点，使用原有逻辑

#### 修改2：`_move_edge_midpoint`（第2504-2523行）

**修改前的问题：**
- 边中点拖拽时没有调用 `detect_vertex_smart_guides`
- 导致没有辅助线显示和吸附

**修改后的逻辑：**
1. 计算边中点的新位置
2. 调用 `detect_vertex_smart_guides` 检测辅助线和吸附
3. 如果有吸附偏移，应用到边中点位置
4. 更新总偏移量
5. 使用更新后的偏移量移动边的两个顶点

## 📝 技术实现

### 1. 边中点检测

```python
# 🎯 检查是否为边中点（索引4-7）
is_edge_midpoint = vertex_index >= 4 and vertex_index <= 7
```

### 2. 边中点拖拽模拟

当拖拽边中点时，需要计算拖拽后矩形的形状：

```python
if is_edge_midpoint:
    # 获取边索引（0-3）
    edge_index = vertex_index - 4
    v1_index = edge_index
    v2_index = (edge_index + 1) % 4
    
    # 获取原始顶点位置
    original_v1 = temp_shape[v1_index]
    original_v2 = temp_shape[v2_index]
    
    # 计算边的方向向量
    edge_dx = original_v2.x() - original_v1.x()
    edge_dy = original_v2.y() - original_v1.y()
    edge_length = math.sqrt(edge_dx**2 + edge_dy**2)
    
    # 计算垂直于边的方向向量（单位向量）
    perp_dx = -edge_dy / edge_length
    perp_dy = edge_dx / edge_length
    
    # 计算边的原始中点
    original_midpoint = QtCore.QPointF(
        (original_v1.x() + original_v2.x()) / 2,
        (original_v1.y() + original_v2.y()) / 2
    )
    
    # 计算新中点相对于原始中点的偏移
    offset = new_pos - original_midpoint
    
    # 计算沿垂直方向的投影（只允许垂直于边的移动）
    projection = offset.x() * perp_dx + offset.y() * perp_dy
    
    # 应用偏移到两个顶点
    move_x = projection * perp_dx
    move_y = projection * perp_dy
    
    temp_shape.points[v1_index] = QtCore.QPointF(
        original_v1.x() + move_x,
        original_v1.y() + move_y
    )
    temp_shape.points[v2_index] = QtCore.QPointF(
        original_v2.x() + move_x,
        original_v2.y() + move_y
    )
```

### 3. 关键步骤解析

#### 步骤1：确定边的两个顶点
```python
edge_index = vertex_index - 4  # 4->0, 5->1, 6->2, 7->3
v1_index = edge_index
v2_index = (edge_index + 1) % 4
```

例如：
- 边中点索引 4（顶边）→ 边索引 0 → 顶点 0 和 1
- 边中点索引 5（右边）→ 边索引 1 → 顶点 1 和 2
- 边中点索引 6（底边）→ 边索引 2 → 顶点 2 和 3
- 边中点索引 7（左边）→ 边索引 3 → 顶点 3 和 0

#### 步骤2：计算垂直方向
```python
# 边的方向向量
edge_dx = v2.x - v1.x
edge_dy = v2.y - v1.y

# 垂直于边的方向向量（逆时针旋转90度）
perp_dx = -edge_dy / edge_length
perp_dy = edge_dx / edge_length
```

#### 步骤3：投影到垂直方向
```python
# 鼠标偏移
offset = new_pos - original_midpoint

# 投影到垂直方向（点积）
projection = offset.x * perp_dx + offset.y * perp_dy
```

这样可以确保边中点只沿垂直于边的方向移动，保持矩形形状。

#### 步骤4：更新两个顶点
```python
move_x = projection * perp_dx
move_y = projection * perp_dy

temp_shape.points[v1_index] = original_v1 + (move_x, move_y)
temp_shape.points[v2_index] = original_v2 + (move_x, move_y)
```

## 🎨 工作流程

### 拖拽边中点时的流程

1. **用户拖拽边中点**（例如索引 4，顶边中点）
   ```
   bounded_move_vertex(pos)
   └─> _move_edge_midpoint(shape, 4, pos)
       ├─> 计算边中点的新位置
       ├─> detect_vertex_smart_guides(shape, 4, new_midpoint_pos)  ← 检测辅助线！
       ├─> 应用吸附偏移（如果有）
       └─> 更新边的两个顶点位置
   ```

2. **`_move_edge_midpoint` 处理**
   ```python
   # 计算边中点的原始位置
   original_midpoint = (original_v1 + original_v2) / 2

   # 计算边中点的新位置
   new_midpoint_pos = original_midpoint + total_offset

   # 🎯 检测辅助线和吸附
   snap_offset = detect_vertex_smart_guides(shape, virtual_index, new_midpoint_pos)

   if snap_offset:
       # 应用吸附偏移
       new_midpoint_pos += snap_offset
       # 更新总偏移量
       total_offset = new_midpoint_pos - original_midpoint

   # 使用更新后的偏移量移动边的两个顶点
   new_v1 = original_v1 + total_offset
   new_v2 = original_v2 + total_offset
   ```

3. **`detect_vertex_smart_guides` 处理**
   ```python
   # 检测到是边中点（索引4）
   is_edge_midpoint = True

   # 模拟拖拽后的矩形形状
   temp_shape = shape.copy()
   # 更新顶点0和1的位置（顶边的两个顶点）
   temp_shape.points[0] = ...
   temp_shape.points[1] = ...

   # 计算边界框
   rect = temp_shape.bounding_rect()

   # 检测辅助线对齐
   # 检测吸附
   # 返回吸附偏移量
   ```

4. **显示辅助线和吸附**
   - 辅助线显示在 `self.smart_guides_lines`
   - 吸附偏移返回给 `_move_edge_midpoint`
   - `_move_edge_midpoint` 应用吸附偏移到边的两个顶点

## 💡 为什么这样设计？

### 问题
- 边中点是"虚拟顶点"，不在 `shape.points` 中
- 直接使用 `temp_shape[vertex_index]` 会报错（索引越界）

### 解决方案
- 检测边中点索引（>= 4）
- 计算边中点拖拽后，两个实际顶点的新位置
- 更新临时形状的顶点
- 使用边界框检测辅助线对齐

### 优势
- ✅ 边中点拖拽体验与角点一致
- ✅ 支持所有矩形类型（rectangle/rotation/rotation3）
- ✅ 支持任意角度的旋转矩形
- ✅ 代码复用性高（后续逻辑不变）
