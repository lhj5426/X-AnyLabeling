# 混合检测功能修复文档

## 问题描述

混合检测开关（checkbox）无法控制高亮功能的行为。虽然功能逻辑已经在代码中实现，但开关状态的改变不会影响实际执行的逻辑。

另外，在未开启混合检测时，正反向标签的切换逻辑存在问题：当正向标签有部分未高亮时，需要按多次才能切换到反向，而不是直接切换。

## 修复内容

### 1. 修复混合检测开关无效问题

**文件：** `views/labeling/label_widget.py`

**问题原因：**
`toggle_highlight()` 函数在定义时使用 `self._config` 读取配置，导致即使用户在设置对话框中修改了混合检测开关，函数内部仍然使用旧的配置引用。

**修复方案：**
在 `toggle_highlight()` 函数内部，每次执行时重新调用 `get_config()` 获取最新配置。

**修改代码：**

```python
def toggle_highlight():
    all_shapes = [item.shape() for item in self.label_list]
    if not all_shapes:
        btn_highlight.setChecked(False)
        return

    # Reload config to get latest settings
    from ...config import get_config
    current_config = get_config()
    
    locked_labels = {label.strip() for label in current_config.get("locked_labels", "").split(',') if label.strip()}
    
    # Filter out shapes that are locked and have not been session-unlocked
    unlocked_shapes = [
        s for s in all_shapes 
        if not (s.label in locked_labels and not s.is_session_unlocked)
    ]

    positive_labels_str = current_config.get("highlight_positive", "")
    positive_labels = {label.strip() for label in positive_labels_str.split(',') if label.strip()}

    negative_labels_str = current_config.get("highlight_negative", "")
    negative_labels = {label.strip() for label in negative_labels_str.split(',') if label.strip()}

    # Get mixed mode setting - always read fresh from config
    mixed_mode_enabled = current_config.get("highlight_mixed_mode", False)
    
    # ... 后续逻辑
```

**关键改动：**
- 添加 `from ...config import get_config`
- 使用 `current_config = get_config()` 替代 `self._config`
- 所有配置读取都使用 `current_config`

### 2. 修复正反向切换逻辑

**文件：** `views/labeling/label_widget.py`

**问题原因：**
在未开启混合检测时，当正向标签有混乱状态（部分高亮），代码会先清空所有高亮，需要再按一次才能高亮，再按一次才能切换到反向。这不符合预期的直接切换行为。

**修复方案：**
在未开启混合检测的正反向模式下，只要正向有任何高亮（包括混乱状态），就直接切换到反向高亮。

**修改前的代码：**

```python
else:
    # Normal mode: clear chaotic state first, then toggle
    # Priority 1: Clean up positive chaotic state
    if is_pos_chaotic:
        for shape in unlocked_shapes:
            shape.selected = False
    # Priority 2: Clean up negative chaotic state
    elif is_neg_chaotic:
        for shape in unlocked_shapes:
            shape.selected = False
    # Priority 3: If positive is on, switch to negative
    elif is_pos_fully_on:
        for shape in unlocked_shapes:
            shape.selected = shape in negative_shapes
    # Priority 4: If negative is on, switch to positive
    elif is_neg_fully_on:
        for shape in unlocked_shapes:
            shape.selected = shape in positive_shapes
    # Default Action: Turn positive on
    else:
        for shape in unlocked_shapes:
            shape.selected = shape in positive_shapes
```

**修改后的代码：**

```python
else:
    # Normal mode: directly toggle between positive and negative
    # Priority 1: If positive is fully on, switch to negative
    if is_pos_fully_on:
        for shape in unlocked_shapes:
            shape.selected = shape in negative_shapes
    # Priority 2: If negative is fully on, switch to positive
    elif is_neg_fully_on:
        for shape in unlocked_shapes:
            shape.selected = shape in positive_shapes
    # Priority 3: If positive has any selection (including chaotic), switch to negative
    elif num_pos_selected > 0:
        for shape in unlocked_shapes:
            shape.selected = shape in negative_shapes
    # Priority 4: If negative has any selection (including chaotic), switch to positive
    elif num_neg_selected > 0:
        for shape in unlocked_shapes:
            shape.selected = shape in positive_shapes
    # Default Action: Turn positive on
    else:
        for shape in unlocked_shapes:
            shape.selected = shape in positive_shapes
```

**关键改动：**
- 移除了清空混乱状态的逻辑（Priority 1 和 2）
- 添加了 Priority 3 和 4：只要正向/反向有任何高亮，就直接切换到对面
- 实现了直接在正反向之间切换，无需中间步骤

## 功能逻辑总结

### 场景1：无标签配置（全局高亮）

**未开启混合检测：**
- 全部高亮 ↔ 全部取消（简单切换）

**开启混合检测：**
- 有部分未高亮 → 先补全高亮（让所有图形都高亮）
- 全部高亮/全部未高亮 → 切换状态

---

### 场景2：仅配置正向标签

**未开启混合检测：**
- 正向标签全部高亮 ↔ 正向标签全部取消（简单切换）

**开启混合检测：**
- 正向标签有部分未高亮 → 先补全正向标签高亮
- 正向标签全部高亮/全部未高亮 → 切换状态

---

### 场景3：仅配置反向标签

**未开启混合检测：**
- 反向标签全部高亮 ↔ 反向标签全部取消（简单切换）

**开启混合检测：**
- 反向标签有部分未高亮 → 先补全反向标签高亮
- 反向标签全部高亮/全部未高亮 → 切换状态

---

### 场景4：同时配置正向和反向标签（核心场景）

#### 未开启混合检测：

**行为：直接在正反向之间切换**

1. 正向有任何高亮（包括部分高亮） → 按一下 → 切换到反向高亮
2. 反向有任何高亮（包括部分高亮） → 按一下 → 切换到正向高亮
3. 都没高亮 → 按一下 → 正向高亮

**示例：**
- 10个图形：5个正向标签1，5个反向标签2
- 当前状态：3个标签1高亮，2个标签1未高亮
- 按一下快捷键 → 5个标签1全部取消高亮，5个标签2全部高亮
- 再按一下 → 5个标签2全部取消高亮，5个标签1全部高亮

#### 开启混合检测：

**行为：先补全混乱状态，再切换**

1. **优先补全混乱状态**
   - 正向有部分未高亮 → 补全正向高亮（让所有正向标签都高亮）
   - 反向有部分未高亮 → 补全反向高亮（让所有反向标签都高亮）

2. **补全后再切换**
   - 正向全部高亮 → 切换到反向全部高亮
   - 反向全部高亮 → 切换到正向全部高亮

3. **默认行为**
   - 都没高亮 → 正向高亮

**示例：**
- 10个图形：5个正向标签1，5个反向标签2
- 当前状态：3个标签1高亮，2个标签1未高亮
- 按一下快捷键 → 5个标签1全部高亮（补全混乱状态）
- 再按一下 → 5个标签1取消高亮，5个标签2全部高亮（切换到反向）
- 再按一下 → 5个标签2取消高亮，5个标签1全部高亮（切换回正向）

---

## 核心区别

| 模式 | 行为 | 适用场景 |
|------|------|----------|
| **未开启混合检测** | 直接切换，有混乱状态也直接切换到对面 | 需要快速在正反向之间切换 |
| **开启混合检测** | 先补全当前方向的混乱状态，再按第二次才切换到对面 | 需要先整理好当前状态再切换 |

## 使用说明

1. **打开高亮设置对话框**
   - 配置正向高亮标签（例如：`qipao, balloon, changfangtiao`）
   - 配置反向高亮标签（例如：`other`）
   - 勾选或取消"启用混合模式检测"

2. **实时生效**
   - 设置会立即保存到配置文件
   - 对话框可以保持打开状态
   - 直接按高亮快捷键即可使用新设置

3. **选择合适的模式**
   - 如果需要快速切换正反向标签 → 不开启混合检测
   - 如果需要先补全混乱状态再切换 → 开启混合检测

## 配置持久化说明

### 配置文件结构

软件使用两个配置文件：

1. **默认配置文件**
   - 路径：`configs/xanylabeling_config.yaml`
   - 作用：软件的默认配置模板
   - 包含：`highlight_mixed_mode: false` 默认值

2. **用户配置文件**
   - 路径：`~/.YSGxanylabelingrc` (Windows: `C:\Users\用户名\.YSGxanylabelingrc`)
   - 作用：保存用户的实际设置
   - 特点：实时保存，重启后保留

### 配置加载顺序

1. 加载默认配置（`xanylabeling_config.yaml`）
2. 加载用户配置（`~/.YSGxanylabelingrc`）并合并
3. 用户配置的值会覆盖默认配置

### 持久化机制

- ✅ 修改设置时立即保存到用户配置文件
- ✅ 软件重启后自动加载保存的设置
- ✅ 配置在所有项目间共享
