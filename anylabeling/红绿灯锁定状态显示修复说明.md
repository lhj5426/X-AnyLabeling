# 红绿灯锁定状态显示修复说明

## 问题描述

在标签列表的红绿灯系统中，锁定/解锁状态的指示灯存在显示问题：
- ✅ 标签被锁定时：正常显示黄色灯
- ❌ 标签未锁定时：不显示任何灯（应该显示蓝色灯）

## 修复内容

### 修改文件
- `views/labeling/widgets/label_list_widget.py`

### 修复逻辑

**修复前：**
```python
# 只在锁定时显示灯
if shape.is_label_locked():
    # 显示黄色或蓝色灯
    painter.drawEllipse(...)
# 未锁定时不显示任何灯 ❌
```

**修复后：**
```python
# 始终显示锁定状态灯
is_locked = shape.is_label_locked()

if is_locked:
    if shape.is_session_unlocked:
        # Session解锁：显示蓝色灯
        color = unlocked_color
    else:
        # 完全锁定：显示黄色灯
        color = locked_color
else:
    # 未锁定状态：显示蓝色灯
    color = unlocked_color

painter.drawEllipse(...)  # 始终显示
```

## 红绿灯系统状态说明

### Position 2: 锁定/解锁状态灯（从右数第2个）

| 状态 | 颜色 | 说明 |
|------|------|------|
| 完全锁定 | 🟡 黄色 | 标签被锁定，无法编辑 |
| Session解锁 | 🔵 蓝色 | 标签在当前会话中临时解锁 |
| 未锁定 | 🔵 蓝色 | 标签未被锁定，可以自由编辑 |

### 完整的红绿灯系统（从右到左）

1. **Position 1（最右）- 选中状态**
   - 🔴 红色：当前选中的标签

2. **Position 2 - 锁定状态**
   - 🟡 黄色：锁定
   - 🔵 蓝色：解锁

3. **Position 3 - 编辑状态**
   - 🟢 绿色：已手动编辑过

4. **Position 4（最左）- 困难标记**
   - 🟣 紫色：标记为困难

## 使用效果

修复后，所有标签都会显示锁定状态灯：
- 锁定的标签显示黄色灯，一目了然
- 未锁定的标签显示蓝色灯，表示可以编辑
- 不再出现"灯消失"的情况
