# 粘贴模式独立开关 - 快速使用指南

## 🎯 新增功能

在**辅助线工具窗口**的**粘贴模式设置**部分，新增了三个独立设置：

### 1. 粘贴模式显示辅助线 ✨
- **作用**：控制在粘贴虚影时是否显示参考线
- **默认**：启用（勾选）

### 2. 粘贴模式启用吸附 🧲
- **作用**：控制在粘贴虚影时是否自动吸附到对齐位置
- **默认**：启用（勾选）

### 3. 粘贴模式吸附距离 📏
- **作用**：控制粘贴模式下的吸附距离（独立于全局吸附距离）
- **范围**：1-50 像素
- **默认**：10 像素

## 🎮 四种使用模式

### 模式 1：完整辅助（推荐）⭐
```
☑ 粘贴模式显示辅助线
☑ 粘贴模式启用吸附
```
**效果**：
- ✅ 显示参考线
- ✅ 自动吸附对齐
- 💡 **最佳体验**，适合精确对齐

**适用场景**：
- 在同一图片内复制标注
- 需要精确对齐到其他矩形
- 快速批量标注

---

### 模式 2：手动对齐
```
☑ 粘贴模式显示辅助线
☐ 粘贴模式启用吸附
```
**效果**：
- ✅ 显示参考线
- ❌ 不自动吸附
- 💡 **完全手动控制**，看得见参考线但不会被吸附

**适用场景**：
- 需要看参考线但不想被吸附
- 想要微调位置
- 需要精确控制偏移量

---

### 模式 3：简洁吸附
```
☐ 粘贴模式显示辅助线
☑ 粘贴模式启用吸附
```
**效果**：
- ❌ 不显示参考线
- ✅ 自动吸附对齐
- 💡 **界面简洁**，但保留吸附功能

**适用场景**：
- 不喜欢参考线遮挡视线
- 但仍然需要自动对齐
- 熟练用户快速操作

---

### 模式 4：完全自由
```
☐ 粘贴模式显示辅助线
☐ 粘贴模式启用吸附
```
**效果**：
- ❌ 不显示参考线
- ❌ 不自动吸附
- 💡 **完全自由**，虚影完全跟随鼠标

**适用场景**：
- 不需要任何辅助
- 随意放置位置
- 快速粗略标注

## 🚀 快速操作流程

### 步骤 1：打开辅助线工具
- 菜单 → 辅助线工具
- 或使用快捷键（如果有配置）

### 步骤 2：配置粘贴模式
1. 找到"粘贴模式设置"部分
2. 勾选/取消"粘贴模式显示辅助线"
3. 勾选/取消"粘贴模式启用吸附"

### 步骤 3：使用粘贴功能
1. 选中一个或多个标注
2. 复制（Ctrl+C）
3. 移动鼠标到目标位置
4. 观察虚影和辅助线（根据配置）
5. 粘贴（Ctrl+V）

## 💡 使用技巧

### 技巧 1：快速切换模式
- 辅助线工具窗口是**非阻塞**的
- 可以在标注过程中随时打开/关闭
- 修改设置后**立即生效**，无需重启

### 技巧 2：组合使用
- 可以先启用辅助线，观察对齐位置
- 如果不满意，取消吸附，手动微调
- 找到合适位置后再粘贴

### 技巧 3：不同场景切换
- **精确对齐**：两个都勾选
- **快速标注**：只勾选吸附
- **自由放置**：两个都不勾选

### 技巧 4：配合全局辅助线
- 粘贴模式的开关**独立于**全局辅助线开关
- 即使关闭全局辅助线，粘贴模式仍可显示辅助线
- 反之亦然


### 默认值
- 所有开关默认都是**启用**（true）
- 首次使用时会使用默认配置
- 修改后会自动保存到配置文件

## 🔧 常见问题

### Q1：为什么我看不到辅助线？
**A**：检查以下几点：
1. 是否勾选了"粘贴模式显示辅助线"
2. 是否启用了"启用虚影粘贴模式"
3. 是否有其他矩形可以对齐（辅助线需要参考对象）
4. 鼠标是否在辅助线显示距离内

### Q2：为什么虚影不会自动吸附？
**A**：检查以下几点：
1. 是否勾选了"粘贴模式启用吸附"
2. 是否在吸附距离内（默认 10 像素）
3. 吸附距离设置是否太小

### Q3：辅助线和吸附有什么区别？
**A**：
- **辅助线**：视觉参考，显示对齐位置的线条
- **吸附**：磁铁效果，自动将虚影移动到对齐位置
- 可以只显示辅助线而不吸附（手动对齐）
- 也可以只吸附而不显示辅助线（简洁界面）

### Q4：这些设置会影响全局辅助线吗？
**A**：
- **不会**！这两个开关只影响粘贴模式
- 全局辅助线有自己独立的开关
- 两者互不影响

### Q5：设置会保存吗？
**A**：
- **会**！所有设置都会自动保存到配置文件
- 下次启动应用时会自动加载
- 无需手动保存
