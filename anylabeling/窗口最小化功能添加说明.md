# X-AnyLabeling 窗口功能增强说明

**修改日期：** 2025-10-02
**修改内容：**
1. 为工具窗口添加最小化功能，移除帮助按钮（问号）
2. 为标签页管理器添加 DELETE 键删除功能

---

## 修改概述

### 1. 窗口最小化功能

为以下4个工具对话框窗口添加了最小化/最大化按钮，并移除了默认的帮助按钮（"?"）：

1. **标签页管理器** (ObjectManagerDialog)
2. **双色标签工具** (LabelToolDialog)
3. **双色标签工具** (DualColorToolDialog)
4. **区域合并工具设置** (MergeDialog)

### 2. DELETE 键删除功能

为 **标签页管理器** (ObjectManagerDialog) 添加了键盘快捷键删除功能：
- 按 **DELETE** 键或 **Backspace** 键可以删除选中的标签
- 支持多选删除
- 右键菜单提示中显示快捷键

## 修改前后对比

### 修改前
窗口标题栏按钮：`[?] [×]`
- **?** - 帮助按钮（默认显示但无实际作用）
- **×** - 关闭按钮

用户无法最小化窗口，只能关闭窗口。

### 修改后
窗口标题栏按钮：`[_] [□] [×]`
- **_** - 最小化按钮（新增）
- **□** - 最大化按钮（新增）
- **×** - 关闭按钮（保留）

用户可以自由地最小化、最大化或关闭窗口。

## 技术实现细节

### 核心代码

在每个对话框的 `__init__()` 方法中添加以下代码：

```python
# 设置窗口标志：移除帮助按钮，添加最小化按钮
self.setWindowFlags(
    Qt.Window |                      # 独立窗口
    Qt.WindowMinimizeButtonHint |    # 最小化按钮
    Qt.WindowMaximizeButtonHint |    # 最大化按钮
    Qt.WindowCloseButtonHint         # 关闭按钮
)
```

### 窗口标志说明

| 标志 | 说明 |
|-----|------|
| `Qt.Window` | 将对话框设置为独立窗口（非模态） |
| `Qt.WindowMinimizeButtonHint` | 添加最小化按钮 |
| `Qt.WindowMaximizeButtonHint` | 添加最大化按钮 |
| `Qt.WindowCloseButtonHint` | 添加关闭按钮 |

**注意：** 不设置 `Qt.WindowContextHelpButtonHint` 即可移除帮助按钮（"?"）。

### 5. object_manager_dialog.py（标签页管理器 - DELETE 键功能）

**修改位置：** 第 110-125 行（`eventFilter` 方法）

**修改前：**
```python
def eventFilter(self, source, event):
    if (source is self.list_widget and
        event.type() == QtCore.QEvent.KeyPress and
        event.key() == QtCore.Qt.Key_E and
        event.modifiers() == QtCore.Qt.ControlModifier):
        if self.list_widget.selectedItems():
            self.edit_requested.emit()
        return True
    return super(ObjectManagerDialog, self).eventFilter(source, event)
```

**修改后：**
```python
def eventFilter(self, source, event):
    if source is self.list_widget and event.type() == QtCore.QEvent.KeyPress:
        # Ctrl+E: Edit label
        if (event.key() == QtCore.Qt.Key_E and
            event.modifiers() == QtCore.Qt.ControlModifier):
            if self.list_widget.selectedItems():
                self.edit_requested.emit()
            return True

        # Delete or Backspace: Delete selected items
        if event.key() in (QtCore.Qt.Key_Delete, QtCore.Qt.Key_Backspace):
            if self.list_widget.selectedItems():
                self.delete_requested.emit()
            return True

    return super(ObjectManagerDialog, self).eventFilter(source, event)
```

## 注意事项

### PyQt5 窗口标志说明

在 PyQt5 中，`QDialog` 默认行为：
- Windows 系统：显示帮助按钮（"?"）
- 某些系统：不显示最小化/最大化按钮

通过显式设置 `setWindowFlags()`，可以精确控制窗口标题栏按钮。

### 常见窗口标志组合

```python
# 1. 仅关闭按钮（默认对话框）
Qt.Dialog | Qt.WindowCloseButtonHint

# 2. 最小化 + 关闭
Qt.Window | Qt.WindowMinimizeButtonHint | Qt.WindowCloseButtonHint

# 3. 最小化 + 最大化 + 关闭（本次修改）
Qt.Window | Qt.WindowMinimizeButtonHint | Qt.WindowMaximizeButtonHint | Qt.WindowCloseButtonHint

# 4. 无法关闭的窗口（谨慎使用）
Qt.Window | Qt.WindowTitleHint | Qt.CustomizeWindowHint
```
