# 统计总览功能改进说明

## 概述

本次更新对"统计总览"窗口进行了全面改进，提升了用户体验和工作效率。

## 主要改进

### 1. 窗口交互优化

- **非阻塞式窗口**：改为非模态窗口，可以在查看总览的同时操作主界面
- **最小化按钮**：添加了窗口最小化功能，方便临时隐藏窗口

### 2. 搜索功能增强

#### 对象视图搜索
- 添加了实时搜索框，支持在对象列表中快速查找
- **支持正则表达式**：可以使用复杂的搜索模式
  - 示例：`qipao|changfangtiao` 可以同时搜索多个标签
  - 示例：`0001.*qipao` 可以搜索特定文件中的标签
- 添加"清除"按钮，快速清空搜索内容
- 搜索框仅在"对象"视图显示，切换到"标签"视图时自动隐藏

### 3. 表格显示优化

#### 列宽调整
- 所有列宽支持手动拖拽调整
- 初始状态自动适应内容宽度
- 方便查看长内容（如坐标点）

#### 对齐优化
- 标签视图中，除标签列外的数字列居中对齐
- 提升了表格的可读性

### 4. 界面中文化

- 将英文标签改为中文：
  - `From` → `从`
  - `To` → `到`
  - `Go` → `跳转`
- 统一了界面元素的高度，视觉更协调

### 5. 智能跳转功能 ⭐

这是本次更新最重要的功能改进：

#### 双击跳转
- 在对象视图中双击任意行
- 自动跳转到对应的图片文件
- 自动在画布上选中该标注对象
- 精确匹配：即使同一文件有多个相同标签，也能准确定位

#### 键盘导航
- 使用方向键上下移动
- 自动跳转并选中对应的标注对象
- 快速浏览和检查不同的标注

#### 技术实现
- 使用坐标点进行精确匹配
- 智能判断是否需要切换文件
- 根据操作类型自动调整延迟时间

## 使用场景

### 场景1：快速查找特定标签
1. 打开统计总览窗口
2. 切换到"对象"视图
3. 在搜索框输入标签名或正则表达式
4. 双击搜索结果，自动跳转并选中

### 场景2：批量检查标注质量
1. 打开统计总览窗口
2. 使用正则表达式过滤特定类型的标注
3. 使用方向键逐个浏览
4. 在主界面直接修改有问题的标注

### 场景3：统计分析
1. 在"标签"视图查看各类标签的数量统计
2. 切换到"对象"视图查看详细信息
3. 使用搜索功能分析特定条件的标注
4. 导出数据进行进一步分析

## 技术细节

### 文件修改
- `views/labeling/widgets/overview_dialog.py`：主要改进文件

### 关键改进点
1. 将 `exec_()` 改为 `show()` 实现非阻塞
2. 添加 `displayed_shape_infos` 保存当前显示的原始数据
3. 实现 `select_shape_by_points()` 方法进行精确匹配
4. 添加 `on_current_cell_changed()` 支持键盘导航
5. 使用正则表达式引擎进行灵活搜索

### 性能优化
- 搜索时使用已加载的数据，无需重新读取文件
- 智能延迟机制，根据是否需要切换文件调整等待时间
- 坐标匹配允许0.01的浮点误差，提高匹配成功率

## 用户反馈

本次改进基于实际使用中的痛点：
- ✅ 解决了需要导出CSV才能搜索的问题
- ✅ 解决了无法直接跳转到标注对象的问题
- ✅ 解决了同标签对象无法区分的问题
- ✅ 提升了整体工作效率
