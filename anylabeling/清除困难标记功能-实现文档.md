# 清除困难标记功能 - 实现文档

## 功能概述

在红绿灯设置窗口中新增了"清除困难标记"功能，支持批量清除所有文件或当前文件的困难标记（difficult标志）。

## 功能特性

### 1. 清除全部困难标记

批量清除所有图片文件中的困难标记，将所有 `difficult: true` 改为 `difficult: false`。

**特点：**
- ✅ 批量处理所有文件
- ✅ 显示进度对话框
- ✅ 实时日志输出
- ✅ 自动刷新当前文件
- ✅ 支持取消操作

### 2. 清除本页困难标记

只清除当前打开图片的困难标记，不影响其他文件。

**特点：**
- ✅ 快速处理单个文件
- ✅ 无需进度对话框
- ✅ 实时日志输出
- ✅ 自动刷新显示

## 使用方法

### 清除全部困难标记

1. 点击菜单栏的"工具" → "红绿灯设置"
2. 在弹出的对话框中点击"清除全部困难标记"按钮
3. 等待进度对话框完成处理
4. 查看日志区域的处理结果
5. 当前文件会自动刷新

### 清除本页困难标记

1. 打开一个包含困难标记的图片
2. 点击菜单栏的"工具" → "红绿灯设置"
3. 在弹出的对话框中点击"清除本页困难标记"按钮
4. 查看日志区域的处理结果
5. 当前文件会自动刷新，紫色困难标记灯消失

## 处理逻辑

### JSON文件处理

**处理前：**
```json
{
  "shapes": [
    {
      "label": "balloon",
      "difficult": true,  // 困难标记
      "points": [[181.0, 101.0], [246.0, 960.0]],
      "shape_type": "rectangle"
    },
    {
      "label": "qipao",
      "difficult": false,
      "points": [[300.0, 200.0], [400.0, 500.0]],
      "shape_type": "rectangle"
    }
  ]
}
```

**处理后：**
```json
{
  "shapes": [
    {
      "label": "balloon",
      "difficult": false,  // 已清除
      "points": [[181.0, 101.0], [246.0, 960.0]],
      "shape_type": "rectangle"
    },
    {
      "label": "qipao",
      "difficult": false,
      "points": [[300.0, 200.0], [400.0, 500.0]],
      "shape_type": "rectangle"
    }
  ]
}
```

### 处理流程

1. **读取JSON文件**
   - 检查文件是否存在
   - 解析JSON数据

2. **遍历shapes**
   - 检查每个shape的difficult字段
   - 如果为true，改为false

3. **保存文件**
   - 只有在有修改时才保存
   - 保持JSON格式（缩进、UTF-8编码）

4. **更新显示**
   - 刷新当前文件
   - 紫色困难标记灯消失
   - 更新日志信息

## 错误处理

### 常见错误

1. **文件不存在**
   ```
   跳过 image.jpg: 标签文件不存在。
   ```

2. **JSON解析错误**
   ```
   ❌ 处理 image.jpg 失败: JSON解析错误
   ```

3. **文件写入错误**
   ```
   ❌ 处理文件时发生错误: 权限不足
   ```

### 错误处理机制

- 单个文件错误不会中断整个处理流程
- 错误信息会记录到日志
- 显示错误对话框提示用户
- 支持用户取消操作

## 性能优化

1. **后台线程处理**
   - 批量操作使用独立线程
   - 不阻塞UI界面
   - 支持取消操作

2. **进度显示**
   - 实时显示处理进度
   - 显示当前处理的文件
   - 显示处理结果统计

3. **智能刷新**
   - 只在当前文件被修改时刷新
   - 避免不必要的文件重载

## 与其他功能的配合

### 与困难标记信号灯配合

**场景**：清除困难标记后，信号灯自动消失

**流程**：
1. 打开包含困难标记的图片（显示紫色灯）
2. 点击"清除本页困难标记"
3. 文件自动刷新
4. 紫色困难标记灯消失

### 与困难标记过滤配合

**场景**：清除后，文件从过滤列表中消失

**流程**：
1. 使用"仅困难标记"过滤
2. 打开筛选出的图片
3. 点击"清除本页困难标记"
4. 如果再次应用过滤，该文件不会出现在列表中

### 与批量操作配合

**场景**：批量清除所有困难标记

**流程**：
1. 加载包含多个困难标记的文件夹
2. 点击"清除全部困难标记"
3. 等待批量处理完成
4. 所有文件的困难标记被清除

## 注意事项

1. **数据安全**
   - 操作会直接修改JSON文件
   - 建议在操作前备份重要数据
   - 操作不可撤销

2. **文件状态**
   - 只处理存在JSON文件的图片
   - 不会创建新的JSON文件
   - 保持JSON文件的其他字段不变

3. **性能考虑**
   - 批量操作可能需要较长时间
   - 支持取消操作
   - 建议在处理大量文件时耐心等待

4. **UI响应**
   - 批量操作时UI保持响应
   - 可以查看实时日志
   - 可以随时取消操作
