# 修复说明 - 间距线和滚轮设置

## 修复的问题

### 问题1：间距线透明度调整时，文字和背景色不跟随

**问题描述：**
- 调整间距线透明度（`spacing_guide_opacity`）时，只有线条的透明度改变
- 文字颜色和文字背景色的透明度保持不变
- 导致视觉效果不一致

**根本原因：**
- 线条使用了 `spacing_guide_opacity` 计算的alpha值
- 文字颜色使用了固定的alpha值255（完全不透明）
- 文字背景色使用了配置中的固定alpha值

**解决方案：**
1. 文字颜色的alpha值改为使用 `spacing_guide_opacity` 计算的alpha值（与线条一致）
2. 文字背景色的alpha值改为：配置的alpha值 × `spacing_guide_opacity`

**修改的文件：**
- `views/labeling/widgets/canvas.py` (第5993-6002行)

**修改前：**
```python
# 绘制背景（使用配置的文字背景色）
bg_r, bg_g, bg_b, bg_a = self.spacing_guide_text_bg_color[:4]
bg_color = QtGui.QColor(bg_r, bg_g, bg_b, bg_a)
p.fillRect(bg_rect, bg_color)

# 绘制文字
text_color = QtGui.QColor(r, g, b, 255)  # 固定alpha=255
p.setPen(text_color)
```

**修改后：**
```python
# 绘制背景（使用配置的文字背景色，并应用透明度）
bg_r, bg_g, bg_b, bg_a = self.spacing_guide_text_bg_color[:4]
# 应用spacing_guide_opacity到背景色的alpha值
bg_alpha_adjusted = int(bg_a * self.spacing_guide_opacity)
bg_color = QtGui.QColor(bg_r, bg_g, bg_b, bg_alpha_adjusted)
p.fillRect(bg_rect, bg_color)

# 绘制文字（使用线条颜色，并应用透明度）
text_color = QtGui.QColor(r, g, b, alpha)  # 使用与线条相同的alpha
p.setPen(text_color)
```

### 问题2：SHIFT+鼠标滚轮功能默认不生效

**问题描述：**
- SHIFT+鼠标滚轮调整矩形边界的功能默认情况下不工作
- 必须打开一次鼠标滚轮设置窗口才生效
- CTRL+鼠标滚轮功能正常工作

**根本原因：**
- Canvas从 `config["canvas"]["wheel_rectangle_editing"]` 读取配置
- WheelSettingsDialog从 `config["wheel_rectangle_editing"]` 读取配置（根级别）
- 用户配置文件中存在两个 `wheel_rectangle_editing` 配置：
  - `canvas.wheel_rectangle_editing` (第14-26行) - Canvas使用的配置
  - 根级别的 `wheel_rectangle_editing` (第516-524行) - WheelSettingsDialog使用的配置
- 两个配置的值不同，导致不一致
- 当打开设置窗口时，WheelSettingsDialog读取根级别的配置，然后通过 `on_value_changed` 更新Canvas的属性，所以功能就生效了

**解决方案：**
1. 修改 `WheelSettingsDialog.__init__` 从正确的位置读取配置：`config["canvas"]["wheel_rectangle_editing"]`
2. 修改 `WheelSettingsDialog.on_value_changed` 保存配置到正确的位置：`config["canvas"]["wheel_rectangle_editing"]`

**修改的文件：**
- `views/labeling/widgets/wheel_settings_dialog.py` (第9-14行, 第278-285行)

**修改1：读取配置的位置**

修改前：
```python
def __init__(self, parent=None, config=None):
    super(WheelSettingsDialog, self).__init__(parent)
    self.parent = parent
    self._config = config if config is not None else {}
    self.wheel_settings = self._config.get("wheel_rectangle_editing", {})  # 从根级别读取
```

修改后：
```python
def __init__(self, parent=None, config=None):
    super(WheelSettingsDialog, self).__init__(parent)
    self.parent = parent
    self._config = config if config is not None else {}
    # Read from canvas.wheel_rectangle_editing, not root level
    self.wheel_settings = self._config.get("canvas", {}).get("wheel_rectangle_editing", {})
```

**修改2：保存配置的位置**

修改前：
```python
# Save to config file
if hasattr(self.parent, '_config'):
    self.parent._config["wheel_rectangle_editing"] = settings  # 保存到根级别
    # Import and use the save_config function
    from anylabeling.config import save_config
    save_config(self.parent._config)
```

修改后：
```python
# Save to config file at the correct location (canvas.wheel_rectangle_editing)
if hasattr(self.parent, '_config'):
    if "canvas" not in self.parent._config:
        self.parent._config["canvas"] = {}
    self.parent._config["canvas"]["wheel_rectangle_editing"] = settings
    # Import and use the save_config function
    from anylabeling.config import save_config
    save_config(self.parent._config)
```

## 技术细节

### 透明度计算公式

**线条透明度：**
```python
alpha = int(spacing_guide_opacity * 255)
```

**文字透明度：**
```python
text_alpha = alpha  # 与线条相同
```

**文字背景透明度：**
```python
bg_alpha_adjusted = int(bg_a * spacing_guide_opacity)
```
其中 `bg_a` 是配置中的文字背景色alpha值（0-255）

**示例：**
- 如果 `spacing_guide_opacity = 0.7`
- 如果 `spacing_guide_text_bg_color = [255, 255, 255, 200]`（白色，alpha=200）
- 则实际绘制的背景色alpha = `int(200 * 0.7) = 140`

### 配置读取路径

**Canvas读取路径：**
```python
wheel_rectangle_editing = config["canvas"]["wheel_rectangle_editing"]
```

**WheelSettingsDialog读取路径（修复后）：**
```python
wheel_settings = config.get("canvas", {}).get("wheel_rectangle_editing", {})
```

**保存路径（修复后）：**
```python
config["canvas"]["wheel_rectangle_editing"] = settings
```
