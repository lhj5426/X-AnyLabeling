# 红绿灯功能增强说明

## 概述

本次更新为红绿灯设置窗口和标签页管理器添加了新功能，增强了标注状态的可视化和管理能力。

---

## 更新内容

### 1. 红绿灯设置窗口 - 清除功能增强

**功能位置：** 工具 → 红绿灯设置

**功能按钮：**
- **清除全部已编辑** - 清除所有图像文件的"已编辑"状态
- **清除本页已编辑** - 仅清除当前打开图像的"已编辑"状态
- **清除全部困难标记** - 清除所有图像文件的"困难标记"（新增）
- **清除本页困难标记** - 仅清除当前打开图像的"困难标记"（新增）

#### 清除已编辑功能

**使用场景：** 清除手动编辑标记

**操作步骤：**
1. 打开红绿灯设置窗口（工具 → 红绿灯设置）
2. 点击"清除全部已编辑"或"清除本页已编辑"按钮
3. 查看日志区域的操作反馈
4. 绿色信号灯将被清除

**技术细节：**
- 清除文件级别的 `manually_edited` 标记
- 清除所有形状的 `is_edited` 标记
- 自动刷新当前文件显示
- 操作完成后在日志区域显示结果

#### 清除困难标记功能（新增）

**使用场景：** 批量或单独清除困难标记

**操作步骤：**
1. 打开红绿灯设置窗口（工具 → 红绿灯设置）
2. 点击"清除全部困难标记"或"清除本页困难标记"按钮
3. 查看日志区域的操作反馈
4. 紫色困难标记灯将被清除

**技术细节：**
- 将所有shapes的 `difficult` 字段从 `true` 改为 `false`
- 批量操作显示进度对话框
- 自动刷新当前文件显示
- 操作完成后在日志区域显示结果

---

### 2. 标签页管理器 - 信号灯系统集成

**功能位置：** 工具 → 标签页管理器（Ctrl+T）

**新增功能：** 对象列表中显示信号灯状态指示器

#### 信号灯说明

在对象列表的每个项目右侧，会显示最多4个彩色圆点，表示不同的状态：

| 位置 | 颜色 | 状态 | 说明 |
|------|------|------|------|
| 最右侧 | 🔴 红色 | 已选中 | 当前项目被选中 |
| 右侧第2 | 🟡 黄色 | 已锁定 | 标签被锁定，不可编辑 |
| 右侧第2 | 🔵 蓝色 | 已解锁 | 锁定标签在本次会话中被临时解锁 |
| 右侧第3 | 🟢 绿色 | 已编辑 | 该对象被手动编辑过 |
| 最左侧 | 🟣 紫色 | 困难标记 | 该对象被标记为困难（difficult: true）|

#### 功能特点

- **实时同步**：信号灯状态与主界面右侧标签列表完全同步
- **可视化管理**：在管理器中直观查看所有对象的状态
- **颜色可配置**：信号灯颜色可在红绿灯设置窗口中自定义

#### 使用示例

```
对象列表显示：
1 other(1)     🔴🟡🟢🟣  ← 选中、锁定、已编辑、困难标记
2 other(2)     🔴🟡🟢    ← 选中、锁定、已编辑
3 other(3)     🔴🟢      ← 选中、已编辑
4 balloon(1)   🟢🟣      ← 已编辑、困难标记
5 balloon(2)   🟣        ← 仅困难标记
6 balloon(3)   🔵        ← 已解锁
7 balloon(4)             ← 无特殊状态
```

## 配置说明

### 信号灯颜色配置

在 `anylabeling/configs/anylabeling_config.yaml` 中配置：

```yaml
traffic_light_colors:
  selected: [255, 0, 0]    # 红色 - 已选中
  edited: [0, 255, 0]      # 绿色 - 已编辑
  difficult: [128, 0, 128] # 紫色 - 困难标记
  locked: [255, 255, 0]    # 黄色 - 已锁定
  unlocked: [0, 0, 255]    # 蓝色 - 已解锁
```

### 锁定标签配置

```yaml
locked_labels: "label1,label2,label3"
```

## 使用流程示例

### 场景1：清除单个文件的编辑标记

1. 打开一个已编辑的图像文件（右侧标签列表显示绿色信号灯）
2. 打开红绿灯设置窗口
3. 点击"清除本页已编辑"按钮
4. 查看日志确认操作成功
5. 绿色信号灯消失

### 场景2：在标签页管理器中查看对象状态

1. 打开标签页管理器（Ctrl+T）
2. 在对象列表中查看每个对象右侧的信号灯
3. 选中某个对象 → 显示红色圆点
4. 编辑某个对象 → 显示绿色圆点
5. 锁定的标签 → 显示黄色圆点
6. 临时解锁的标签 → 显示蓝色圆点

---

## 注意事项

1. **清除本页已编辑**：
   - 只影响当前打开的文件
   - 不会影响其他文件的编辑状态
   - 操作后会自动刷新当前文件显示

2. **信号灯显示**：
   - 信号灯颜色可在红绿灯设置窗口中自定义
   - 信号灯状态实时更新
   - 与主界面标签列表完全同步

3. **性能优化**：
   - 清除本页已编辑操作无需进度对话框
   - 信号灯绘制使用高效的委托模式
   - 不影响其他功能的性能
