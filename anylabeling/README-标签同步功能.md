# 标签同步功能

## 功能说明

将当前页面的标签同步到其他页面，支持批量操作。

## 使用方法

1. **打开工具**：菜单 → 工具 → 标签同步工具
2. **选择标签**：在列表中选择要同步的标签（支持多选）
3. **设置范围**：选择"所有页面"或"自定义范围"
4. **选择模式**：合并模式或替换模式
5. **开始同步**

## 功能特性

- 标签列表与画布双向同步选择
- 显示红绿灯状态指示
- 支持合并模式（保留原有标签）和替换模式
- 自定义范围默认从当前页到最后一页
- 可跳过当前页面
- 实时刷新标签列表

## 文件

- `views/labeling/widgets/label_sync_dialog.py` - 对话框
- `views/labeling/label_widget.py` - 核心逻辑
