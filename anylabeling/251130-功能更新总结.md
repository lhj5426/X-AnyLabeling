# 2025年11月30日 功能更新总结

## 一、框选和路径选择线条固定像素

### 问题描述
ALT+鼠标左键框选模式和SHIFT+鼠标左键路径选择模式的线条宽度会随着图片缩放比例变化，放大到500%或1000%时线条变得很粗。

### 解决方案
在 `views/labeling/widgets/canvas.py` 中修改 `draw_selection_box()` 和 `draw_path_selection()` 函数，使用 `p.resetTransform()` 重置painter变换，将图像坐标转换为屏幕坐标绘制，保持固定的物理像素大小。

### 效果
无论图片放大到多少倍，框选和路径选择的线条都保持固定的物理像素大小（3px）。

## 二、工具窗口快捷键功能

### 功能概述
为15个工具窗口添加快捷键支持，实现三态切换逻辑：
- 窗口未打开时：按快捷键打开窗口
- 窗口最小化时：按快捷键恢复窗口
- 窗口正常显示时：按快捷键隐藏窗口

### 新增快捷键的工具窗口

| 工具名称 | 快捷键配置键 | 默认快捷键 |
|---------|-------------|-----------|
| 标签排序工具 | tag_sort_tool | Alt+1 |
| 旋转框角度修正工具 | angle_correction_tool | Alt+2 |
| 区域合并工具 | merge_tool | Alt+3 |
| 双色标签工具 | dual_color_tool | Alt+4 |
| 掩膜生成 | mask_generator_tool | Alt+5 |
| 红绿灯窗口 | traffic_light_tool | Alt+6 |
| 矩形缩放工具 | rectangle_scale_tool | Alt+7 |
| 页文本工具 | page_text_tool | Alt+8 |
| 高亮设置 | highlight_settings_tool | Alt+9 |
| 标签管理器 | label_manager | Alt+0 |
| 标签切换快捷键管理器 | label_toggle_shortcut_manager | Ctrl+Alt+T |
| 颜色管理工具 | color_manager_tool | Ctrl+Alt+C |
| 辅助线工具 | smart_guides_tool | Ctrl+Alt+G |
| 快捷键管理器 | shortcut_manager_tool | Ctrl+Alt+K |
| 鼠标滚轮设置 | wheel_settings_tool | Ctrl+Alt+W |

### 修改的文件
- `views/labeling/widgets/shortcut_manager_dialog.py` - 添加快捷键配置项
- `views/labeling/label_widget.py` - 添加toggle方法和action定义
- `views/labeling/utils/qt.py` - 设置 `Qt.ApplicationShortcut` 使快捷键全局生效
- `configs/xanylabeling_config.yaml` - 添加默认快捷键配置

### 关键技术点
- 使用 `action.setShortcutContext(QtCore.Qt.ApplicationShortcut)` 使快捷键在应用程序级别生效
- 使用 `hide()` 而不是 `close()` 隐藏窗口，保持窗口状态

## 三、矩形分割工具快捷键修复

### 问题描述
矩形分割工具窗口打开后，无法直接按快捷键关闭，必须先点击主窗口。

### 解决方案
- 移除 `SegmentationDialog` 内部的快捷键创建
- 修改 `update_shortcut` 方法，不再创建内部快捷键
- 添加 `setModal(False)` 确保是非模态窗口

### 修改的文件
- `views/labeling/widgets/segmentation_dialog.py`

## 四、矩形分割后隐藏标签显示问题修复

### 问题描述
使用分割工具对显示的矩形执行分割后，被隐藏的矩形会全部显示出来。

### 解决方案
在 `views/labeling/label_widget.py` 的 `add_label` 方法中，根据形状的 `visible` 属性设置 `checkState`：
```python
label_list_item.setCheckState(Qt.Checked if shape.visible else Qt.Unchecked)
```

## 五、矩形对齐工具统一角度功能修复

### 问题描述
执行统一角度后，横向倾斜的矩形会变成竖向倾斜。

### 原因分析
代码假设 `points[0]` 到 `points[1]` 是宽度，但没有考虑原始矩形的方向。

### 解决方案
在 `views/labeling/label_widget.py` 的 `_perform_alignment` 方法中：
1. 计算参照矩形和目标矩形的两条边长度
2. 判断它们是横向还是竖向
3. 如果方向不一致，交换宽高以保持视觉上的一致性
