# 工具窗口快捷键功能实现文档

## 功能概述

为以下工具窗口添加快捷键支持，实现三态切换逻辑：
1. 窗口未打开时：按快捷键打开窗口
2. 窗口最小化时：按快捷键恢复窗口
3. 窗口正常显示时：按快捷键隐藏窗口

**重要特性**：快捷键在应用程序级别生效，即使焦点在工具窗口上，也可以直接按快捷键关闭窗口，无需先点击主窗口。

#### 2.2 添加通用toggle方法

```python
def _toggle_dialog(self, dialog_attr, open_method):
    """通用的对话框切换方法
    
    行为：
    - 如果对话框不存在或隐藏：打开它
    - 如果对话框最小化：恢复并激活它
    - 如果对话框正常显示：关闭它
    """
    dialog = getattr(self, dialog_attr, None)
    
    if dialog is None or not dialog.isVisible():
        open_method()
    elif dialog.isMinimized():
        dialog.setWindowState(
            dialog.windowState() & ~QtCore.Qt.WindowMinimized | QtCore.Qt.WindowActive
        )
        dialog.raise_()
        dialog.activateWindow()
    else:
        dialog.close()
```

## 使用方法

1. 打开快捷键管理器（菜单 -> 工具 -> 快捷键管理器）
2. 在"工具功能"分类中找到需要设置快捷键的工具
3. 点击对应的输入框，按下想要的快捷键组合
4. 点击"保存"按钮应用更改

## 注意事项

- 标签管理器和标签切换快捷键管理器是模态对话框，每次按快捷键都会打开新窗口
- 其他工具窗口支持三态切换（打开/恢复/隐藏）
- 快捷键设置保存在配置文件中，重启软件后仍然有效
- 快捷键使用 `Qt.ApplicationShortcut` 上下文，即使焦点在工具窗口上也能触发

## 关键修改

### views/labeling/utils/qt.py

在 `new_action` 函数中添加了应用程序级别的快捷键上下文：

```python
# 设置快捷键上下文为应用程序级别，这样即使焦点在子窗口上也能触发
action.setShortcutContext(QtCore.Qt.ApplicationShortcut)
```

这样无论焦点在主窗口还是工具窗口上，快捷键都能正常触发。
