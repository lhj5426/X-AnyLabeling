## 📖 使用方法

### 方法1：使用分辨率计算器（推荐）

**步骤**：
1. 在"原始分辨率"中输入：`1920` × `1080`
2. 在"目标分辨率"中输入：`2560` × `1440`

```
[11:30:26] ✅ 当前页面缩放完成！缩放了 4 个矩形，比例: 1.333333
```

**步骤**：
1. 在"缩放比例"输入框中直接输入：`1.333333`
2. 点击"**应用缩放**"按钮

## 🔧 技术实现

### 1. 实时计算方法

```python
def calculate_scale_from_resolution(self):
    """根据分辨率计算缩放比例"""
    source_w = self.source_width.value()
    source_h = self.source_height.value()
    target_w = self.target_width.value()
    target_h = self.target_height.value()
    
    # 计算宽度和高度的缩放比例
    scale_w = target_w / source_w
    scale_h = target_h / source_h
    
    # 检查是否相同
    if abs(scale_w - scale_h) < 0.0001:
        # 相同：显示绿色
        self.scale_result_label.setText(f"缩放比例: {scale_w:.6f}")
        self.scale_result_label.setStyleSheet("color: #4CAF50;")
    else:
        # 不同：显示橙色警告
        self.scale_result_label.setText(f"宽: {scale_w:.6f} | 高: {scale_h:.6f} (⚠️不同)")
        self.scale_result_label.setStyleSheet("color: #FF9800;")
```

### 2. 应用计算结果

```python
def apply_calculated_scale(self):
    """应用计算出的缩放比例"""
    scale_w = target_w / source_w
    scale_h = target_h / source_h
    
    # 检查宽高比例是否相同
    if abs(scale_w - scale_h) > 0.0001:
        self.add_log("⚠️ 警告：宽度比例和高度比例不同！", "warning")
        self.add_log(f"ℹ️ 将使用宽度比例: {scale_w:.6f}", "info")
    
    # 填入输入框
    self.scale_input.setText(f"{scale_w:.6f}")
```

### 3. 自动连接信号

```python
self.source_width.valueChanged.connect(self.calculate_scale_from_resolution)
self.source_height.valueChanged.connect(self.calculate_scale_from_resolution)
self.target_width.valueChanged.connect(self.calculate_scale_from_resolution)
self.target_height.valueChanged.connect(self.calculate_scale_from_resolution)
```

## 💡 使用技巧

### 技巧1：快速输入常用分辨率

分辨率计算器默认值：
- 原始：1920 × 1080
- 目标：2560 × 1440

如果你的情况不同，只需修改对应的数值即可。

### 技巧2：查看当前图像分辨率

在"图像信息"中可以看到当前图像的实际分辨率：
```
图像信息: 当前图像: 1920 x 1080
```

可以根据这个信息填写"原始分辨率"。

### 技巧3：处理宽高比例不同的情况

如果宽高比例不同（例如从 16:9 转换到 4:3）：
1. 工具会显示警告
2. 默认使用宽度比例
3. 你可以手动调整目标分辨率，使宽高比例相同

### 技巧4：保存常用分辨率

如果经常使用某个分辨率转换：
1. 输入一次后，工具会记住
2. 下次打开时会自动填入上次的值

## ⚠️ 注意事项

### 1. 宽高比例不同

如果原始和目标的宽高比例不同：
- 矩形会变形
- 建议调整目标分辨率，保持宽高比例相同

**示例**：
```
❌ 不推荐：
原始: 1920×1080 (16:9)
目标: 1600×1200 (4:3)
结果: 矩形会变形

✅ 推荐：
原始: 1920×1080 (16:9)
目标: 2560×1440 (16:9)
结果: 矩形不变形
```

### 2. 精度问题

- 缩放比例显示6位小数
- 实际计算使用完整精度
- 不用担心精度损失

### 3. 分辨率范围

- 最小值：1
- 最大值：99999
- 支持任意分辨率
