# 边缘吸附功能 - 实现文档

## 📋 功能概述

为矩形移动添加了**边缘吸附**功能，允许矩形在移动时自动吸附到其他矩形的边缘（贴边效果）。

### 核心特性

1. **独立方向控制** - 可以单独控制上、下、左、右四个方向的吸附
2. **按方向独立优先级** - 辅助线吸附和边缘吸附按方向独立判断优先级
3. **可调吸附距离** - 独立的吸附距离设置（默认 50 像素）
4. **独立开关** - 边缘吸附独立于辅助线吸附开关
5. **只吸附矩形** - 边缘吸附只吸附到其他矩形的边缘，不会吸附到辅助线上

---

## 🎯 优先级说明（重要更新）

### 按方向独立判断优先级

**核心原则**：辅助线吸附和边缘吸附按**方向独立**判断优先级，而不是全局优先级。

### 4 种场景说明

#### **场景 1：辅助线开启 + 辅助线吸附开启 + 某方向吸附开启**
```yaml
smart_guides_enabled: true          # 开启辅助线显示
smart_guides_enable_snap: true      # 开启辅助线吸附
smart_guides_snap_left: true        # 开启左侧吸附
smart_guides_show_vertical: true    # 显示垂直辅助线
```
- ✅ 矩形可以吸附到辅助线上（左边缘对齐其他矩形的左边缘）
- ✅ 显示垂直辅助线

#### **场景 2：辅助线吸附 + 边缘吸附同时开启（同一方向）**
```yaml
smart_guides_enabled: true
smart_guides_enable_snap: true
smart_guides_snap_left: true        # 辅助线：左侧吸附
edge_snap_enabled: true
edge_snap_left: true                # 边缘吸附：左侧吸附
```
- ✅ 辅助线吸附优先于边缘吸附（左方向）
- ✅ 矩形吸附到辅助线上，显示辅助线

#### **场景 3：辅助线开启但吸附关闭 + 边缘吸附开启**
```yaml
smart_guides_enabled: true          # 开启辅助线显示
smart_guides_enable_snap: false     # ❌ 关闭辅助线吸附
edge_snap_enabled: true             # 开启边缘吸附
edge_snap_left: true                # 左侧边缘吸附
```
- ✅ 矩形只和矩形吸附（边缘贴边）
- ❌ **不会吸附到辅助线上**（因为辅助线吸附已关闭）
- ✅ 可以显示辅助线（仅作为参考，不吸附）

#### **场景 4：辅助线关闭 + 边缘吸附开启**
```yaml
smart_guides_enabled: false         # 关闭辅助线显示
edge_snap_enabled: true             # 开启边缘吸附
edge_snap_left: true
```
- ✅ 只和矩形吸附（边缘贴边）
- ❌ 不显示辅助线

### 按方向独立优先级示例

**示例**：辅助线开启上下吸附 + 边缘吸附开启左右吸附
```yaml
# 辅助线设置
smart_guides_enable_snap: true
smart_guides_snap_top: true         # ✅ 上边吸附
smart_guides_snap_bottom: true      # ✅ 下边吸附
smart_guides_snap_left: false       # ❌ 左边不吸附
smart_guides_snap_right: false      # ❌ 右边不吸附

# 边缘吸附设置
edge_snap_enabled: true
edge_snap_left: true                # ✅ 左边吸附
edge_snap_right: true               # ✅ 右边吸附
edge_snap_top: false                # ❌ 上边不吸附
edge_snap_bottom: false             # ❌ 下边不吸附
```

**效果**：
- **垂直方向（上下）**：使用辅助线吸附（显示水平辅助线）
- **水平方向（左右）**：使用边缘吸附（不显示垂直辅助线）
- ✅ 两个方向可以同时生效，互不干扰

### 工作原理

```python
# 对于每个方向（X 和 Y）独立判断：
for direction in [X方向, Y方向]:
    if 辅助线吸附开启 and 该方向有辅助线吸附:
        ✅ 使用辅助线吸附
    elif 边缘吸附开启 and 该方向有边缘吸附:
        ✅ 使用边缘吸附
    else:
        ❌ 该方向不吸附
```

这样设计的好处：
- **灵活组合** - 可以在不同方向使用不同的吸附方式
- **互不干扰** - 辅助线吸附上下，边缘吸附左右，同时生效
- **精确控制** - 每个方向都可以独立控制

#### 新增 `_detect_edge_snap()` 方法（第 5507-5591 行）：

```python
def _detect_edge_snap(self, moving_rects, snap_distance):
    """
    检测边缘吸附（矩形边缘贴边）

    Args:
        moving_rects: 正在移动的矩形列表
        snap_distance: 吸附距离

    Returns:
        QtCore.QPointF: 吸附偏移量，如果没有吸附则返回None
    """
    # 获取所有移动形状的整体边界
    all_left = min(r['left'] for r in moving_rects)
    all_right = max(r['right'] for r in moving_rects)
    all_top = min(r['top'] for r in moving_rects)
    all_bottom = max(r['bottom'] for r in moving_rects)

    snap_x = None
    snap_y = None
    min_dist_x = snap_distance
    min_dist_y = snap_distance

    # 遍历所有其他形状，检测边缘吸附
    for other_shape in self.shapes:
        # 跳过不可见和正在移动的形状
        if not self.is_visible(other_shape):
            continue

        # 检查是否是正在移动的形状
        is_moving = False
        other_rect = other_shape.bounding_rect()
        for moving_rect in moving_rects:
            if (abs(other_rect.left() - moving_rect['left']) < 0.1 and
                abs(other_rect.right() - moving_rect['right']) < 0.1 and
                abs(other_rect.top() - moving_rect['top']) < 0.1 and
                abs(other_rect.bottom() - moving_rect['bottom']) < 0.1):
                is_moving = True
                break

        if is_moving:
            continue

        # 检测水平边缘吸附（左右边缘贴边）
        if self.edge_snap_left:
            # 移动矩形的左边 贴 目标矩形的右边
            dist = abs(all_left - target_right)
            if dist < min_dist_x:
                min_dist_x = dist
                snap_x = target_right - all_left

        if self.edge_snap_right:
            # 移动矩形的右边 贴 目标矩形的左边
            dist = abs(all_right - target_left)
            if dist < min_dist_x:
                min_dist_x = dist
                snap_x = target_left - all_right

        # 检测垂直边缘吸附（上下边缘贴边）
        if self.edge_snap_top:
            # 移动矩形的上边 贴 目标矩形的下边
            dist = abs(all_top - target_bottom)
            if dist < min_dist_y:
                min_dist_y = dist
                snap_y = target_bottom - all_top

        if self.edge_snap_bottom:
            # 移动矩形的下边 贴 目标矩形的上边
            dist = abs(all_bottom - target_top)
            if dist < min_dist_y:
                min_dist_y = dist
                snap_y = target_top - all_bottom

    # 返回吸附偏移量
    if snap_x is not None or snap_y is not None:
        return QtCore.QPointF(snap_x if snap_x is not None else 0,
                             snap_y if snap_y is not None else 0)

    return None
```

**边缘吸附逻辑**：
- **左边缘吸附**：移动矩形的左边 → 目标矩形的右边（贴边）
- **右边缘吸附**：移动矩形的右边 → 目标矩形的左边（贴边）
- **上边缘吸附**：移动矩形的上边 → 目标矩形的下边（贴边）
- **下边缘吸附**：移动矩形的下边 → 目标矩形的上边（贴边）

**关键点**：
- **只遍历 `self.shapes`**：只检测其他矩形，不检测辅助线
- **跳过正在移动的形状**：避免自己吸附自己
- **独立方向控制**：每个方向可以独立开关

### 边缘吸附检测算法

```python
# 1. 获取移动矩形的整体边界
all_left = min(r['left'] for r in moving_rects)
all_right = max(r['right'] for r in moving_rects)
all_top = min(r['top'] for r in moving_rects)
all_bottom = max(r['bottom'] for r in moving_rects)

# 2. 遍历所有其他矩形
for other_shape in self.shapes:
    # 3. 计算边缘距离
    dist_left_to_right = abs(all_left - target_right)
    dist_right_to_left = abs(all_right - target_left)
    dist_top_to_bottom = abs(all_top - target_bottom)
    dist_bottom_to_top = abs(all_bottom - target_top)
    
    # 4. 找到最近的吸附位置
    if dist < min_dist and dist < snap_distance:
        snap_offset = target_pos - moving_pos
```

#### 1. **修复：边缘吸附不应该吸附到辅助线上**

- 边缘吸附统一在 `detect_smart_guides` 方法中处理
- 边缘吸附独立于 `enable_snap` 参数，只要 `edge_snap_enabled=True` 就生效
- `_detect_edge_snap` 方法只遍历 `self.shapes`，不检测辅助线
