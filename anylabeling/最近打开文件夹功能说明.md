# 最近打开文件夹功能说明

## 功能概述

在"文件"菜单中显示最近打开的文件夹历史记录，方便快速切换到之前使用的文件夹。

## 功能特性

### 1. 显示最近打开的文件夹（而非文件）
- 记录最近打开的**文件夹路径**，不再显示单个文件
- 最多显示 **50个** 文件夹历史记录
- 按打开时间倒序排列（最新的在最前面）

### 2. 路径长度限制
- 单个路径最长显示 **200个字符**
- 超过200字符的路径会截断并显示 `...`
- 示例：
  ```
  C:\Users\username\very\long\path\that\exceeds\two\hundred\characters\will\be\truncated\and\show\dots\at\the\end\to\indicate\there\is\more\content\that\cannot\...
  ```

### 3. 历史记录持久化
- ✅ **软件重启后自动恢复历史记录**
- ✅ 每次打开新文件夹时实时保存到配置文件
- ✅ 使用 Qt Settings 机制保存（注册表/配置文件）

### 4. 清除历史功能
- 菜单最下方提供"清除最近打开的历史"选项
- 点击后立即清空所有历史记录并保存

## 使用方法

### 打开最近的文件夹
1. 点击菜单栏 **文件** → **是否打开文件**
2. 选择列表中的任意文件夹路径
3. 软件会自动加载该文件夹中的图片

示例菜单：
```
文件 → 是否打开文件
  &1 J:\G\Desktop\OCRTEST\0005
  &2 J:\G\Desktop\OCRTEST\0004
  &3 D:\Projects\Images\Dataset1
  &4 C:\Users\admin\Documents\images
  ...
  &50 E:\data\training_set
  ─────────────────────────
  清除最近打开的历史
```

### 清除历史记录
1. 点击菜单栏 **文件** → **是否打开文件**
2. 点击最下方的 **清除最近打开的历史**
3. 所有历史记录立即清空

```python
def update_recent_folder(self, folder_path):
    """Add a folder to the recent folders list.

    Args:
        folder_path: Absolute path to the folder

    Note:
        If the folder is already in the list, it's moved to the front.
        If the list exceeds max_recent_folders limit (50), the oldest entry is removed.
    """
    folder_path = str(folder_path)
    if folder_path in self.recent_folders:
        self.recent_folders.remove(folder_path)
    elif len(self.recent_folders) >= self.max_recent_folders:
        self.recent_folders.pop()
    self.recent_folders.insert(0, folder_path)
    self.settings.setValue("recent_folders", self.recent_folders)
```

```python
def update_file_menu(self):
    # ... 省略其他代码 ...

    # Display recent folders (max 50)
    for i, folder_path in enumerate(self.recent_folders):
        # Truncate long paths to 200 characters
        display_path = folder_path
        if len(folder_path) > 200:
            display_path = folder_path[:200] + "..."

        # Create menu action with keyboard shortcut
        action = QtWidgets.QAction(
            f"&{i + 1} {display_path}",
            self,
            triggered=lambda checked, path=folder_path: self.load_recent_folder(path)
        )
        menu.addAction(action)

    # Add separator and clear history option
    if self.recent_folders:
        menu.addSeparator()
        clear_action = QtWidgets.QAction(
            "清除最近打开的历史",
            self,
            triggered=self.clear_recent_folders
        )
        menu.addAction(clear_action)
```

## 配置存储

### 存储位置
- **Windows**: 注册表 `HKEY_CURRENT_USER\Software\anylabeling\anylabeling`
- **Linux/Mac**: 配置文件 `~/.config/anylabeling/anylabeling.conf`

### 存储键名
- `recent_folders`: 列表类型，存储所有文件夹路径

## 注意事项

1. 历史记录会跨会话保留，除非手动清除
2. 重复打开同一文件夹会将其移到列表最前面
3. 超过50个文件夹时，最旧的记录会被自动移除
4. 路径必须是绝对路径
5. 每次操作都会立即保存到配置文件，无需手动保存
