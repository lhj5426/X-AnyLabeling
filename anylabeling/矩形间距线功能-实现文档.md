## 📋 功能概述

为X-AnyLabeling添加**矩形间距线**功能，用于显示矩形之间的距离。

### 功能特点

1. ✅ **三种矩形类型支持**
   - 水平矩形 (rectangle)
   - 水平旋转矩形 (rotation/rotation3 @ 0°/90°/180°/270°)
   - 有角度旋转矩形 (rotation/rotation3 @ 其他角度)

2. ✅ **四条边检测**
   - 检测矩形的左、右、上、下四条边
   - 对每条边检查对侧是否有其他矩形

3. ✅ **间距线显示**
   - 在两个矩形之间显示间距线
   - 间距线位置：矩形中间
   - 间距线方向：垂直于矩形边

4. ✅ **距离数值显示**
   - 在间距线上显示距离数值
   - 精度：小数点后2位
   - 背景：半透明黑色

## 🔧 技术实现

### 矩形类型判断
```python
def get_rectangle_type(shape) -> str:
    # 返回值：
    # - 'horizontal': 水平矩形
    # - 'horizontal_rotation': 水平旋转矩形
    # - 'tilted_rotation': 有角度旋转矩形
```

### 间距检测流程
1. 获取移动矩形的四条边
2. 对每条边，检查对侧是否有其他矩形
3. 计算最近的对侧矩形的距离
4. 如果距离在显示范围内，生成间距线数据

### 间距线数据结构
```python
{
    'x1': float,        # 线段起点X
    'y1': float,        # 线段起点Y
    'x2': float,        # 线段终点X
    'y2': float,        # 线段终点Y
    'distance': float,  # 距离值
    'type': str         # 'horizontal', 'vertical', 'tilted'
}
```

### 绘制流程
1. 绘制间距线（实线）
2. 计算线的中点
3. 格式化距离数值（小数点后2位）
4. 绘制半透明背景
5. 绘制距离文字

## 🚀 使用方式

1. **启用功能**
   - 在配置文件中设置 `spacing_guide_enabled: true`

2. **创建或移动矩形**
   - 创建矩形或拖动矩形时，自动显示间距线

3. **查看距离**
   - 间距线上显示距离数值（小数点后2位）

4. **调整配置**
   - 修改配置文件中的参数调整线宽、颜色、透明度等
