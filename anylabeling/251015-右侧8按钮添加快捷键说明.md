# 251015-右侧8按钮添加快捷键说明

## 1. 需求

为软件右侧的“标签列表”和“对象列表”中的8个功能按钮添加可自定义的快捷键。

## 2. 修改内容

### 2.1. 配置文件修改

为了实现快捷键的自定义功能，我们首先在默认配置文件中添加了新的快捷键配置项。

*   **文件路径**: `anylabeling/configs/xanylabeling_config.yaml`
*   **修改内容**: 在 `shortcuts` 部分，添加了以下8个快捷键的默认配置。

```yaml
  select_all_labels: Alt+Q
  deselect_all_labels: Alt+W
  invert_selection_labels: Alt+E
  toggle_overlap: Alt+R
  select_all_shapes: Alt+A
  deselect_all_shapes: Alt+S
  invert_selection_shapes: Alt+I
  toggle_highlight: Alt+F
```

### 2.2. UI 逻辑修改

修改了UI代码，使其在启动时读取上述配置，并将快捷键应用到对应的按钮上。

*   **文件路径**: `anylabeling/views/labeling/label_widget.py`
*   **修改内容**:
    1.  在 `LabelingWidget` 类的 `__init__` 方法中，为“对象列表”的4个按钮（全选, 反选, 取消, 高亮）添加了 `setShortcut()` 方法，以应用配置中的快捷键。
    2.  在 `create_label_control_buttons` 方法中，为“标签列表”的4个按钮（全选, 反选, 取消, 重叠）添加了 `setShortcut()` 方法，以应用配置中的快捷键。

### 2.3. 核心逻辑修正

修复了一个程序启动时配置被错误覆盖的Bug。

*   **文件路径**: `anylabeling/config.py`
*   **修改内容**: 在 `get_config` 函数中，注释掉了最后自动回写配置文件的 `save_config(config)` 调用，以防止用户在个人配置文件中的手动修改被程序启动时加载的旧配置覆盖。

## 3. 快捷键说明

以下是新增的8个快捷键及其默认值。您可以在您的个人配置文件 (`C:\Users\YourUsername\.YSGxanylabelingrc`) 中找到并修改它们。

*   `select_all_labels: Alt+Q` # 全选 (标签列表)
*   `deselect_all_labels: Alt+W` # 取消 (标签列表)
*   `invert_selection_labels: Alt+E` # 反选 (标签列表)
*   `toggle_overlap: Alt+R` # 重叠
*   `select_all_shapes: Alt+A` # 全选 (对象列表)
*   `deselect_all_shapes: Alt+S` # 取消 (对象列表)
*   `invert_selection_shapes: Alt+I` # 反选 (对象列表)
*   `toggle_highlight: Alt+F` # 高亮
