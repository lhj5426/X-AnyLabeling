# 矩形缩放工具 - 缩放次数统计功能说明

## 📋 功能概述

新增**缩放次数统计**功能，自动记录每个缩放比例使用的次数，并在日志中显示警告，帮助用户发现重复操作。

### 使用场景

当你不小心多次点击"应用缩放"按钮时，工具会：
1. 自动记录每个比例使用的次数
2. 在日志中显示警告提示
3. 提示使用累乘还原功能恢复

---

## 🎯 功能特点

### 1️⃣ 自动记录缩放次数

每次应用缩放后，工具会自动记录该比例使用的次数。

**示例**：
```

[14:23:59] ✅ 当前页面缩放完成！缩放了 13 个矩形，比例: 0.3000 [第2次] ⚠️ 重复操作

[14:24:00] 💡 提示：比例 0.3000 已使用 3 次，如需还原可使用累乘还原功能
```

### 2️⃣ 智能警告提示

- **第1次使用**：绿色成功提示 ✅
- **第2次及以上**：橙色警告提示 ⚠️
- **第3次及以上**：额外显示累乘还原提示 💡

### 3️⃣ 支持所有缩放模式

- ✅ 当前页面缩放
- ✅ 批量缩放（全部）
- ✅ 范围缩放

### 4️⃣ 重置历史功能

新增"重置历史"按钮，可以清空缩放次数统计，重新开始计数。

## 🔧 技术实现

### 1. 缩放历史记录

使用字典存储每个比例的使用次数：

```python
# 缩放历史记录：{比例: 次数}
self.scale_history = {}

# 示例：
# {
#     0.3000: 3,    # 0.3 使用了3次
#     0.5000: 2,    # 0.5 使用了2次
#     1.5000: 1     # 1.5 使用了1次
# }
```

### 2. 记录逻辑

```python
def record_scale_history(self, scale_factor, scaled_count, is_batch=False, ...):
    # 四舍五入到4位小数，避免浮点数精度问题
    scale_key = round(scale_factor, 4)
    
    # 记录或更新次数
    if scale_key in self.scale_history:
        self.scale_history[scale_key] += 1
    else:
        self.scale_history[scale_key] = 1
    
    times = self.scale_history[scale_key]
    
    # 根据次数显示不同的日志
    if times == 1:
        level = "success"  # 绿色
    else:
        level = "warning"  # 橙色
```

### 3. 重置功能

```python
def reset_scale_history(self):
    """重置缩放历史记录"""
    self.scale_history.clear()
    self.add_log("🔄 缩放历史已重置", "info")
```

## ⚠️ 注意事项

### 1. 历史记录的生命周期

- **会话内有效**：缩放历史在对话框打开期间一直保留
- **关闭后清空**：关闭对话框后，历史记录会被清空
- **手动重置**：点击"重置历史"按钮可以随时清空

### 2. 浮点数精度处理

比例会四舍五入到4位小数进行统计：
- `0.299994` → 统计为 `0.3000`
- `0.300001` → 统计为 `0.3000`
- 这两个会被视为同一个比例

### 3. 批量缩放也会计数

无论是单页缩放还是批量缩放，都会累加到同一个比例的计数中。

### 4. 撤销操作不影响计数

使用 Ctrl+Z 撤销缩放操作，不会减少计数。如需重新计数，请点击"重置历史"。

## 🎯 使用建议

### 建议1：开始新任务时重置历史

如果你要处理新的一批图像，建议先点击"重置历史"，清空之前的统计。

### 建议2：注意警告提示

看到 ⚠️ 重复操作警告时，检查是否手误多点了。

### 建议3：使用累乘还原

如果确实多点了，按照提示使用"累乘还原"功能快速恢复。

### 建议4：配合撤销功能

如果刚操作完，直接 Ctrl+Z 撤销最快，不需要计算。
