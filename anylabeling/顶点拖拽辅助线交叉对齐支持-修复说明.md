# 顶点拖拽辅助线交叉对齐支持 - 修复说明

**修复日期：** 2025-11-09  
**修复原因：** 拖拽顶点/边中点时，辅助线缺少交叉对齐检测，导致辅助线显示不完整

---

## 📋 问题描述

### 修复前的行为

**拖拽顶点/边中点时：**
- ✅ 检测相同边对齐（左对左、右对右、上对上、下对下）
- ❌ **缺少交叉边对齐**（左对右、右对左、上对下、下对上）

**移动整个形状时：**
- ✅ 检测相同边对齐
- ✅ 检测交叉边对齐（PS 风格）

**导致的问题：**
拖拽顶点/边中点时，辅助线功能不完整，无法检测到交叉对齐的情况。

### 修复后的行为

**拖拽顶点/边中点时：**
- ✅ 检测相同边对齐
- ✅ 检测交叉边对齐（PS 风格）← 新增！

**移动整个形状时：**
- ✅ 检测相同边对齐
- ✅ 检测交叉边对齐（PS 风格）

**现在的效果：**
拖拽顶点/边中点时，辅助线功能与移动整个形状时完全一致。

---

## 🎯 什么是交叉对齐？

### 相同边对齐
```
矩形A          矩形B
┌─────┐        ┌─────┐
│     │        │     │  ← 左边对齐左边
└─────┘        └─────┘
```

### 交叉边对齐（PS 风格）
```
矩形A          矩形B
┌─────┐┌─────┐
│     ││     │  ← 矩形A的右边 对齐 矩形B的左边
└─────┘└─────┘
```

这种对齐方式在 Photoshop 等设计软件中非常常见，可以快速对齐相邻的矩形。

## 🔧 修改的文件

### `views/labeling/widgets/canvas.py`

#### 修改方法：`detect_vertex_smart_guides`（第5865-5925行）

**修改前的检测逻辑：**
```python
# 只检测相同边对齐
h_alignments = [
    ('left', moving_bounds['left'], target['left']),
    ('right', moving_bounds['right'], target['right']),
]
```

**修改后的检测逻辑：**
```python
# 检测相同边 + 交叉边对齐（PS 风格）
h_alignments = [
    # 相同边对齐
    ('left', moving_bounds['left'], target['left']),
    ('right', moving_bounds['right'], target['right']),
    # 交叉边对齐（PS 风格）
    ('left_to_right', moving_bounds['left'], target['right']),   # 移动矩形的左边 对齐 目标矩形的右边
    ('right_to_left', moving_bounds['right'], target['left']),   # 移动矩形的右边 对齐 目标矩形的左边
]
```

**垂直对齐也做了相同的修改：**
```python
# 检测相同边 + 交叉边对齐（PS 风格）
v_alignments = [
    # 相同边对齐
    ('top', moving_bounds['top'], target['top']),
    ('bottom', moving_bounds['bottom'], target['bottom']),
    # 交叉边对齐（PS 风格）
    ('top_to_bottom', moving_bounds['top'], target['bottom']),   # 移动矩形的顶边 对齐 目标矩形的底边
    ('bottom_to_top', moving_bounds['bottom'], target['top']),   # 移动矩形的底边 对齐 目标矩形的顶边
]
```

## 📝 技术实现

### 1. 水平对齐检测（4种方式）

| 对齐类型 | 说明 | 示例 |
|---------|------|------|
| **left** | 左边对齐左边 | `┌─┐  ┌─┐` |
| **right** | 右边对齐右边 | `┌─┐  ┌─┐` |
| **left_to_right** | 左边对齐右边 | `┌─┐┌─┐` |
| **right_to_left** | 右边对齐左边 | `┌─┐┌─┐` |

### 2. 垂直对齐检测（4种方式）

| 对齐类型 | 说明 | 示例 |
|---------|------|------|
| **top** | 顶边对齐顶边 | 矩形顶部对齐 |
| **bottom** | 底边对齐底边 | 矩形底部对齐 |
| **top_to_bottom** | 顶边对齐底边 | 矩形上下相邻 |
| **bottom_to_top** | 底边对齐顶边 | 矩形上下相邻 |

### 3. 吸附方向开关

修改后的吸附逻辑：

```python
# 水平吸附
if align_type in ['left', 'left_to_right']:
    should_snap = self.smart_guides_snap_left
elif align_type in ['right', 'right_to_left']:
    should_snap = self.smart_guides_snap_right

# 垂直吸附
if align_type in ['top', 'top_to_bottom']:
    should_snap = self.smart_guides_snap_top
elif align_type in ['bottom', 'bottom_to_top']:
    should_snap = self.smart_guides_snap_bottom
```

**逻辑说明：**
- `left` 和 `left_to_right` 都使用 `smart_guides_snap_left` 开关
- `right` 和 `right_to_left` 都使用 `smart_guides_snap_right` 开关
- 垂直方向同理

## 💡 为什么需要交叉对齐？

### 设计软件的标准功能

在 Photoshop、Figma、Sketch 等设计软件中，交叉对齐是标准功能：

1. **快速对齐相邻元素**
   - 将矩形B的左边对齐到矩形A的右边
   - 无需手动计算位置

2. **提高标注效率**
   - 标注相邻的物体时，可以快速对齐边缘
   - 减少手动调整的时间

3. **保持一致性**
   - 移动整个形状时有交叉对齐
   - 拖拽顶点/边中点时也应该有交叉对齐
   - 保持功能的一致性
