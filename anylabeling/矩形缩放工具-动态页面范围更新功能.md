# 矩形缩放工具 - 动态页面范围更新功能

## 📋 功能概述

新增**动态页面范围更新**功能，当你在主窗口切换页面时，矩形缩放工具的"范围"起始页会自动更新为当前页。

### 问题场景

**之前的问题**：
```
1. 在第2页打开矩形缩放工具
   → 范围显示：从第 2 页到第 100 页 ✅

2. 切换到第3页
   → 范围仍然显示：从第 2 页到第 100 页 ❌（没有更新）

3. 必须关闭工具窗口，重新打开
   → 范围才会显示：从第 3 页到第 100 页 ✅
```

**现在的解决方案**：
```
1. 在第2页打开矩形缩放工具
   → 范围显示：从第 2 页到第 100 页 ✅

2. 切换到第3页
   → 范围自动更新：从第 3 页到第 100 页 ✅（动态更新）

3. 切换到第10页
   → 范围自动更新：从第 10 页到第 100 页 ✅（动态更新）
```

---

## 🎯 功能特点

### 1️⃣ 自动跟随当前页

无论你如何切换页面，范围的起始页始终跟随当前页：

- ✅ 点击"下一张"按钮 → 自动更新
- ✅ 点击"上一张"按钮 → 自动更新
- ✅ 在文件列表中点击 → 自动更新
- ✅ 使用快捷键切换 → 自动更新
- ✅ 跳转到指定页 → 自动更新

### 2️⃣ 保持工具窗口打开

不需要关闭再打开工具窗口，范围会实时更新。

### 3️⃣ 结束页保持不变

只有起始页会跟随当前页变化，结束页始终保持为总页数。

**示例**：
```
总共100页

在第2页：从第 2 页到第 100 页
在第3页：从第 3 页到第 100 页
在第50页：从第 50 页到第 100 页
```

## 🔧 技术实现

### 1. 监听页面切换事件

在 `load_file()` 方法中，每次加载新文件后，自动更新矩形缩放工具的页面范围：

```python
def load_file(self, filename=None):
    # ... 加载文件的代码 ...
    
    # Update rectangle scale dialog page range if open
    self._update_rectangle_scale_page_range()
    
    return True
```

### 2. 更新页面范围方法

```python
def _update_rectangle_scale_page_range(self):
    """Update page range in rectangle scale dialog if it's open and visible."""
    if (hasattr(self, 'rectangle_scale_dialog') and
        self.rectangle_scale_dialog is not None and
        self.rectangle_scale_dialog.isVisible()):
        # 获取当前页码
        if self.filename and self.filename in self.fn_to_index:
            current_page = self.fn_to_index[str(self.filename)] + 1  # 从0开始，所以+1
        else:
            current_page = 1
        total_pages = len(self.image_list) if self.image_list else 0
        # 更新页面范围
        self.rectangle_scale_dialog.update_page_range(current_page, total_pages)
```

### 3. 只在工具打开时更新

只有当矩形缩放工具窗口是**打开且可见**的状态时，才会更新页面范围，避免不必要的计算。

## 📊 更新逻辑

### 更新时机

| 操作 | 是否更新范围 | 说明 |
|------|-------------|------|
| 切换到下一页 | ✅ 是 | 自动更新起始页 |
| 切换到上一页 | ✅ 是 | 自动更新起始页 |
| 点击文件列表 | ✅ 是 | 自动更新起始页 |
| 跳转到指定页 | ✅ 是 | 自动更新起始页 |
| 工具窗口关闭 | ❌ 否 | 不更新（窗口不可见） |
| 工具窗口最小化 | ❌ 否 | 不更新（窗口不可见） |

### 更新内容

| 项目 | 更新方式 | 示例 |
|------|---------|------|
| 起始页 | 跟随当前页 | 当前第3页 → 起始页=3 |
| 结束页 | 保持总页数 | 总共100页 → 结束页=100 |
| 范围最大值 | 更新为总页数 | 总共100页 → 最大值=100 |
| 范围最小值 | 固定为1 | 最小值=1 |

## ⚠️ 注意事项

### 1. 结束页会被重置

如果你手动修改了结束页（比如改成50），切换页面后会恢复为总页数（100）。

**解决方法**：
- 如果需要固定范围，先切换到起始页，再修改结束页，然后立即应用缩放
- 或者在应用缩放前不要切换页面

### 2. 只在工具打开时更新

如果工具窗口关闭或最小化，切换页面不会更新范围。重新打开工具窗口时，会更新为当前页。

### 3. 手动修改仍然有效

你仍然可以手动修改起始页和结束页，只是切换页面时会被重置。
